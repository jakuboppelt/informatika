Jak funguje internet

Od čtyř počítačů v roce 1969 k šesti miliardám lidí. Pakety, IP adresy, TCP a UDP, HTTP a VPN, všechno si vyzkoušíš na interaktivních ukázkách.

Údaje platí k říjnu 2026. Zdroje jsou na posledním snímku.

Vrstvy

Každá vrstva přidá svou obálku

AplikačníHTTP, DNS, e-mail
TransportníTCP, UDP: porty
SíťováIP: adresy a směrování
SpojováEthernet, Wi-Fi: MAC

Model TCP/IP má 4 vrstvy. Teoretický model OSI jich má 7 (fyzická, linková, síťová, transportní, relační, prezentační, aplikační), internet ale stojí na TCP/IP.

NAT

Celá domácnost za jednou veřejnou adresou

Doma mají zařízení soukromé adresy (192.168.x.x), které v internetu neplatí. Router je při odeslání přepíše na svou jedinou veřejnou adresu a pamatuje si, komu patří odpověď. Klikni na zařízení.

Porty

IP adresa určí počítač, port určí program

IP adresa je jako adresa domu, port jako číslo bytu. Port je 16bitové číslo (0 až 65 535). Server poslouchá na známém portu, klient si vybere dočasný.

  • Internet je síť sítí. Data putují v paketech, každý zvlášť, a skládají se u příjemce.
    • 
        
  • Vrstvy: aplikační (HTTP, DNS), transportní (TCP, UDP), síťová (IP), spojová (Ethernet, Wi-Fi).
    • 
        
  • IPv4 má 32 bitů a adresy došly, pomáhá NAT a přechod na IPv6 (128 bitů). DNS překládá jména na adresy.
    • 
        
  • TCP je spolehlivé a hlídá pořadí, UDP je rychlé a nic nezaručuje. HTTP/3 běží nad UDP.
    • 
        
  • HTTP = požadavek a odpověď se stavovým kódem. HTTPS šifruje obsah, ne název domény.
    • 
        
  • VPN přesune důvěru od poskytovatele k provozovateli VPN, anonymitu nezaručí.
