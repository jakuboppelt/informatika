Sudoku krok za krokem ručně i v Pythonu

Dvě sudoku 6 × 6. První vyřešíš tak, že vždy najdeš políčko, kam jde napsat jen jedna číslice. U druhého taková políčka nejsou: musíš zkusit hádat, dojdeš ke sporu a vrátíš se. Pak stejný postup naprogramuješ v Pythonu a necháš ho vyřešit i velké sudoku 9 × 9.

Po ukázce bys měl umět

  • určit kandidáty prázdného políčka
  • vyřešit sudoku pomocí jediných možností
  • zvolit, kde hádat, a poznat spor
  • správně se vrátit: co smazat a co zkusit dál
  • napsat rekurzivní backtracking v Pythonu
  • vysvětlit, proč pomáhá políčko s nejméně možnostmi

Ručně

Pravidla a značení

Sudoku 6 × 6 má šest řádků, šest sloupců a šest čtverců 2 × 3 (oddělené silnější čarou). Do prázdných políček doplň číslice 1 až 6 tak, aby v každém řádku, sloupci i čtverci byla každá číslice právě jednou.

Políčka označujeme jako buňky v tabulkovém procesoru: sloupec písmenem A až F, řádek číslem 1 až 6. Políčko D3 je ve sloupci D a ve třetím řádku.

Kandidáti políčka jsou číslice, které v něm ještě můžou být: nejsou v jeho řádku, sloupci ani čtverci.

Postup

  1. Kandidáti. U prázdného políčka se podívej do jeho řádku, sloupce a čtverce. Co tam není, je kandidát.
  2. Jediná možnost. Najdi políčko, které má jen jednoho kandidáta, a napiš ho. Je to jisté.
  3. Pokus. Když takové políčko není, vyber políčko s nejméně kandidáty (nejlépe se dvěma) a jednoho zkus. Na papíře ho napiš jinou barvou nebo zakroužkuj, ať víš, odkud jsi začal hádat. Všechno, co napíšeš potom, je taky nejisté.
  4. Spor a návrat. Když narazíš na políčko, do kterého nejde napsat nic, pokus byl špatně. Smaž všechno od pokusu (včetně něj) a zkus další kandidáta.

Přesně tímhle postupem jede i program v Pythonu níže. Krokovače na této stránce ukazují, co dělá on.

V Pythonu

1. Mřížka

Mřížku uložíme jako seznam řádků, každý řádek je seznam čísel. Prázdné políčko je 0. Políčko v řádku r a sloupci s je mrizka[r][s], oba indexy počítáme od nuly.

Ukázka
VYSKA, SIRKA = 2, 3          # rozměry jednoho čtverce: 2 × 3
N = VYSKA * SIRKA            # velikost mřížky: 6 × 6, číslice 1 až 6

ZADANI = [                   # 0 znamená prázdné políčko
    [0, 0, 2, 3, 6, 5],
    [5, 6, 3, 1, 4, 2],
    [0, 0, 0, 4, 0, 6],
    [0, 0, 0, 0, 0, 1],
    [0, 3, 0, 0, 0, 4],
    [0, 2, 0, 0, 1, 3],
]

print(ZADANI[0][2])          # řádek 1, sloupec C: vypíše 2

Rozměry čtverce máme v konstantách. Když je změníš na 3, 3, program bude řešit klasické sudoku 9 × 9.

2. Kandidáti

Funkce kandidati posbírá do množiny všechno, co je v řádku, sloupci a čtverci políčka, a vrátí číslice, které tam nejsou.

Ukázka
def kandidati(mrizka, r, s):
    """Číslice, které jde napsat do políčka (r, s) podle pravidel."""
    pouzite = set(mrizka[r])                            # řádek
    pouzite |= {mrizka[i][s] for i in range(N)}         # sloupec
    r0 = r // VYSKA * VYSKA                             # levý horní roh čtverce
    s0 = s // SIRKA * SIRKA
    for i in range(r0, r0 + VYSKA):                     # čtverec
        for j in range(s0, s0 + SIRKA):
            pouzite.add(mrizka[i][j])
    return [c for c in range(1, N + 1) if c not in pouzite]

Kde začíná čtverec? Celočíselným dělením a vynásobením zaokrouhlíme index dolů na násobek velikosti čtverce. Políčko v řádku r = 3 (řádek 4) leží ve čtverci, který začíná řádkem 3 // 2 * 2 = 2 (řádek 3). Sloupec s = 4 (E) leží ve čtverci od sloupce 4 // 3 * 3 = 3 (D).

>>> kandidati(ZADANI, 0, 0)      # políčko A1
[1, 4]

3. Políčko s nejméně možnostmi

Projdeme všechna prázdná políčka a zapamatujeme si to s nejkratším seznamem kandidátů. Když je víc stejně dobrých, vyhraje první (shora, zleva). Funkce vrátí trojici (r, s, kandidáti), nebo None, když už prázdné políčko není.

Ukázka
def najdi_policko(mrizka):
    """Prázdné políčko s nejméně možnostmi, nebo None, když je vše vyplněné."""
    nejlepsi = None
    for r in range(N):
        for s in range(N):
            if mrizka[r][s] == 0:
                moznosti = kandidati(mrizka, r, s)
                if nejlepsi is None or len(moznosti) < len(nejlepsi[2]):
                    nejlepsi = (r, s, moznosti)
    return nejlepsi

Políčko s jediným kandidátem vyhraje vždy, pokud existuje. Pokud ne, vybere se políčko s nejméně možnostmi, a tam se hádá. Je to stejný postup, jaký používáš ručně.

4. Řešení s návratem

Funkce res vyplní jedno políčko a pak zavolá sama sebe na zbytek mřížky. Takové funkci se říká rekurzivní. Vrací True, když se podaří mřížku dovyplnit, a False při sporu.

Ukázka
def res(mrizka):
    """Doplní mřížku. Vrátí True, když se to povede, jinak False."""
    policko = najdi_policko(mrizka)
    if policko is None:
        return True                       # vše vyplněné: vyřešeno
    r, s, moznosti = policko
    if not moznosti:
        return False                      # spor: do políčka nejde nic
    for cislo in moznosti:
        mrizka[r][s] = cislo              # zkusíme číslici
        if res(mrizka):                   # a řešíme zbytek
            return True
        mrizka[r][s] = 0                  # nevyšlo to: smažeme a zkusíme další
    return False                          # žádná číslice nevyšla

Tři situace:

  • Žádné prázdné políčko: hotovo, vracíme True a to „probublá“ všemi vnořenými voláními až nahoru.
  • Prázdné políčko bez kandidátů: spor, vracíme False. Volající funkce smaže svoje políčko a zkusí další číslici.
  • Jinak zkoušíme kandidáty jednoho po druhém. U jediné možnosti cyklus proběhne jednou. Když nevyjde žádná, vracíme False o úroveň výš, tedy ještě dál zpátky.
Kde je zásobník?

U džbánů měl prohledávání do hloubky zásobník. Tady ho nevidíš, ale je tam: každé rozpracované volání res čeká, až se vnořené vrátí. Python si je ukládá do zásobníku volání. Návrat v backtrackingu je obyčejný návrat z funkce.

Celý program

Ve finální verzi program navíc vypisuje každý krok, počítá napsané číslice a políčka označuje písmenem a číslem. Ulož ho jako sudoku.py a spusť příkazem python sudoku.py.

sudoku.py
# Řešení sudoku prohledáváním s návratem (backtracking)

VYSKA, SIRKA = 2, 3          # rozměry jednoho čtverce: 2 × 3
N = VYSKA * SIRKA            # velikost mřížky: 6 × 6, číslice 1 až 6
SLOUPCE = "ABCDEFGHI"        # sloupce označujeme písmeny, řádky čísly

ZADANI = [                   # 0 znamená prázdné políčko
    [0, 0, 2, 3, 6, 5],
    [5, 6, 3, 1, 4, 2],
    [0, 0, 0, 4, 0, 6],
    [0, 0, 0, 0, 0, 1],
    [0, 3, 0, 0, 0, 4],
    [0, 2, 0, 0, 1, 3],
]

VYPISOVAT = True             # False = jen výsledek, bez jednotlivých kroků
kroku = 0                    # kolikrát jsme napsali číslici


def zprava(text):
    if VYPISOVAT:
        print(text)


def nazev(r, s):
    """Políčko v řádku r a sloupci s jako text, např. C4."""
    return SLOUPCE[s] + str(r + 1)


def kandidati(mrizka, r, s):
    """Číslice, které jde napsat do políčka (r, s) podle pravidel."""
    pouzite = set(mrizka[r])                            # řádek
    pouzite |= {mrizka[i][s] for i in range(N)}         # sloupec
    r0 = r // VYSKA * VYSKA                             # levý horní roh čtverce
    s0 = s // SIRKA * SIRKA
    for i in range(r0, r0 + VYSKA):                     # čtverec
        for j in range(s0, s0 + SIRKA):
            pouzite.add(mrizka[i][j])
    return [c for c in range(1, N + 1) if c not in pouzite]


def najdi_policko(mrizka):
    """Prázdné políčko s nejméně možnostmi, nebo None, když je vše vyplněné."""
    nejlepsi = None
    for r in range(N):
        for s in range(N):
            if mrizka[r][s] == 0:
                moznosti = kandidati(mrizka, r, s)
                if nejlepsi is None or len(moznosti) < len(nejlepsi[2]):
                    nejlepsi = (r, s, moznosti)
    return nejlepsi


def res(mrizka):
    """Doplní mřížku. Vrátí True, když se to povede, jinak False."""
    global kroku
    policko = najdi_policko(mrizka)
    if policko is None:
        return True                       # vše vyplněné: vyřešeno
    r, s, moznosti = policko
    if not moznosti:
        zprava(f"   slepá ulička: do {nazev(r, s)} nejde napsat nic")
        return False
    if len(moznosti) > 1:
        zprava(f"   volba v {nazev(r, s)}: možnosti {moznosti}")
    for cislo in moznosti:
        kroku += 1
        mrizka[r][s] = cislo
        zprava(f"{kroku:3}. {nazev(r, s)} = {cislo}"
               + ("" if len(moznosti) == 1 else f"   (zkouším {cislo} z {moznosti})"))
        if res(mrizka):
            return True
        mrizka[r][s] = 0                  # nevyšlo to: smažeme a zkusíme dál
        zprava(f"   zpět: mažu {nazev(r, s)}")
    return False


def vypis(mrizka):
    print("   " + " ".join(SLOUPCE[:N]))
    for r in range(N):
        print(f"{r + 1:2} " + " ".join(str(c) if c else "." for c in mrizka[r]))


mrizka = [radek[:] for radek in ZADANI]   # kopie, zadání zůstane beze změny
vypis(mrizka)
print()
if res(mrizka):
    print()
    vypis(mrizka)
    print("Napsaných číslic:", kroku)
else:
    print("Sudoku nemá řešení.")

Procvičení

Vyzkoušej

1. Spusť program pro příklad 1. Kolik číslic napíše a kolikrát musí hádat?

16 číslic, tedy přesně tolik, kolik je prázdných políček, a ani jednou nehádá. Ve výpisu není žádný řádek „volba“ ani „zpět“.

2. V příkladu 2 změň for cislo in moznosti: na for cislo in reversed(moznosti):. Co se stane?

Program zkouší kandidáty od největšího, takže v A1 zkusí nejdřív 4. To je správně, ke sporu nedojde a napíše jen 18 číslic místo 22. Měl štěstí. U jiného sudoku by mu obrácené pořadí naopak uškodilo.

3. Použij u příkladu 2 naivní výběr políčka (první prázdné). Kolik číslic program napíše?

4. Přidej do zadání příkladu 2 číslici 1 do políčka A1 (to byla špatná volba). Co program vypíše?

„Sudoku nemá řešení.“ Po třech napsaných číslicích (B1 = 4, B4 = 5, B3 = 1) narazí na spor v C3 a nemá kam se vrátit, protože nikde nehádal. Pravidla přitom zadání neporušuje: v řádku, sloupci ani čtverci se nic neopakuje. Že řešení nemá, se ukáže až hledáním.

5. Smaž ze zadání příkladu 2 číslici v políčku C1 (dvojku nahraď nulou). Kolik má sudoku řešení?

Sedm. Program to nepozná, protože skončí u prvního řešení. Na spočítání všech řešení potřebuješ funkci, která se po nalezení řešení nezastaví:

Počet řešení
def pocet_reseni(mrizka):
    policko = najdi_policko(mrizka)
    if policko is None:
        return 1                          # jedno vyplnění, jedno řešení
    r, s, moznosti = policko
    pocet = 0
    for cislo in moznosti:
        mrizka[r][s] = cislo
        pocet += pocet_reseni(mrizka)     # sečteme řešení všech větví
        mrizka[r][s] = 0
    return pocet

print(pocet_reseni([radek[:] for radek in ZADANI]))

Pořádné sudoku má právě jedno řešení. Tvůrci sudoku to kontrolují přesně takhle.

6. Kde v programu je „návrat“ z ručního postupu?

Řádek mrizka[r][s] = 0. Když vnořené volání vrátí False, políčko se smaže. Protože se to stane v každém vnořeném volání postupně, smaže se všechno od pokusu, stejně jako když na papíře gumuješ vše od zakroužkovaného čísla.
