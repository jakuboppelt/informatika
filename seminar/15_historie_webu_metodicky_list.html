Historie a funkce webu 90′

Seminář 90 minut pro maturanty. Žáci po hodině dokážou vyložit vznik a vývoj webu, rozlišit technologie na straně klienta a serveru, popsat cestu požadavku od prohlížeče k serveru a vysvětlit, jak web zpracovává data uživatelů. Hodinu vedeš podle prezentace, studenti mají studijní text.

Cíle hodiny

Žák:

  • vysvětlí rozdíl mezi internetem a webem,
  • popíše vznik webu v CERNu a zařadí do času klíčové prohlížeče a technologie,
  • porovná Web 1.0 a Web 2.0,
  • rozliší jazyky na straně klienta a serveru a uvede jejich úlohu,
  • popíše průběh načtení stránky od dotazu DNS po vykreslení,
  • porovná cookie, session a localStorage a zdůvodní požadavky GDPR.

Předpoklady a pomůcky

  • Žáci znají základy sítí (adresa IP, DNS, model klient–server) z otázky o počítačových sítích.
  • Prezentace „15 – Historie a funkce webu“ a studijní text k otázce.
  • Počítače s prohlížečem (stačí jeden do dvojice), projektor.

Aktivita: Co o mně web ví

Zadání. Dvojice si vybere jeden běžný web (zpravodajský server, e-shop, školní web) a pomocí nástrojů pro vývojáře v prohlížeči (klávesa F12) zjistí, jak web komunikuje a co si o návštěvníkovi ukládá.

Postup.

  1. Otevřete web v anonymním okně a nic nepotvrzujte. Na kartě Síť (Network) stránku znovu načtěte. Zapište počet požadavků, stavový kód prvního požadavku a alespoň tři různé typy stažených souborů (HTML, CSS, JavaScript, obrázek).
  2. Zjistěte, na kolik různých domén prohlížeč posílal požadavky. Které z nich nepatří navštívenému webu?
  3. Na kartě Aplikace (Application), případně Úložiště (Storage), prohlédněte cookies a localStorage. Zapište počet cookies před udělením souhlasu.
  4. Přijměte všechny cookies v liště a stránku načtěte znovu. Jak se změnil počet cookies a počet domén?
  5. Zhodnoťte cookie lištu: jde odmítnout stejně snadno jako přijmout?

Závěr, ke kterému mají žáci dojít. Jedna stránka znamená desítky požadavků HTTP na různé servery. Web je složen z HTML, CSS a JavaScriptu. Část cookies je nezbytná pro fungování, další slouží analytice a reklamě a pocházejí od třetích stran. Po udělení souhlasu jich výrazně přibude. Souhlas má být dobrovolný a odmítnutí stejně snadné jako přijetí – ne každý web to dodržuje.

Varianta bez počítačů. Učitel promítne nástroje pro vývojáře na jednom webu a žáci vyplňují záznamový list společně.

Časté chyby a miskoncepce

ChybaJak na ni reagovat
„Internet a web je totéž.“Nechat žáky vyjmenovat služby internetu, které web nejsou (e-mail, hry, videohovory). Internet je síť, web služba.
„HTML je programovací jazyk.“Zeptat se, zda v HTML jde zapsat podmínka nebo cyklus. HTML je značkovací jazyk, programuje se v JavaScriptu.
„Java a JavaScript jsou jeden jazyk.“Zdůraznit, že jde o dva nesouvisející jazyky s podobným názvem.
„Web vymyslel Bill Gates nebo Google.“Vrátit se k časové ose: Tim Berners-Lee, CERN, 1989–1991. Google vznikl až v roce 1998.
„Cookie je program nebo virus.“Ukázat cookie v nástrojích pro vývojáře: je to krátký text, dvojice název a hodnota. Sám nic nespouští.
„Anonymní režim mě na internetu skryje.“Vysvětlit, že pouze neukládá historii a cookies v počítači. Web i poskytovatel připojení návštěvu vidí dál.

Výstupní lístek

  1. Vysvětlete jednou větou rozdíl mezi internetem a webem.
  2. Uveďte dva jazyky, které běží v prohlížeči, a dva, které běží na serveru.
  3. Proč web potřebuje cookies, když je protokol HTTP bezstavový?

Co má zaznít u maturity

  • Na výbornou: Žák odliší internet od webu, popíše vznik webu (Berners-Lee, CERN, 1989–1991, HTML, URL, HTTP), vývoj prohlížečů včetně války prohlížečů a přechod od Webu 1.0 k Webu 2.0. Rozdělí technologie na klientské a serverové a u každé uvede úlohu, souvisle popíše cestu požadavku (DNS, HTTP, stavové kódy, vykreslení) a pojmy frontend a backend. Charakterizuje moderní web (responzivní design, webové aplikace, API, HTTPS). Porovná cookie, session a localStorage, vysvětlí cookies třetích stran a hlavní zásady GDPR.
  • Na dostatečnou: Žák ví, že web je služba internetu, zná Tima Bernerse-Leeho a přibližnou dobu vzniku, vyjmenuje HTML, CSS a JavaScript s jejich úlohou, uvede alespoň jeden serverový jazyk, s dopomocí popíše, že prohlížeč posílá požadavek a server odpovídá, a ví, k čemu slouží cookies.

Doplňující otázky zkoušejícího: Co znamená, že je HTTP bezstavový? Jaký je rozdíl mezi metodami GET a POST? Proč nestačí kontrolovat formulář jen v prohlížeči? Co přináší HTTPS oproti HTTP? Proč je výhodné oddělit obsah (HTML) od vzhledu (CSS)? Co je API a k čemu ho webová aplikace používá?
