Programování v Pythonu

Charakteristika jazyka, jeho zařazení, funkce a využití v praxi.

Co je Python

Python je vysokoúrovňový, interpretovaný, dynamicky typovaný programovací jazyk pro obecné použití. Navrhl ho Guido van Rossum, první verze vyšla v roce 1991. Název pochází z britské komediální skupiny Monty Python, nikoli od hada.

Dnes se používá řada Python 3 (od roku 2008). Python 2 už není podporován a s trojkou není zpětně kompatibilní.

Hlavní rysy jazyka:

  • Čitelnost. Bloky kódu se nevyznačují závorkami, ale odsazením. Odsazení je tedy součást syntaxe, ne jen úprava.
  • Interpret. Zdrojový kód se nepřekládá předem do strojového kódu. Interpret (nejčastěji CPython) ho přeloží do bajtkódu a ten vykonává virtuální stroj.
  • Dynamické typování. Typ nepatří proměnné, ale hodnotě. Proměnná je jen jméno, které na hodnotu odkazuje.
  • Automatická správa paměti. O uvolňování paměti se stará garbage collector.
  • Bohatá standardní knihovna a obrovský ekosystém balíčků (instalují se nástrojem pip z repozitáře PyPI).

Kategorizace: kam Python patří

Programovací jazyky se třídí podle několika hledisek. U maturity je dobré umět Python zařadit podle každého z nich a srovnat ho s C++.

Dynamické vs. statické typování. V Pythonu se typ kontroluje až za běhu, v C++ už při překladu. Chyba v typu se proto v Pythonu projeví, až když program dojde na daný řádek.

Silné vs. slabé typování. Python je silně typovaný: výraz "3" + 4 skončí chybou TypeError, jazyk sám tiše nepřevádí text na číslo.

Paradigmata. Procedurální styl skládá program z funkcí. Objektový styl sdružuje data a chování do tříd. Funkcionální styl pracuje s funkcemi jako s hodnotami (map, filter, lambda).

Typy se dělí na měnitelné (mutable: list, dict, set) a neměnné (immutable: int, float, str, tuple). Rozdíl je důležitý při předávání do funkcí.

Řízení toku programu

vek = int(input("Kolik ti je? "))

if vek >= 18:
    print("dospělý")
elif vek >= 15:
    print("mladistvý")
else:
    print("dítě")

for i in range(3):        # cyklus s daným počtem opakování
    print(i)              # 0, 1, 2

while vek < 18:           # cyklus s podmínkou
    vek += 1

Cyklus for v Pythonu prochází prvky kolekce nebo rozsahu (range). Příkaz break cyklus ukončí, continue přeskočí na další průchod.

Funkce

Funkce je pojmenovaný blok kódu, který řeší jednu dílčí úlohu a dá se volat opakovaně. Důvody, proč funkce používat: kód se neopakuje, program se dělí na menší srozumitelné části a jednotlivé části se dají samostatně testovat.

def obsah_obdelniku(a, b=1):
    """Vrátí obsah obdélníku o stranách a, b."""
    return a * b

print(obsah_obdelniku(3, 4))     # 12
print(obsah_obdelniku(5))        # 5, b má výchozí hodnotu
print(obsah_obdelniku(b=2, a=6)) # 12, pojmenované argumenty

Části funkce

  • Definice začíná klíčovým slovem def, následuje jméno, závorky s parametry a dvojtečka.
  • Parametr je jméno v definici, argument je konkrétní hodnota při volání.
  • Návratová hodnota se předává příkazem return. Funkce bez return vrací None.
  • Dokumentační řetězec (docstring) popisuje, co funkce dělá.

Druhy parametrů

  • Poziční: přiřazují se podle pořadí.
  • Pojmenované (keyword): přiřazují se podle jména, f(b=2, a=6).
  • S výchozí hodnotou: def f(a, b=1).
  • Proměnný počet: *args sbírá poziční argumenty do n-tice, **kwargs pojmenované do slovníku.

Rozsah platnosti proměnných

Proměnná vytvořená uvnitř funkce je lokální a po skončení funkce zaniká. Proměnná vytvořená mimo funkce je globální. Funkce může globální proměnnou číst; aby ji mohla přepsat, musí ji označit slovem global. Spoléhat na globální proměnné se nedoporučuje, protože funkce pak závisí na okolí a hůř se testuje.

Předávání argumentů

Python předává odkaz na objekt. Pokud funkce změní měnitelný objekt (například přidá prvek do seznamu), změna je vidět i venku. Neměnné hodnoty funkce změnit nemůže, jen si vytvoří novou.

def pridej(seznam):
    seznam.append(99)

cisla = [1, 2]
pridej(cisla)
print(cisla)    # [1, 2, 99]

Rekurze a lambda

def faktorial(n):
    if n <= 1:              # ukončovací podmínka
        return 1
    return n * faktorial(n - 1)

dvojnasobek = lambda x: x * 2
serazeno = sorted(["Petr", "Jo", "Alena"], key=lambda s: len(s))

Rekurzivní funkce musí mít ukončovací podmínku, jinak skončí chybou RecursionError.

Výhody: čitelná syntaxe, rychlý vývoj, obrovské množství knihoven, přenositelnost mezi operačními systémy, velká komunita.

Nevýhody: pomalejší běh než u kompilovaných jazyků, vyšší spotřeba paměti, chyby v typech se projeví až za běhu, omezený souběh vláken v CPythonu (GIL), malé uplatnění v mobilních aplikacích a hrách náročných na výkon.

V praxi se slabší výkon obchází tím, že výpočetně náročné části jsou napsané v C nebo C++ a Python je jen volá. Tak funguje například NumPy.

Shrnutí

Python je interpretovaný, dynamicky a silně typovaný multiparadigmatický jazyk s důrazem na čitelnost. Funkce se definují slovem def, přijímají parametry a hodnotu vracejí příkazem return. Funkce dělíme na vestavěné, knihovní a uživatelské, dále podle návratové hodnoty a na zvláštní druhy (lambda, rekurzivní, metody). Python se používá hlavně v datech, AI, webovém backendu a automatizaci; platí za to nižší rychlostí běhu.
