HTML a CSS

Značkovací a stylovací jazyk webu: stavba stránky, selektory, rozložení a využití

Šipky na klávesnici nebo tlačítka dole. Studijní text a metodický list jsou na rozcestníku.

Tři vrstvy webové stránky

HTML: obsahZnačkovací jazyk. Popisuje strukturu a význam obsahu: nadpisy, odstavce, odkazy, obrázky.
CSS: vzhledStylovací jazyk. Určuje barvy, písmo, rozměry a rozložení prvků.
JavaScript: chováníProgramovací jazyk. Reaguje na uživatele a mění stránku za běhu.
Hlavní myšlenka

HTML a CSS nejsou programovací jazyky.

Nemají proměnné v běžném smyslu, podmínky ani cykly. Popisují, co na stránce je a jak to vypadá, ne jak se má něco spočítat.

Historie a standardy

1991
Tim Berners-Lee v CERNu vytváří HTML jako jazyk pro sdílení dokumentů.
1996
První specifikace CSS odděluje vzhled od obsahu.
HTML5
Sémantické značky, audio, video a formulářové prvky bez pluginů.
CSS3
Moduly: flexbox, grid, animace, media queries.
Kdo to řídí
Standardy vydávají W3C a WHATWG, prohlížeče je postupně zavádějí.

Kostra HTML dokumentu

<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <title>Moje stránka</title>
  <link rel="stylesheet" href="styl.css">
</head>
<body>
  <h1>Nadpis</h1>
  <p>Odstavec s <a href="o-mne.html">odkazem</a>.</p>
</body>
</html>
  • DOCTYPE říká prohlížeči, že jde o HTML5.
  • head obsahuje informace o stránce, body její viditelný obsah.
  • Element tvoří počáteční značka, obsah a koncová značka.
  • Atribut upřesňuje element: href, src, lang, class.

Blokové a řádkové elementy

BlokovéZačínají na novém řádku a zabírají celou šířku rodiče. Příklady: div, p, h1, ul, section.
ŘádkovéZůstávají v řádku textu a jsou široké jen podle obsahu. Příklady: span, a, strong, img.

Pravidlo CSS

h1 {
  color: #14213D;
  font-size: 32px;
}

.karta {
  padding: 16px;
  border: 1px solid gray;
}

#menu a:hover {
  text-decoration: underline;
}
  • Pravidlo má selektor a blok deklarací ve složených závorkách.
  • Deklarace je dvojice vlastnost a hodnota oddělená dvojtečkou.
  • Selektor určuje, kterých elementů se pravidlo týká.

Kaskáda, specificita, dědičnost

Kaskáda
Platí-li pro element více pravidel, rozhoduje původ, specificita a nakonec pořadí.
Specificita
Sílu selektoru určuje jeho složení: id je silnější než třída, třída než typ.
Pořadí
Při stejné specificitě vyhrává pravidlo zapsané později.
Dědičnost
Některé vlastnosti, hlavně písmo a barva textu, přebírají potomci od rodiče.
Připojení stylů
Externí soubor, značka style v hlavičce nebo atribut style u elementu.

Box model

ObsahVlastní text nebo obrázek. Rozměr určují width a height.
PaddingVnitřní okraj mezi obsahem a rámečkem. Má barvu pozadí.
BorderRámeček kolem prvku: tloušťka, styl, barva.
MarginVnější okraj. Odděluje prvek od sousedů, je průhledný.

Rozložení stránky

Normální tokBlokové prvky pod sebou, řádkové vedle sebe. Výchozí chování.
FlexboxRozložení v jednom směru, do řádku nebo sloupce. Menu, karty, zarovnání.
GridDvourozměrná mřížka řádků a sloupců. Celé rozvržení stránky.
PozicováníVlastnost position: relative, absolute, fixed, sticky.
ResponzivitaMedia queries mění styly podle šířky displeje.
JednotkyAbsolutní px, relativní %, em, rem, vw a vh.

Využití

Webové stránkyKaždý web tvoří HTML a CSS, ať ho generuje cokoli.

E-mailyFormátované zprávy a newslettery.
Desktop a mobilAplikace postavené na webových technologiích, například Electron.
DokumentaceNápovědy, e-knihy ve formátu EPUB, export do PDF.
