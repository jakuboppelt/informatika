Objektově orientované programování a datové struktury

Objekt, třída, dědičnost, polymorfismus a datové struktury pole, zásobník, fronta a spojový seznam.

Co je objektově orientované programování

Objektově orientované programování (OOP) je způsob psaní programů, kdy se program skládá z objektů. Objekt spojuje dohromady data (jeho stav) a funkce, které s nimi pracují (jeho chování). Program pak tvoří objekty, které si navzájem volají metody.

Alternativou je procedurální programování, kde se program skládá z funkcí a data jsou od nich oddělená. OOP se hodí pro větší programy, protože je rozděluje na samostatné části s jasnou odpovědností. Je v jazycích jako Python, Java, C++ nebo C#.

Třída a objekt

Třída je šablona nebo návrh. Popisuje, jaké atributy a metody budou mít objekty daného druhu. Objekt (také instance) je konkrétní výtvor třídy. Z jedné třídy lze vytvořit libovolně mnoho objektů a každý má vlastní hodnoty atributů.

  • Atribut je proměnná patřící objektu a drží jeho stav, například jméno nebo věk.
  • Metoda je funkce patřící objektu a popisuje, co objekt umí.
  • Konstruktor je zvláštní metoda, která se spustí při vytvoření objektu a nastaví počáteční stav. V Pythonu se jmenuje __init__.
  • self je odkaz na objekt, nad kterým se metoda právě volá. Python ho předává jako první parametr každé metody.
class Zvire:
    def __init__(self, jmeno):
        self.jmeno = jmeno

    def ozvi_se(self):
        print(self.jmeno + " vydává zvuk")

azor = Zvire("Azor")
micka = Zvire("Micka")
azor.ozvi_se()

Objekty azor a micka jsou dvě samostatné instance téže třídy. Změna atributu jednoho druhý neovlivní.

Čtyři principy OOP

Zapouzdření

Data a metody, které s nimi pracují, jsou pohromadě v objektu. Vnitřní stav se před okolím skrývá a mění se jen přes metody, takže objekt může hlídat, aby zůstal v platném stavu (například věk nikdy nebude záporný). Mnoho jazyků má pro skrytí klíčová slova private a public. Python skrytí jen naznačuje názvem: atribut začínající podtržítkem (_vek) je určený jen pro vnitřní použití třídy.

Abstrakce

Objekt ukazuje navenek jen to podstatné. Kdo volá metodu, nemusí vědět, jak uvnitř funguje. Řidič používá pedály a volant, nemusí znát stavbu motoru.

Dědičnost

Třída může dědit od jiné třídy. Podtřída (potomek) převezme atributy a metody nadtřídy (předka) a může je rozšířit nebo změnit. Dědičnost vyjadřuje vztah „je“: pes je zvíře. Společný kód se tak píše jednou, v nadtřídě.

class Pes(Zvire):
    def ozvi_se(self):
        print(self.jmeno + ": haf")

class Kocka(Zvire):
    def ozvi_se(self):
        print(self.jmeno + ": mnau")

Třída Pes zdědila konstruktor od třídy Zvire a metodu ozvi_se přepsala (anglicky overriding): má stejné jméno, ale jiné chování.

Polymorfismus

Polymorfismus (mnohotvarost) znamená, že stejné volání se chová různě podle toho, jakého typu objekt je.

for z in [Pes("Azor"), Kocka("Micka"), Zvire("Neznámé")]:
    z.ozvi_se()

Cyklus volá na každém objektu stejnou metodu, ale pes zaštěká, kočka zamňouká a obecné zvíře vydá obecný zvuk. Kód, který s objekty pracuje, nemusí rozlišovat jejich druh. Díky tomu lze přidat novou podtřídu, aniž by se musel měnit stávající kód.

Související pojmy

PojemVýznam
Přepsání metody (overriding)podtřída nahradí metodu zděděnou od nadtřídy
Přetížení (overloading)více metod stejného jména s různými parametry; mají ho C++ a Java, Python ne
Abstraktní třídatřída, ze které se nevytváří objekty, jen se od ní dědí; předepisuje metody, které musí podtřídy dodat

Kdy dědičnost a kdy skládání? Dědičnost se hodí, když opravdu platí „je“. Když platí „má“, je lepší skládání, protože je volnější a lépe se mění.

Datové struktury

Datová struktura je způsob, jak se data uspořádají v paměti, aby se s nimi dalo efektivně pracovat. Každá struktura je rychlá v něčem jiném. Rychlost se vyjadřuje složitostí (zápis O): O(1) znamená, že operace trvá stejně dlouho bez ohledu na množství dat, O(n) že trvá úměrně počtu prvků.

StrukturaPrincipTypické operaceSložitost
Polesouvislý blok paměti, prvky stejného typu, index od 0čtení a zápis podle indexuO(1); vložení doprostřed O(n)
ZásobníkLIFO: poslední dovnitř, první venpush, pop, peekO(1)
FrontaFIFO: první dovnitř, první venenqueue, dequeueO(1)
Spojový seznamuzly s hodnotou a odkazem na další uzelvložení a smazání na známém místěO(1); hledání O(n)

Pole

Pole je souvislý blok paměti, ve kterém leží prvky stejného typu těsně za sebou. Adresa prvku se vypočte z indexu, proto je čtení i zápis podle indexu okamžité (O(1)). Indexuje se od nuly.

Nevýhodou je vložení nebo smazání uprostřed: prvky za daným místem se musí posunout, což trvá úměrně jejich počtu (O(n)). V jazycích C a C++ má pole pevnou velikost. Seznam list v Pythonu je dynamické pole: při zaplnění se přesune do většího bloku paměti. Přidání na konec je proto v průměru rychlé.

Zásobník

Zásobník (anglicky stack) funguje principem LIFO, last in, first out: poslední vložený prvek se odebere jako první. Představ si hromadu talířů: přidává se i bere shora. Základní operace jsou push (vložit na vrchol), pop (odebrat z vrcholu) a peek (podívat se na vrchol bez odebrání).

Použití: tlačítko zpět a vrácení změn (undo), zásobník volání funkcí v programu, kontrola párových závorek, vyhodnocování výrazů.

zasobnik = []
zasobnik.append(1)
zasobnik.append(2)
print(zasobnik.pop())      # 2

Fronta

Fronta (anglicky queue) funguje principem FIFO, first in, first out: první vložený prvek se odebere jako první, jako řada u pokladny. Základní operace jsou enqueue (zařadit na konec) a dequeue (odebrat ze začátku).

Použití: tisk dokumentů, fronty úloh a zpráv, procházení grafu do šířky.

from collections import deque
fronta = deque()
fronta.append(1)
fronta.append(2)
print(fronta.popleft())    # 1

V Pythonu se pro frontu používá deque. Odebírání prvního prvku ze seznamu přes pop(0) je pomalé, protože se všechny ostatní prvky posouvají (O(n)).

Spojový seznam

Spojový seznam se skládá z uzlů. Každý uzel drží hodnotu a odkaz na další uzel, poslední uzel ukazuje na nic (None). Uzly mohou ležet v paměti kdekoli, spojují je jen odkazy.

class Uzel:
    def __init__(self, hodnota):
        self.hodnota = hodnota
        self.dalsi = None

a = Uzel(1)
b = Uzel(2)
c = Uzel(3)
a.dalsi = b
b.dalsi = c

u = a
while u is not None:
    print(u.hodnota)
    u = u.dalsi

Druhy: jednosměrný seznam má v uzlu jen odkaz na následníka, obousměrný i na předchůdce (jde procházet oběma směry, ale zabere víc paměti), u kruhového seznamu poslední uzel ukazuje zpět na první.

Výhoda: vložení nebo smazání uzlu na známém místě je rychlé (O(1)), nic se neposouvá, jen se přepojí odkazy. Nevýhoda: k n-tému prvku se musí projít všechny předchozí (O(n)) a každý uzel potřebuje paměť navíc na odkaz.

Porovnání pole a spojového seznamu

PoleSpojový seznam
Přístup k n-tému prvkuO(1)O(n)
Vložení doprostředO(n), posouvá seO(1) na známém místě
Paměťsouvislá, bez odkazůrozptýlená, odkaz u každého uzlu

Zásobník i frontu lze postavit nad polem i nad spojovým seznamem. Datové struktury jsou tak samy příkladem OOP: každá je třída s daty a metodami.

Shrnutí

OOP skládá program z objektů, které mají atributy a metody. Třída je šablona, objekt její instance. Základní principy jsou zapouzdření, abstrakce, dědičnost a polymorfismus. Datové struktury určují uložení dat: pole dává rychlý přístup podle indexu, zásobník pracuje podle LIFO, fronta podle FIFO a spojový seznam dovoluje rychlé vkládání a mazání na známém místě.
