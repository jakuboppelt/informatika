Objektově orientované programování a datové struktury

Objekt, třída, dědičnost, polymorfismus a datové struktury pole, zásobník, fronta a spojový seznam

Šipky na klávesnici nebo tlačítka dole. Studijní text a metodický list jsou na rozcestníku.

Hlavní myšlenka

Objektově orientované programování skládá program z objektů, které mají data i chování.

Datové struktury určují, jak se data uspořádají v paměti, aby se dala rychle číst, vkládat a rušit.

Základní pojmy OOP

TřídaŠablona nebo návrh. Popisuje, jaká data a jaké metody budou mít objekty.
ObjektKonkrétní výtvor třídy, také instance. Z jedné třídy jich vznikne libovolně mnoho.
AtributProměnná patřící objektu. Drží jeho stav, třeba jméno nebo věk.
MetodaFunkce patřící objektu. Popisuje, co objekt umí.
KonstruktorMetoda, která se spustí při vzniku objektu a nastaví počáteční stav. V Pythonu __init__.
selfOdkaz na objekt, nad kterým se metoda právě volá.

Třída a objekt v Pythonu

class Zvire:
    def __init__(self, jmeno):
        self.jmeno = jmeno

    def ozvi_se(self):
        print(self.jmeno + " vydává zvuk")

azor = Zvire("Azor")
micka = Zvire("Micka")
azor.ozvi_se()
  • class zavádí třídu, jméno třídy se píše velkým písmenem.
  • __init__ je konstruktor, nastaví atribut jmeno.
  • Zvire("Azor") vytvoří nový objekt, azor a micka jsou dvě samostatné instance.
  • Metodu voláme přes tečku: azor.ozvi_se().

Čtyři principy OOP

Zapouzdření
Data a metody jsou pohromadě v objektu. Vnitřek se před okolím skrývá a mění se jen přes metody. V Pythonu se skrytí vyznačuje podtržítkem, _vek.
Abstrakce
Objekt ukáže jen to podstatné. Kdo volá metodu, nemusí vědět, jak uvnitř funguje.
Dědičnost
Podtřída převezme atributy a metody nadtřídy a může je rozšířit nebo změnit. Vyjadřuje vztah „je“: pes je zvíře.
Polymorfismus
Stejné volání se chová podle typu objektu různě. Na zvířeti zavolám ozvi_se() a pes zaštěká, kočka zamňouká.

Dědičnost a polymorfismus

class Pes(Zvire):
    def ozvi_se(self):
        print(self.jmeno + ": haf")

class Kocka(Zvire):
    def ozvi_se(self):
        print(self.jmeno + ": mnau")

for z in [Pes("Azor"), Kocka("Micka"), Zvire("Neznámé")]:
    z.ozvi_se()
  • Pes(Zvire) znamená, že Pes dědí od třídy Zvire, včetně __init__.
  • Metoda ozvi_se se v podtřídách přepisuje (overriding).
  • Cyklus volá stejnou metodu na třech různých objektech.
  • Každý objekt odpoví po svém. To je polymorfismus.

Datové struktury: přehled

Pole

Uložení
Prvky leží v paměti těsně za sebou. Adresa prvku se vypočte z indexu, proto je čtení okamžité.
Velikost
V jazyce C++ je pole pevně dané. Seznam list v Pythonu je dynamické pole, které se podle potřeby zvětšuje.
Vložení doprostřed
Prvky za místem se musí posunout, trvá úměrně počtu prvků: O(n).
Použití
Tabulky hodnot, obrázek jako pole pixelů, základ pro další struktury.

Zásobník a fronta

zasobnik = []
zasobnik.append(1)
zasobnik.append(2)
print(zasobnik.pop())      # 2, poslední dovnitř

from collections import deque
fronta = deque()
fronta.append(1)
fronta.append(2)
print(fronta.popleft())    # 1, první dovnitř
  • Zásobník jako talíře na hromadě: bereme vždy ten nahoře. LIFO.
  • Seznam v Pythonu stačí: append vloží na konec, pop odebere z konce.
  • Fronta jako řada u pokladny: obsluhujeme toho, kdo čeká nejdéle. FIFO.
  • Pro frontu se používá deque. Odebrání první položky ze seznamu přes pop(0) je pomalé, O(n).

Spojový seznam

class Uzel:
    def __init__(self, hodnota):
        self.hodnota = hodnota
        self.dalsi = None

a = Uzel(1)
b = Uzel(2)
c = Uzel(3)
a.dalsi = b
b.dalsi = c

u = a
while u is not None:
    print(u.hodnota)
    u = u.dalsi
  • Uzel drží hodnotu a odkaz na další uzel. Poslední uzel odkazuje na None.
  • Uzly mohou být v paměti kdekoli, spojují je odkazy.
  • Průchod začíná u prvního uzlu a postupuje po odkazech.
  • Seznam ukazuje, že datovou strukturu lze postavit z objektů.

Spojový seznam: vlastnosti

Jednosměrný
Každý uzel zná jen následníka. Procházet jde jen dopředu.
Obousměrný
Uzel zná následníka i předchůdce. Jde procházet oběma směry, ale zabere víc paměti.
Výhoda
Vložení a smazání uzlu na známém místě je rychlé. Nic se neposouvá, jen se přepojí odkazy.
Nevýhoda
K n-tému prvku se musí projít všechny předchozí, O(n). Každý uzel navíc zabírá paměť na odkaz.
