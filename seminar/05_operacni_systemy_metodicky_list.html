Operační systémy 90′

Seminář 90 minut pro maturanty. Žáci po hodině vysvětlí funkce operačního systému, popíšou vývoj od MS-DOS po dnešní Windows a srovnají Windows, Linux a macOS. Hodinu vedeš podle prezentace, studenti mají studijní text.

Cíle hodiny

Žák:

  • definuje operační systém a vysvětlí jeho funkce,
  • popíše stavbu systému (jádro, ovladače, shell),
  • charakterizuje MS-DOS a vysvětlí, čím se liší od moderních systémů,
  • popíše dvě vývojové řady Windows,
  • charakterizuje Linux a macOS a srovná je s Windows.

Předpoklady a pomůcky

  • Žáci jsou běžnými uživateli alespoň jednoho systému.
  • Prezentace „05 – Operační systémy“, studijní text.
  • Emulátor DOSBox nebo online emulátor MS-DOS, počítač či virtuální stroj s Linuxem, Správce úloh ve Windows.

Aktivita: úkoly v MS-DOS

  1. Vypište obsah složky (dir).
  2. Vytvořte složku SKOLA (md SKOLA) a přejděte do ní (cd SKOLA).
  3. Zkuste vytvořit soubor s názvem delším než osm znaků. Co se stane?
  4. Zkuste spustit dva programy současně. Jde to?

Závěr, ke kterému mají žáci dojít: systém je jednoúlohový, textový a názvy souborů mají tvar 8.3.

Aktivita: časová osa Windows

Kartičky: Windows 1.0, 3.1, 95, 98, NT 3.1, 2000, XP, Vista, 7, 8, 10, 11 a kartičky s událostmi (nabídka Start, NTFS, spojení řad, dlaždice, TPM). Skupiny je řadí do dvou rovnoběžných řad. Kontrolní otázka: proč je Windows XP zlomová verze?

Časté chyby a miskoncepce

ChybaJak na ni reagovat
„Operační systém je to, co vidím na ploše.“Plocha je jen rozhraní. Ukázat server bez grafiky.
„Práce v příkazovém řádku Windows je MS-DOS.“Příkazový řádek je program v moderních Windows, MS-DOS byl samostatný systém.
„Linux je jeden systém.“Linux je jádro, systémem je distribuce.
„Android nemá s Linuxem nic společného.“Android používá jádro Linuxu.
„macOS je úplně jiný svět než Linux.“Oba vycházejí z UNIXu, terminál se chová podobně.
Zaměňování pořadí verzí Windows.Pomůcka: dvě řady, které se spojí v XP.

Výstupní lístek

  1. Uveďte tři funkce operačního systému.
  2. Čím se MS-DOS liší od Windows 11? Uveďte dva rozdíly.
  3. Proč na serverech převažuje Linux?

Co má zaznít u maturity

  • Na výbornou: definice a funkce OS, stavba a typy jader, historie od dávkového zpracování přes UNIX k osobním počítačům, charakteristika MS-DOS, obě řady Windows s klíčovými verzemi, Linux (Torvalds, GPL, distribuce, využití), macOS (unixový základ, přechody procesorů), srovnání podle více hledisek.
  • Na dostatečnou: žák ví, k čemu OS slouží, jmenuje hlavní systémy, ví, že MS-DOS byl textový, a uvede základní rozdíl mezi Windows a Linuxem.

Doplňující otázky zkoušejícího: Co je ovladač? Co je multitasking? Jaký souborový systém používá váš počítač? Co znamená open source?
