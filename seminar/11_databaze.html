Databáze a základy SQL

Druhy databází, tabulky a vztahy mezi nimi, klíče, datové typy a základní příkazy SQL. Všechno na jedné malé školní databázi, kterou si pak postavíš na vlastním počítači.

Praktická ukázka a studijní text jsou na rozcestníku vedle prezentace.

Pojmy

Databáze, SŘBD a databázový systém

Databáze je uspořádaná sbírka dat uložených podle pevných pravidel.

SŘBD, systém řízení báze dat (anglicky DBMS), je program, který databázi spravuje: ukládá, hlídá pravidla, vyřizuje dotazy a řídí přístup.

Databázový systém = databáze + SŘBD. Aplikace se nikdy nehrabe v souborech přímo, ptá se SŘBD.

SQL

      
Jazyk, kterým se s databází mluví

      
SQL (Structured Query Language) vznikl v IBM v roce 1974 pod jménem SEQUEL. Je deklarativní: řekneš, co chceš dostat, a databáze sama vymyslí, jak to najít. Standard ISO/IEC 9075, poslední vydání SQL:2023.

      
SkupinaK čemuPříkazy

        
DDL definice datvytvořit a měnit strukturuCREATE, ALTER, DROP

        
DML manipulace s datyvkládat, měnit, mazat řádkyINSERT, UPDATE, DELETE

        
DQL dotazyčíst dataSELECT

        
DCL řízení přístupupráva uživatelůGRANT, REVOKE

        
TCL transakcepotvrdit, nebo vrátit změnyBEGIN, COMMIT, ROLLBACK

      

      
Velikost písmen u příkazů nerozhoduje. Klíčová slova se píšou velkými písmeny, aby byla v dotazu dobře vidět.

    


    
    

      
DDL

      
CREATE TABLE: postav tabulku

      


CREATE TABLE studenti (
  id        INTEGER PRIMARY KEY,
  jmeno     VARCHAR(40) NOT NULL,
  prijmeni  VARCHAR(40) NOT NULL,
  narozen   DATE,
  email     VARCHAR(80) UNIQUE,
  trida_id  INTEGER NOT NULL
            REFERENCES tridy(id)
);

        

          
Každý řádek = jeden sloupec: název, typ a omezení.

          
    
            
  • PRIMARY KEY primární klíč
    • 
            
  • NOT NULL hodnota je povinná
    • 
            
  • UNIQUE hodnota se nesmí opakovat
    • 
            
  • REFERENCES cizí klíč do jiné tabulky
    • 
            
  • CHECK (…) vlastní podmínka, třeba známka 1 až 5
    • 
          

          
Strukturu jde změnit: ALTER TABLE studenti ADD COLUMN telefon VARCHAR(20); a smazat i s daty: DROP TABLE studenti;

        

      

    


    
    

      
DML

      
Vložit, změnit, smazat


INSERT INTO studenti (jmeno, prijmeni, narozen, trida_id)
VALUES ('Petr', 'Beneš', '2010-04-04', 1);

UPDATE studenti
SET email = 'petr.benes@skola.example'
WHERE prijmeni = 'Beneš';

DELETE FROM studenti
WHERE prijmeni = 'Beneš';

      
Bez WHERE platí UPDATE a DELETE pro všechny řádky tabulky. DELETE FROM studenti; smaže celou školu. Proto si podmínku nejdřív vyzkoušej v SELECT.

      
Texty a data jsou v jednoduchých apostrofech, čísla bez nich. Datum se píše ve tvaru rok-měsíc-den.

Transakce

      
Všechno, nebo nic

      


BEGIN;
UPDATE ucty SET zustatek = zustatek - 500
  WHERE id = 1;   -- Adam posílá
UPDATE ucty SET zustatek = zustatek + 500
  WHERE id = 2;   -- Eliška dostává
COMMIT;

        
Kdyby server spadl mezi oběma příkazy, peníze by zmizely. Transakce spojí příkazy do jednoho celku: buď proběhnou všechny (COMMIT), nebo žádný (ROLLBACK).

      

      

      

    


    
    

      
Bezpečnost

      
Když aplikace skládá SQL z toho, co napíše uživatel

      
Přihlašovací formulář, který vloží text z pole přímo do dotazu, dovolí útočníkovi změnit význam dotazu. Tomu se říká SQL injection a pořád patří k nejčastějším chybám webových aplikací.


-- špatně: text od uživatele se přilepí do příkazu
dotaz = "SELECT * FROM uzivatele WHERE jmeno = '" + jmeno + "'"

-- správně: parametrizovaný dotaz, hodnota jde zvlášť
con.execute("SELECT * FROM uzivatele WHERE jmeno = ?", (jmeno,))

      
Obrana je jednoduchá: nikdy neskládat SQL z textu od uživatele a používat parametrizované dotazy. Skutečné případy jsou v prezentaci Úniky a útoky.
