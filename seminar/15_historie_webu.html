Hlavní myšlenka

Web není internet. Internet je síť, web je jedna ze služeb, které po ní běží.

Dalšími službami internetu jsou třeba e-mail, přenos souborů nebo videohovory.

Vznik webu v CERNu

1989
Tim Berners-Lee navrhuje v CERNu systém propojených dokumentů pro sdílení informací mezi vědci.
1990
Vzniká první webový server a první prohlížeč s názvem WorldWideWeb, který stránky uměl i upravovat.
1991
Web se otevírá veřejnosti. První stránka info.cern.ch vysvětluje, co je web a jak ho používat.
1993
CERN uvolňuje technologii webu zdarma pro všechny. Díky tomu se web rychle rozšířil.
1994
Vzniká konsorcium W3C, které pod vedením Bernerse-Leeho vydává webové standardy.

Web 1.0 a Web 2.0

Web 1.0Statické stránky, které se jen čtou. Obsah tvoří autor webu, návštěvník je pasivní čtenář. Stránky jsou hotové soubory HTML uložené na serveru. Typicky osobní stránky a katalogy odkazů v devadesátých letech.
Web 2.0Interaktivní web zhruba od roku 2004. Obsah tvoří sami uživatelé: blogy, Wikipedie, YouTube, sociální sítě. Stránky se skládají dynamicky z databáze a mění se bez opětovného načtení díky technice AJAX.

Co se stane po zadání adresy

1. DNS
Prohlížeč zjistí, jaká adresa IP patří k doménovému jménu.
2. Spojení
Naváže spojení se serverem, u HTTPS navíc šifrované.
3. Požadavek
Pošle požadavek HTTP, nejčastěji metodou GET na konkrétní adresu URL.
4. Odpověď
Server vrátí stavový kód, například 200 nebo 404, a obsah stránky.
5. Vykreslení
Prohlížeč dotáhne styly, skripty a obrázky a stránku zobrazí.

Požadavek a odpověď HTTP

GET /clanky/web.html HTTP/1.1
Host: www.example.com
Cookie: session=a81f

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Set-Cookie: session=a81f; Secure

<!DOCTYPE html>
<html> ... </html>
  • Model klient–server: nahoře požadavek prohlížeče, dole odpověď serveru.
  • HTTP je bezstavový: server si mezi požadavky nic nepamatuje.
  • Proto se uživatel rozpoznává podle cookie posílané s každým požadavkem.
  • Stavové kódy: 200 v pořádku, 404 nenalezeno, 500 chyba serveru.

Sledování, analytika a GDPR

Analytika
Web měří návštěvnost: odkud lidé přišli, co si prohlíželi a jak dlouho.
Cookie třetí strany
Ukládá ji jiná doména než navštívený web. Umožňuje sledovat uživatele napříč weby.
GDPR
Nařízení EU účinné od roku 2018. Osobní údaje lze zpracovávat jen s právním důvodem.
Souhlas s cookies
Nezbytné cookies souhlas nepotřebují, analytické a reklamní ano. Odmítnout musí jít snadno.
Práva uživatele
Právo na přístup k údajům, na opravu, výmaz a přenos údajů.
