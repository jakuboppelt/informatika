Cvičení: HTML a CSS v praxi </>

Deset krátkých úkolů. Každý má vlastní editor: nahoře píšeš kód, pod ním hned vidíš výsledek. Nic se neinstaluje a nic se nikam neodesílá.

Úkolů9 + 1 bonus, od nejlehčího
Časzhruba 40 minut
Když se zaseknešnejdřív Nápověda, až potom Řešení

Jak pracovat

  • Úkoly dělej popořadě, každý navazuje na předchozí.
  • Výsledek se mění, jak píšeš. Když se něco rozbije, Ctrl + Z vrátí poslední změnu a tlačítko Začít znovu vrátí celý úkol na začátek.
  • Řešení si otevři až po vlastním pokusu. Je jen jedno z možných, tvoje může vypadat jinak a být správně.
  • Všechno potřebné najdeš ve studijním textu.
Neuloží se

Po zavření nebo obnovení stránky se tvůj kód smaže. Co si chceš nechat, zkopíruj si.

HTML

1 Najdi a oprav chyby

3 min

Stránka pod editorem vypadá divně: půlka textu je tučná a obrázek nemá popis. V kódu jsou tři chyby. Najdi je a oprav.

Nápověda

Hledej neuzavřenou značku, značky, které se kříží, a obrázek bez atributu, který čte čtečka pro nevidomé.

Řešení
<h1>Můj oblíbený hrad</h1>
<p>Karlštejn založil <strong>Karel IV.</strong> v roce 1348.</p>
<p>Je to <em>jeden z <strong>nejnavštěvovanějších</strong></em> hradů.</p>
<img src="https://picsum.photos/300/150" alt="Fotografie hradu">

1) Chyběla koncová značka </strong>. 2) Značky se křížily: co se otevře poslední (strong), musí se zavřít první. 3) Obrázku chyběl alt.

2 Doplň kostru

3 min

Kód funguje, ale chybí mu kostra. Doplň DOCTYPE, html s jazykem, head s kódováním a názvem stránky a body.

Nápověda

Pořadí: DOCTYPE → html → head (meta charset, title) → body. Obsah stránky patří do body.

Řešení
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <title>Moje stránka</title>
</head>
<body>
  <h1>Ahoj</h1>
  <p>Tohle je stránka bez kostry.</p>
</body>
</html>

Vzhled se nezmění, prohlížeč je tolerantní. Bez meta charset by se ale mohla rozbít čeština a bez title nemá stránka název v záložce.

3 Seznam a odkazy

4 min

Z obyčejného textu udělej nečíslovaný seznam tří předmětů. Pod něj přidej odkaz na https://cs.wikipedia.org s textem „Wikipedie“, který se otevře v nové záložce.

Nápověda

Seznam: ul obaluje, každá položka je li. Odkaz: a s atributy href a target="_blank".

Řešení
<h2>Moje oblíbené předměty</h2>
<ul>
  <li>Informatika</li>
  <li>Matematika</li>
  <li>Fyzika</li>
</ul>
<a href="https://cs.wikipedia.org" target="_blank">Wikipedie</a>

ul je seznam s odrážkami, ol by byl číslovaný. Každá položka musí být v li uvnitř seznamu.

4 Postav tabulku

5 min

Převeď rozvrh na tabulku: záhlaví Den | Předmět | Učebna a tři řádky dat. Záhlaví dej do thead a buňky th, data do tbody.

Nápověda

Řádek je tr. Buňka záhlaví th, buňka dat td. Atribut border="1" na table zatím nahradí CSS, ať tabulku vidíš.

Řešení
<table border="1">
  <thead>
    <tr><th>Den</th><th>Předmět</th><th>Učebna</th></tr>
  </thead>
  <tbody>
    <tr><td>Pondělí</td><td>Informatika</td><td>U12</td></tr>
    <tr><td>Úterý</td><td>Matematika</td><td>204</td></tr>
    <tr><td>Středa</td><td>Fyzika</td><td>Laboratoř</td></tr>
  </tbody>
</table>

Tabulky jsou na data, ne na rozložení stránky. th prohlížeč sám zobrazí tučně a na střed.

CSS

5 První pravidla

4 min

V <style> napiš pravidla tak, aby: celá stránka měla písmo Arial a světle šedé pozadí #f2f2f2, nadpis byl tmavě modrý (navy) a na střed.

Nápověda

Selektor body pro celou stránku, h1 pro nadpis. Vlastnosti font-family, background, color, text-align.

Řešení
<style>
  body {
    font-family: Arial, sans-serif;
    background: #f2f2f2;
  }
  h1 {
    color: navy;
    text-align: center;
  }
</style>

Písmo stačí nastavit na body, zdědí ho všechny prvky uvnitř. Za čárkou je záložní písmo pro případ, že Arial chybí.

6 Třída a ID

4 min

Zvýrazni jen druhý a čtvrtý odstavec žlutým pozadím (použij třídu). Poslední odstavec udělej červeně a kurzívou (použij ID). Ostatní odstavce se nesmí změnit.

Nápověda

V HTML: class="…" a id="…". V CSS: třída s tečkou, ID s mřížkou.

Řešení
<style>
  .zvyrazneny { background: yellow; }
  #posledni   { color: red; font-style: italic; }
</style>

<p>První odstavec.</p>
<p class="zvyrazneny">Druhý odstavec.</p>
<p>Třetí odstavec.</p>
<p class="zvyrazneny">Čtvrtý odstavec.</p>
<p id="posledni">Poslední odstavec.</p>

Třídu může mít víc prvků, ID jen jeden. Proto je třída na dva odstavce a ID na jeden.

7 Kdo vyhraje?

4 min

Nejdřív bez spouštění tipni, jakou barvu bude mít text. Pak klikni na Ukázat výsledek. Potom uprav jen CSS tak, aby byl text modrý, a nepoužij !important.

Nápověda

Specificita: ID › třída › prvek. Aby vyhrála modrá, musí mít její selektor vyšší specificitu než ten se zelenou.

Řešení
<style>
  #zprava           { color: green; }
  #zprava.dulezita  { color: blue; }   /* ID + třída = 1-1-0 > 1-0-0 */
  p                 { color: red; }
</style>

Text je zelený, protože ID (1-0-0) přebije třídu (0-1-0) i prvek (0-0-1), bez ohledu na pořadí. Modrá vyhraje, když jí dáš selektor se stejným ID a navíc třídou. Jiné řešení: smazat pravidlo s ID.

8 Krabice přesně na míru

5 min

Krabice má mít padding: 20px a rámeček 5px, ale celková šířka na obrazovce má být přesně 300 px, stejně jako šedý pruh nad ní. Nastav width. Pak zkus druhý způsob s box-sizing.

Nápověda

Celková šířka = width + 2 · padding + 2 · border. Nebo box-sizing: border-box, pak width zahrnuje padding i rámeček.

Řešení
.krabice {
  padding: 20px;
  border: 5px solid navy;
  width: 250px;   /* 250 + 2·20 + 2·5 = 300 */
}

/* nebo: */
.krabice {
  box-sizing: border-box;
  padding: 20px;
  border: 5px solid navy;
  width: 300px;
}

Výchozí content-box přičítá padding a rámeček k šířce. border-box je do ní započítá, proto se mu v praxi dává přednost.

9 Karty vedle sebe

5 min

Postav tři karty vedle sebe s mezerou 16 px a vycentruj je na stránce. Použij Flexbox na prvek, který karty obaluje.

Nápověda

display: flex dáváš rodiči (.rada), ne kartám. Mezera: gap. Na střed: justify-content: center.

Řešení
.rada {
  display: flex;
  gap: 16px;
  justify-content: center;
}

Flexbox se nastavuje rodiči a ten pak rozmisťuje své děti. Zkus i space-between nebo flex-direction: column.

Bonus

10 Na mobilu pod sebou

4 min

Vezmi karty z minulého úkolu. Přidej media query, aby na obrazovce užší než 500 px byly karty pod sebou. Ověř to přepínačem šířky náhledu (320 px a 700 px).

Nápověda

@media (max-width: 500px) { … } a uvnitř pro .rada změň flex-direction.

Řešení
@media (max-width: 500px) {
  .rada {
    flex-direction: column;
    align-items: center;
  }
}

Media query platí jen za podmínky. Tady se pravidla uvnitř uplatní, jen když je okno užší než 500 px. Takhle se dělá responzivní web.
