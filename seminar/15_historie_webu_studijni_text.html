Historie a funkce webu

Od první stránky v CERNu k webovým aplikacím: jazyky, vývoj, moderní web a zpracování uživatelských dat.

Internet a web

Web není totéž co internet. Internet je celosvětová síť propojených počítačových sítí, která přenáší data pomocí protokolů TCP/IP. Web (World Wide Web, WWW) je jedna ze služeb, které po internetu běží: soustava dokumentů a aplikací propojených hypertextovými odkazy. Vedle webu používá internet i e-mail, přenos souborů nebo videohovory.

První weby

Web vymyslel britský fyzik a informatik Tim Berners-Lee v evropské laboratoři CERN u Ženevy. V roce 1989 navrhl systém, který měl vědcům usnadnit sdílení dokumentů, v roce 1990 naprogramoval první webový server a první prohlížeč nazvaný WorldWideWeb a v roce 1991 byl web zpřístupněn veřejnosti. První webová stránka na adrese info.cern.ch popisovala samotný projekt: co je web, jak si pořídit prohlížeč a jak spustit vlastní server.

Web od počátku stojí na třech prvcích:

  • HTML (HyperText Markup Language) – značkovací jazyk, kterým se zapisuje obsah a struktura stránky.
  • URL (Uniform Resource Locator) – jednotná adresa, která jednoznačně určuje každý dokument.
  • HTTP (HyperText Transfer Protocol) – protokol, kterým si prohlížeč vyžádá dokument od serveru.

Rozhodující bylo, že CERN v roce 1993 uvolnil technologii webu zdarma pro kohokoli. V roce 1994 založil Berners-Lee konsorcium W3C, které dodnes vydává webové standardy.

První stránky byly čistě textové, s nadpisy, odstavci a odkazy. Neměly téměř žádné formátování a obrázky se otevíraly v samostatném okně.

Programovací jazyky pro web

Webové technologie se dělí podle toho, kde kód běží: na klientu (v prohlížeči), nebo na serveru.

Na straně klienta se používá trojice jazyků a každý má jinou úlohu. HTML určuje obsah a strukturu a není programovacím jazykem, protože neobsahuje podmínky ani cykly. CSS určuje vzhled a rozložení. JavaScript je plnohodnotný programovací jazyk, který přidává chování: reaguje na kliknutí, kontroluje formuláře, mění stránku a komunikuje se serverem.

<button id="tl">Klikni</button>
<p id="vystup" style="color: navy"></p>
<script>
  document.getElementById("tl").onclick = function () {
    document.getElementById("vystup").textContent = "Ahoj!";
  };
</script>

Data se ukládají do databáze. S relačními databázemi (MySQL, PostgreSQL) se pracuje dotazovacím jazykem SQL.

Rozsáhlé aplikace se nepíší od nuly, ale pomocí frameworků a knihoven. Na klientu jsou to React, Vue nebo Angular, na serveru například Django, Laravel nebo Express.

Jak web funguje

Web pracuje v modelu klient–server: klient (prohlížeč) posílá požadavky a server na ně odpovídá. Po zadání adresy proběhne tento postup:

  1. Prohlížeč se zeptá systému DNS, jaká adresa IP patří k doménovému jménu.
  2. Naváže se serverem spojení, u HTTPS šifrované.
  3. Pošle požadavek HTTP, nejčastěji metodou GET (získání dat); formuláře často odesílá metodou POST.
  4. Server požadavek zpracuje, případně načte data z databáze, a vrátí odpověď se stavovým kódem (200 v pořádku, 404 nenalezeno, 500 chyba serveru) a obsahem.
  5. Prohlížeč zpracuje HTML, stáhne styly, skripty a obrázky a stránku vykreslí.

Frontend je část aplikace, která běží v prohlížeči a kterou uživatel vidí. Backend běží na serveru: obsahuje aplikační logiku, pracuje s databází a rozhoduje o oprávněních.

Protokol HTTP je bezstavový – server si mezi dvěma požadavky sám nepamatuje, kdo s ním komunikuje. Proto vznikly cookies a relace.

Moderní vzhled a funkce

Dnešní web je především platformou pro aplikace, které se přizpůsobí jakémukoli zařízení.

  • Responzivní design – jedna stránka mění rozložení podle šířky displeje. Využívá pružné rozvržení a pravidla CSS závislá na velikosti okna (media queries).
  • Webové aplikace – pošta, mapy, kancelářské nástroje nebo bankovnictví běží přímo v prohlížeči. Stránka se nenačítá znovu celá, JavaScript si na pozadí vyžádá jen potřebná data.
  • API – rozhraní, přes které si programy vyměňují data, obvykle ve formátu JSON. Díky němu může stejný server obsluhovat web i mobilní aplikaci.
  • HTTPS – HTTP šifrované protokolem TLS. Zajišťuje, že obsah po cestě nikdo nepřečte ani nezmění, a certifikátem ověřuje totožnost serveru.
  • HTML5 a moderní CSS – video, zvuk, kreslení, animace a složitá rozvržení bez zásuvných modulů, jako býval Flash.

Zpracování uživatelských dat

Web získává data dvojím způsobem: uživatel je vyplní sám, nebo je web zaznamená z jeho chování.

Cookiev prohlížeči, posílá se s každým požadavkemdo vypršení platnostipřihlášení, košík, sledování
Session (relace)na serveru, v cookie je jen identifikátordo odhlášení nebo vypršenístav přihlášeného uživatele
localStoragev prohlížeči, serveru se neposíládokud se nesmaženastavení, rozpracovaná data
Databázena serverutrvaleúčty, obsah, objednávky

Data z formuláře musí server vždy zkontrolovat sám. Kontrola v prohlížeči slouží pohodlí uživatele, ne bezpečnosti. Hesla se do databáze neukládají čitelně, ale jako otisk (hash).

Cookies první strany nastavuje navštívený web. Cookies třetích stran nastavuje jiná doména, typicky reklamní nebo analytická služba vložená do stránky, a umožňují sledovat uživatele napříč weby. Prohlížeče je proto postupně omezují. Webová analytika měří, odkud návštěvníci přišli, co si prohlíželi a kde web opustili.

Zpracování osobních údajů v Evropské unii upravuje nařízení GDPR, účinné od května 2018. Provozovatel smí zpracovávat osobní údaje jen s právním důvodem (například souhlas nebo plnění smlouvy), jen v nezbytném rozsahu a musí je zabezpečit. Uživatel má právo vědět, jaké údaje o něm web má, nechat je opravit, vymazat nebo přenést jinam. Z pravidel pro cookies plyne, že technicky nezbytné cookies souhlas nevyžadují, kdežto analytické a reklamní ano – a odmítnutí musí být stejně snadné jako přijetí.
