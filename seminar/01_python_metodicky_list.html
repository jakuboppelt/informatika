Programování v Pythonu 90′

Seminář 90 minut pro maturanty. Žáci po hodině zařadí Python mezi programovací jazyky, vysvětlí stavbu funkce a roztřídí funkce podle druhu. Praktická zkouška se v této hodině neprocvičuje. Hodinu vedeš podle prezentace, studenti mají studijní text.

Cíle hodiny

Žák:

  • charakterizuje Python (interpretovaný, dynamicky a silně typovaný, multiparadigmatický) a srovná ho s kompilovaným jazykem,
  • popíše části funkce: definici, parametry, tělo, návratovou hodnotu,
  • rozliší parametr a argument, lokální a globální proměnnou,
  • roztřídí funkce na vestavěné, knihovní a uživatelské a uvede další druhy (lambda, rekurzivní, metody),
  • uvede oblasti využití Pythonu, jeho výhody a nevýhody.

Předpoklady a pomůcky

  • Žáci už v Pythonu programovali (proměnné, podmínky, cykly).
  • Prezentace „01 – Programování v Pythonu“, studijní text ke stejné otázce.
  • Počítače s Pythonem 3 nebo online interpret, projektor, lístečky na třídění funkcí.

Aktivita: třídění funkcí

Na lístečcích jsou ukázky: len("abc"), print("ahoj"), math.sqrt(9), def pozdrav(jmeno): ..., lambda x: x + 1, "text".upper(), rekurzivní faktorial(n), random.randint(1, 6).

Skupina každou ukázku zařadí do jedné nebo více kategorií (vestavěná, knihovní, uživatelská, s návratovou hodnotou, bez ní, anonymní, rekurzivní, metoda). Cílem je, aby žáci zjistili, že kategorie nejsou vzájemně výlučné: print je vestavěná a zároveň bez návratové hodnoty.

Časté chyby a miskoncepce

ChybaJak na ni reagovat

„Funkce nemůže změnit nic venku.“Ukázka s seznam.append uvnitř funkce.

Výstupní lístek

  1. Napište jednou větou, co znamená, že je Python dynamicky typovaný.
  2. Jaký je rozdíl mezi print(x) a return x uvnitř funkce?
  3. Uveďte jednu oblast, kde byste Python použili, a jednu, kde ne. Proč?

Co má zaznít u maturity

  • Na výbornou: zařazení jazyka podle více hledisek se srovnáním, přesná terminologie funkcí (parametr, argument, návratová hodnota, rozsah platnosti), kategorizace s vlastními příklady, využití s konkrétními knihovnami a vyvážené zhodnocení výhod a nevýhod.
  • Na dostatečnou: žák ví, že Python je interpretovaný, umí popsat definici funkce a uvede alespoň dvě oblasti využití.

Doplňující otázky zkoušejícího: Co je None? Proč se nedoporučují globální proměnné? Proč je Python pomalejší než C++ a jak se to v praxi obchází?
