Informatika · Seminář · Maturitní otázka 11 · Praktická ukázka

Školní databáze v SQLite na vlastním počítači

Postavíš si malou databázi školy se třídami, studenty, předměty a známkami a vyzkoušíš na ní všechno z prezentace: SELECT, WHERE, ORDER BY, GROUP BY, JOIN, INSERT, UPDATE, DELETE i to, jak databáze sama hlídá správnost dat. U každého dotazu si můžeš rozbalit, co přesně má vyjít.

Po ukázce bys měl umět

  • vytvořit databázi a spustit v ní skript SQL
  • napsat SELECT s WHERE, ORDER BY a LIMIT
  • použít LIKE, IS NULL a agregační funkce
  • spojit tabulky pomocí JOIN a LEFT JOIN
  • seskupit řádky přes GROUP BY a HAVING
  • vložit, změnit a smazat záznam
  • vysvětlit chyby, kterými databáze odmítne špatná data
  • navrhnout vlastní tabulky s klíči

Příprava

Co nainstalovat

Použijeme SQLite: celá databáze je jeden soubor na disku a nepotřebuje žádný server. K ní program s oknem, ve kterém se píše SQL a hned je vidět výsledek.

  1. Otevři sqlitebrowser.org/dl a stáhni DB Browser for SQLite. Na Windows zvol Standard installer for 64-bit Windows, nebo verzi .zip (no installer), pokud nemáš práva instalovat programy. Je zdarma a s otevřeným kódem, existuje i pro macOS a Linux.
  2. Program spusť. Ovládání je anglicky, názvy tlačítek proto uvádíme anglicky.
Nechceš nic instalovat?

Python má SQLite v sobě. Postup je na konci v části Totéž v Pythonu.

Vytvoř databázi

  1. Klikni na New Database a ulož soubor jako skola.db, třeba do složky Dokumenty.
  2. Otevře se okno pro návrh tabulky. Zavři ho tlačítkem Cancel, tabulky vytvoří skript.
  3. Přepni na záložku Execute SQL.
  4. Zkopíruj celý skript níže (tlačítko Kopírovat) a vlož ho do okna. Nebo si stáhni soubor 11_skola.sql a otevři ho tlačítkem Open SQL file.
  5. Spusť ho klávesou F5 (nebo Ctrl + Enter). Dole se má objevit hláška, že se příkazy provedly bez chyby.
  6. Ulož změny: Write Changes (Ctrl + S).
Write Changes

DB Browser drží změny, dokud je nepotvrdíš. Když program zavřeš bez Write Changes, zeptá se, jestli je uložit. Na to pamatuj u každého INSERT, UPDATE a DELETE.

Skript 11_skola.sql
-- Školní databáze pro maturitní otázku 11: Databáze a základy SQL
-- Spusť celý skript najednou. Smaže staré tabulky a vytvoří je znovu s daty.
-- Kontrolu cizích klíčů má DB Browser for SQLite zapnutou sám,
-- v Pythonu ji zapni příkazem PRAGMA foreign_keys = ON.

DROP TABLE IF EXISTS znamky;
DROP TABLE IF EXISTS studenti;
DROP TABLE IF EXISTS predmety;
DROP TABLE IF EXISTS tridy;

CREATE TABLE tridy (
  id      INTEGER PRIMARY KEY,
  nazev   VARCHAR(10) NOT NULL UNIQUE,
  rocnik  INTEGER NOT NULL CHECK (rocnik BETWEEN 1 AND 4)
);

CREATE TABLE studenti (
  id        INTEGER PRIMARY KEY,
  jmeno     VARCHAR(40) NOT NULL,
  prijmeni  VARCHAR(40) NOT NULL,
  narozen   DATE,
  email     VARCHAR(80) UNIQUE,
  trida_id  INTEGER NOT NULL REFERENCES tridy(id)
);

CREATE TABLE predmety (
  id       INTEGER PRIMARY KEY,
  nazev    VARCHAR(40) NOT NULL,
  zkratka  VARCHAR(5) NOT NULL UNIQUE
);

CREATE TABLE znamky (
  id          INTEGER PRIMARY KEY,
  student_id  INTEGER NOT NULL REFERENCES studenti(id),
  predmet_id  INTEGER NOT NULL REFERENCES predmety(id),
  znamka      INTEGER NOT NULL CHECK (znamka BETWEEN 1 AND 5),
  vaha        INTEGER NOT NULL DEFAULT 1,
  datum       DATE NOT NULL
);

8. Spoj tři tabulky

Všechny známky z matematiky se jménem studenta. Spojovací tabulka znamky drží jen čísla, jména dodají dva JOINy. Přezdívky z, s, p zkracují zápis.

Dotaz
SELECT s.prijmeni, p.nazev AS predmet, z.znamka, z.datum
FROM znamky AS z
JOIN studenti AS s ON z.student_id = s.id
JOIN predmety AS p ON z.predmet_id = p.id
WHERE p.zkratka = 'M'
ORDER BY z.znamka, s.prijmeni;

10. Kdo nemá známku: LEFT JOIN

Obyčejný JOIN vrátí jen studenty, kteří nějakou známku mají. LEFT JOIN vezme všechny studenty a tam, kde známka chybí, doplní NULL. COUNT(z.id) počítá jen hodnoty, které nejsou NULL.

Dotaz
SELECT s.jmeno, s.prijmeni, COUNT(z.id) AS pocet_znamek
FROM studenti AS s
LEFT JOIN znamky AS z ON z.student_id = s.id
GROUP BY s.id
HAVING COUNT(z.id) = 0;
Co uvidíš (1 řádek)
jmenoprijmenipocet_znamek
AnnaNěmcová0

Zkus: vyměň LEFT JOIN za JOIN. Výsledek bude prázdný.

Změň strukturu

Škola chce u studentů evidovat telefon. ALTER TABLE přidá sloupec, stávající řádky v něm budou mít NULL:

ALTER TABLE
ALTER TABLE studenti ADD COLUMN telefon VARCHAR(20);

Podívej se na záložku Database Structure, nový sloupec tam bude. Proč je telefon VARCHAR a ne INTEGER? Kvůli předvolbě +420, mezerám a úvodním nulám.

Samostatně

Úkoly

Napiš dotaz sám. Řešení si rozbal, až když ti dotaz funguje, nebo když opravdu nevíš dál. Tvoje řešení může vypadat jinak a být správně: rozhoduje výsledek.

Úkol 1: Průměr z každého předmětu

Vypiš názvy předmětů a průměrnou známku zaokrouhlenou na dvě místa, od nejlepšího předmětu.

SELECT p.nazev, ROUND(AVG(z.znamka), 2) AS prumer
FROM znamky AS z
JOIN predmety AS p ON z.predmet_id = p.id
GROUP BY p.id
ORDER BY prumer;

Úkol 4: Nejlepší třída

Průměrná známka každé třídy (podle názvu třídy), od nejlepší.

Tady jsou potřeba tři tabulky: známka zná studenta, student zná třídu.

Úkol 5: Vážený průměr

Každá známka má váhu (1 nebo 2). Spočítej vážený průměr každého studenta a vypiš tři nejlepší. Vážený průměr = součet (známka × váha) / součet vah.

Řešení

Násobení * 1.0 je důležité: dělení dvou celých čísel by v SQLite dalo celé číslo a desetinná část by se ztratila.

SELECT s.jmeno, s.prijmeni,
       ROUND(SUM(z.znamka * z.vaha) * 1.0 / SUM(z.vaha), 2) AS vazeny_prumer
FROM studenti AS s
JOIN znamky AS z ON z.student_id = s.id
GROUP BY s.id
ORDER BY vazeny_prumer
LIMIT 3;

Navrhni tabulky: kroužky

Škola nabízí kroužky (robotika, fotbal, šachy). Každý kroužek má název, vedoucího a den v týdnu. Student může chodit do víc kroužků a kroužek má víc studentů.

  1. Jaký vztah je mezi studenty a kroužky?
  2. Navrhni tabulky se sloupci, typy a klíči a napiš je jako CREATE TABLE.
  3. Vlož tři kroužky a zapiš do nich pár studentů.
  4. Napiš dotaz, který vypíše kroužky a počet studentů v každém.
Jedno možné řešení

Vztah je M : N, proto potřebuješ spojovací tabulku. Složený primární klíč zajistí, že student nebude v jednom kroužku zapsaný dvakrát.

CREATE TABLE krouzky (
  id       INTEGER PRIMARY KEY,
  nazev    VARCHAR(40) NOT NULL UNIQUE,
  vedouci  VARCHAR(60) NOT NULL,
  den      VARCHAR(10) NOT NULL
);

CREATE TABLE clenstvi (
  student_id  INTEGER NOT NULL REFERENCES studenti(id),
  krouzek_id  INTEGER NOT NULL REFERENCES krouzky(id),
  PRIMARY KEY (student_id, krouzek_id)
);

INSERT INTO krouzky (nazev, vedouci, den) VALUES
  ('Robotika', 'Mgr. Kovář', 'pondělí'),
  ('Fotbal',   'Bc. Rychlý', 'středa'),
  ('Šachy',    'Ing. Věžová', 'čtvrtek');

INSERT INTO clenstvi (student_id, krouzek_id) VALUES
  (1, 1), (2, 1), (5, 1), (3, 2), (7, 2), (9, 3);

SELECT k.nazev, COUNT(c.student_id) AS pocet
FROM krouzky AS k
LEFT JOIN clenstvi AS c ON c.krouzek_id = k.id
GROUP BY k.id
ORDER BY pocet DESC;

Totéž v Pythonu

Python obsahuje modul sqlite3, takže nic dalšího instalovat nemusíš. Ulož si do jedné složky soubor 11_skola.sql a vedle něj tenhle program jako spust.py. Spusť ho v terminálu ve stejné složce příkazem python spust.py.

spust.py
import sqlite3

con = sqlite3.connect("skola.db")           # otevře soubor, nebo ho vytvoří
con.execute("PRAGMA foreign_keys = ON")     # zapne kontrolu cizích klíčů

with open("11_skola.sql", encoding="utf-8") as f:
    con.executescript(f.read())             # vytvoří tabulky a vloží data

dotaz = """
SELECT jmeno, prijmeni, narozen
FROM studenti
WHERE trida_id = 2
"""
for radek in con.execute(dotaz):
    print(radek)

con.commit()                                # uloží změny do souboru
con.close()

Parametrizovaný dotaz

Když něco nefunguje

Hláška nebo problémPříčina a řešení
no such table: studentPřeklep v názvu tabulky (správně studenti), nebo se skript ještě nespustil.
no such column: …Překlep v názvu sloupce. Názvy jsou bez diakritiky: prijmeni, ne příjmení.
near "…": syntax errorChyba v zápisu těsně u uvedeného slova: chybějící čárka mezi sloupci, středník uprostřed dotazu, špatné pořadí částí.
ambiguous column name: idSloupec id je ve víc spojených tabulkách. Napiš, ze které: s.id.
Text v uvozovkách nefungujeTexty patří do jednoduchých apostrofů 'Novák'. Dvojité uvozovky jsou v SQL pro názvy sloupců.
Po zavření zmizely změnyChybělo Write Changes. Spusť skript nebo příkazy znovu a ulož.
database is lockedDatabázi má otevřenou jiný program (třeba druhé okno DB Browseru nebo běžící Python). Zavři ho.
