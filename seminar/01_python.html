Co je Python

Vznik
Guido van Rossum, první verze 1991. Dnes se používá řada Python 3.
Čitelnost
Bloky kódu určuje odsazení, ne závorky. Odsazení je součást syntaxe.
Interpret
Kód se překládá do bajtkódu a ten vykonává virtuální stroj (CPython).
Typy
Typ patří hodnotě, ne proměnné. Proměnná je jen jméno pro hodnotu.
Knihovny
Bohatá standardní knihovna a balíčky z PyPI instalované přes pip.

Datové typy

Číslaint pro celá čísla libovolné velikosti, float pro desetinná.
Text a logikastr je neměnný řetězec, bool nabývá hodnot True a False.
Seznam a n-ticelist je měnitelný, tuple neměnná. Obojí drží pořadí prvků.
Slovníkdict ukládá dvojice klíč a hodnota, hledá se podle klíče.
Množinaset neobsahuje duplicity a nemá pořadí.
Měnitelnostlist, dict a set lze měnit na místě. Čísla, text a tuple ne.

Řízení toku programu

vek = int(input("Kolik ti je? "))

if vek >= 18:
    print("dospělý")
elif vek >= 15:
    print("mladistvý")
else:
    print("dítě")

for i in range(3):
    print(i)        # 0, 1, 2
  • Podmínka: if, elif, else. Za podmínkou následuje dvojtečka a odsazený blok.
  • Cyklus for prochází prvky kolekce nebo rozsahu range.
  • Cyklus while běží, dokud platí podmínka.
  • break cyklus ukončí, continue přeskočí na další průchod.
Hlavní myšlenka

Funkce je pojmenovaný blok kódu, který řeší jednu úlohu a dá se volat opakovaně.

Kód se neopakuje, program se dělí na části a ty se dají samostatně testovat.

Definice a volání funkce

def obsah(a, b=1):
    """Vrátí obsah obdélníku."""
    return a * b

print(obsah(3, 4))      # 12
print(obsah(5))         # 5
print(obsah(b=2, a=6))  # 12
  • def, jméno, parametry v závorce, dvojtečka a odsazené tělo.
  • Parametr je jméno v definici, argument je hodnota při volání.
  • return vrací výsledek. Funkce bez return vrací None.
  • Parametr může mít výchozí hodnotu, argumenty lze pojmenovat.

Rozsah platnosti a předávání

Lokální proměnná
Vzniká uvnitř funkce a po jejím skončení zaniká.
Globální proměnná
Vzniká mimo funkce. Funkce ji může číst, pro zápis potřebuje slovo global.
Předávání
Funkce dostává odkaz na objekt, ne jeho kopii.
Měnitelné typy
Změna seznamu nebo slovníku uvnitř funkce je vidět i venku.
Neměnné typy
Číslo ani text funkce venku nezmění, vytvoří si novou hodnotu.

Rekurze a lambda

def faktorial(n):
    if n <= 1:
        return 1
    return n * faktorial(n - 1)

dvakrat = lambda x: x * 2

jmena = ["Petr", "Jo", "Alena"]
sorted(jmena, key=lambda s: len(s))
  • Rekurzivní funkce volá sama sebe na menším vstupu.
  • Bez ukončovací podmínky skončí chybou RecursionError.
  • lambda je krátká funkce bez jména, hodí se jako argument jiné funkce.
