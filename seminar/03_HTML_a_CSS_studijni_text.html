Úvod

HTML, CSS a JavaScript: tři vrstvy webu

Každá webová stránka stojí na třech technologiích. Každá má jinou roli a dobrá stránka je od sebe drží oddělené.

HTML
Obsah a struktura

Co na stránce je: nadpisy, odstavce, obrázky, odkazy, formuláře.

CSS
Vzhled

Jak to vypadá: barvy, písma, rozložení, přizpůsobení mobilu.

JavaScript
Chování

Co to dělá: reakce na kliknutí, změny obsahu za běhu, komunikace se serverem.

Často se používá přirovnání k domu. HTML jsou zdi, okna a dveře, tedy konstrukce. CSS je omítka, barva a nábytek. JavaScript je elektřina: vypínač, po jehož stisknutí se něco stane.

Je HTML programovací jazyk?

Ne. Na tuhle otázku se zkoušející často ptá, protože otázka se jmenuje „Programování HTML a CSS“.

JazykTypProč
HTMLznačkovací jazyk (markup language)Jen označuje, co je který kus textu (nadpis, odstavec, odkaz). Nemá proměnné, podmínky ani cykly.
CSSstylový jazyk (style sheet language)Popisuje vzhled pomocí pravidel. Neumí provádět algoritmy.
JavaScriptprogramovací (skriptovací) jazykMá proměnné, podmínky, cykly, funkce. Dokáže řešit libovolnou výpočetní úlohu.

HTML a CSS jsou tedy deklarativní: popisujeme, jak má výsledek vypadat, a ne postup, jak ho vytvořit. Proto se správně mluví o „tvorbě webu v HTML a CSS“, ne o programování.

Jak se stránka dostane k uživateli

  1. Uživatel zadá adresu (URL), např. https://www.skola.cz/index.html.
  2. Prohlížeč (klient) pošle přes protokol HTTP/HTTPS požadavek na webový server.
  3. Server pošle zpět HTML soubor.
  4. Prohlížeč HTML čte (tzv. parsování) a postaví z něj stromovou strukturu DOM. Když narazí na odkaz na CSS, obrázek nebo skript, stáhne i ty.
  5. Prohlížeč spojí DOM se styly z CSS a stránku vykreslí (renderuje).
  6. JavaScript pak může DOM za běhu měnit a stránka se překreslí.

HTML i CSS jsou obyčejné textové soubory (přípony .html a .css). Napsat je jde v jakémkoli textovém editoru, a nepotřebují překladač: přímo je čte prohlížeč.

Historie HTML a CSS

HTML vymyslel britský fyzik a informatik Tim Berners-Lee v evropském centru jaderného výzkumu CERN ve Švýcarsku. Chtěl, aby si vědci mohli snadno sdílet dokumenty a propojovat je odkazy. Kromě HTML navrhl i protokol HTTP, první webový prohlížeč a první webový server. Je tedy „otcem“ celého webu (World Wide Web).

  1. 1989 Návrh webu v CERNBerners-Lee sepsal návrh systému propojených dokumentů (hypertextu).
  2. 1991 První popis HTMLDokument „HTML Tags“ s 18 značkami. Zveřejněna první webová stránka.
  3. 1993 Návrh HTML u IETFTakzvané „HTML 1.0“ zůstalo jen návrhem, oficiálním standardem se nikdy nestalo. Vzniká prohlížeč Mosaic, který umí zobrazit obrázky v textu.
  4. 1994 Vzniká W3CKonsorcium World Wide Web Consortium, které založil Berners-Lee, začíná webové standardy spravovat.
  5. 1995 HTML 2.0 – první oficiální standardVydán organizací IETF (RFC 1866). Přináší formuláře. Ve stejném roce vzniká JavaScript (Brendan Eich, Netscape).
  6. 1996 CSS1První verze CSS od W3C. Autory jsou Håkon Wium Lie a Bert Bos (návrh už z roku 1994).
  7. 1997 HTML 3.2Standard W3C. Tabulky, obtékání obrázků, applety. Prohlížeče soupeří (Netscape × Internet Explorer) a přidávají vlastní značky.
  8. 1997–1999 HTML 4.0 a 4.01Hlavní myšlenka: oddělit obsah od vzhledu. Vzhled se má psát v CSS, značky jako <font> jsou zastaralé. Lepší podpora skriptů. CSS2 vychází v roce 1998.
  9. 2000 XHTML 1.0HTML přepsané podle přísných pravidel jazyka XML (každá značka musí být uzavřena, malá písmena). Nakonec se neprosadilo.
  10. 2004 Vzniká WHATWGSkupina výrobců prohlížečů (Apple, Mozilla, Opera) začíná vyvíjet nové HTML místo XHTML 2.
  11. 2014 HTML5Oficiální doporučení W3C. Sémantické prvky (<header>, <nav>, <article>…), nativní <video> a <audio>, <canvas>, nové typy polí ve formulářích. Konec pluginu Flash.
  12. 2019 → HTML Living StandardW3C a WHATWG se dohodly, že HTML bude jeden „živý standard“, který spravuje WHATWG a průběžně se doplňuje. Číslované verze (HTML6) už nebudou.

CSS se po verzi CSS2 (2.1) přestalo vydávat jako celek. Od „CSS3“ se dělí na samostatné moduly (barvy, selektory, Flexbox, Grid, animace…), které se vyvíjejí každý zvlášť.

K maturitě

Zapamatuj si hlavně: Tim Berners-Lee, CERN, 1989–1991; HTML 2.0 (1995) jako první standard; HTML 4 a oddělení vzhledu do CSS; HTML5 (2014); dnes Living Standard od WHATWG. Organizace: W3C (CSS a dříve HTML), WHATWG (dnešní HTML), IETF (internetové protokoly, HTML 2.0).

HTML

Syntaxe HTML: značky, prvky, atributy

HTML označuje části textu pomocí značek (anglicky tags) ve špičatých závorkách. Počáteční značka, obsah a koncová značka dohromady tvoří prvek (element).

<a href="https://www.w3.org" target="_blank">Web W3C</a>
<!-- │  └─ atribut="hodnota"         │          │
     │                              obsah    koncová značka
     počáteční značka (tag) -->
  • Počáteční značka <a>, koncová značka </a> (s lomítkem).
  • Atribut upřesňuje prvek: zapisuje se do počáteční značky jako název="hodnota". Prvek může mít více atributů oddělených mezerou.
  • Komentář <!-- … --> prohlížeč nezobrazí; slouží pro poznámky autora.
  • Názvy značek se píšou malými písmeny. Na velikosti písmen v HTML nezáleží, ale je to zvyk.

Párové a nepárové prvky

<!-- Párové prvky: mají počáteční i koncovou značku -->
<p>Toto je odstavec.</p>
<strong>Důležitý text</strong>

<!-- Nepárové (prázdné) prvky: nemají obsah ani koncovou značku -->
<br>
<img src="pes.jpg" alt="Hnědý pes na louce">
<input type="text" name="jmeno">
<meta charset="UTF-8">

Nepárové prvky (<br>, <img>, <input>, <meta>, <link>, <hr>) nemají obsah. V XHTML se psaly s lomítkem na konci (<br />); v HTML5 to jde, ale není to nutné.

Vnořování

Prvky se do sebe vnořují. Vnořený prvek se musí zavřít dřív než ten, který ho obsahuje:

<!-- Správně: co se otevře poslední, zavře se první -->
<p>Text je <strong>velmi <em>důležitý</em></strong>.</p>

<!-- Špatně: značky se kříží -->
<p>Text je <strong>velmi <em>důležitý</strong></em>.</p>

Důležité globální atributy

Tyto atributy může mít skoro každý prvek:

AtributK čemu slouží
idJedinečný identifikátor prvku. Na stránce smí být jen jednou. Používá ho CSS, JavaScript i odkazy (#kontakt).
classZařazení do třídy. Víc prvků může mít stejnou třídu, jeden prvek může mít více tříd. Hlavní „háček“ pro CSS.
styleInline CSS přímo u prvku (používat výjimečně).
titleText bubliny, která se ukáže po najetí myší.
langJazyk obsahu (cs, en). Důležitý pro čtečky a vyhledávače.

Kostra HTML dokumentu

Každá HTML stránka má stejnou základní strukturu. Tuhle kostru bys měl umět napsat zpaměti a vysvětlit každý řádek.

<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Krátký popis stránky pro vyhledávače">
  <title>Název stránky v záložce</title>
  <link rel="stylesheet" href="styl.css">
</head>
<body>
  <h1>Hlavní nadpis</h1>
  <p>Obsah, který uvidí uživatel.</p>
  <script src="skript.js"></script>
</body>
</html>
ŘádekVýznam
<!DOCTYPE html>Deklarace typu dokumentu. Musí být úplně první. Říká prohlížeči, že jde o HTML5, a zapne standardní režim zobrazení. Není to HTML prvek.
<html lang="cs">Kořenový prvek, obaluje celý dokument. lang určuje jazyk.
<head>Hlavička: informace o stránce (metadata), které se přímo nezobrazují.
<meta charset="UTF-8">Kódování znaků. Bez něj se mohou rozbít česká písmena s háčky a čárkami.
<meta name="viewport" …>Nastaví šířku stránky podle šířky zařízení. Nutné pro správné zobrazení na mobilu.
<meta name="description">Popis stránky, který se zobrazuje ve výsledcích vyhledávání (SEO).
<title>Název stránky v záložce prohlížeče, v záložkách a ve výsledcích vyhledávání.
<link rel="stylesheet">Připojení externího CSS souboru.
<body>Tělo: všechno, co se uživateli zobrazí.
<script>JavaScript. Často se dává na konec body, aby se nejdřív načetl obsah.

Odkazy a obrázky

Odkazy jsou podstatou hypertextu (odtud „HyperText“ v názvu HTML). Cesty k souborům mohou být absolutní nebo relativní:

<!-- Absolutní adresa: celá URL -->
<a href="https://www.seznam.cz">Seznam</a>

<!-- Relativní adresa: vzhledem k aktuálnímu souboru -->
<a href="kontakt.html">Kontakt</a>
<a href="clanky/clanek1.html">Článek ve složce clanky</a>
<a href="../index.html">O složku výš</a>

<!-- Odkaz na místo na stránce (kotva) a na e-mail -->
<a href="#kontakt">Skok na sekci s id="kontakt"</a>
<a href="mailto:info@skola.cz">Napište nám</a>

<!-- Obrázek: alt je povinný popis pro nevidomé a pro případ, že se obrázek nenačte -->
<img src="obrazky/skola.jpg" alt="Budova gymnázia" width="600" height="400">

Atribut target="_blank" otevře odkaz v nové záložce. U obrázku je atribut alt povinný: čtečka obrazovky ho přečte nevidomému uživateli a zobrazí se, když se obrázek nenačte. Běžné formáty obrázků na webu: JPG (fotky), PNG (průhlednost), SVG (vektorová grafika), WebP (moderní, menší soubory), GIF (jednoduché animace).

Multimédia

<video src="video.mp4" controls width="640">
  Váš prohlížeč nepodporuje video.
</video>

<audio src="hudba.mp3" controls></audio>

<!-- Vložení cizí stránky (např. mapy nebo videa z YouTube) -->
<iframe src="https://www.openstreetmap.org/export/embed.html" width="400" height="300"></iframe>

Před HTML5 šlo video přehrát jen pomocí pluginu (Adobe Flash). Atribut controls zobrazí ovládací prvky přehrávače. <iframe> vloží do stránky jinou stránku.

Obecné kontejnery

<div> (blokový) a <span> (řádkový) nemají žádný význam. Slouží jen k seskupení obsahu, aby ho šlo stylovat přes CSS nebo ovládat JavaScriptem. Pokud existuje prvek s významem (<nav>, <article>), má přednost.

Pozor

Tabulky slouží pro tabulková data, ne pro rozložení stránky. Kdysi se celé weby skládaly z tabulek; dnes se na rozložení používá CSS (Flexbox, Grid). Výjimkou jsou HTML e-maily, viz Využití.

Formuláře

Formuláře umožňují uživateli posílat data na server: přihlášení, registrace, vyhledávání, objednávka.

<form action="/prihlaska" method="post">
  <label for="jmeno">Jméno:</label>
  <input type="text" id="jmeno" name="jmeno" required>

  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email" placeholder="jan@novak.cz">

  <label for="trida">Třída:</label>
  <select id="trida" name="trida">
    <option value="1A">1.A</option>
    <option value="2B">2.B</option>
  </select>

  <p>Pohlaví:</p>
  <label><input type="radio" name="pohlavi" value="m"> muž</label>
  <label><input type="radio" name="pohlavi" value="z"> žena</label>

  <label><input type="checkbox" name="souhlas"> Souhlasím s podmínkami</label>

  <label for="zprava">Zpráva:</label>
  <textarea id="zprava" name="zprava" rows="4"></textarea>

  <button type="submit">Odeslat</button>
</form>
  • action je adresa, kam se data odešlou (zpracuje je server, např. v PHP nebo Pythonu).
  • method je způsob odeslání. GET přidá data do URL (?jmeno=Jan): hodí se pro vyhledávání, adresu jde uložit. POST je pošle v těle požadavku: pro hesla, citlivá a větší data.
  • name je název pole, pod kterým server hodnotu dostane. Bez něj se pole neodešle.
  • <label> je popisek pole. Propojený přes for a id: kliknutím na popisek se aktivuje pole a čtečka ví, co pole znamená.
  • required, type="email", min, max zajišťují základní kontrolu (validaci) přímo v prohlížeči.

Typy pole <input>: text, password, email, number, tel, date, checkbox (zaškrtávací pole, více možností), radio (přepínač, jedna možnost ze skupiny se stejným name), file, range, color, submit, hidden.

Sémantické HTML5

Sémantika znamená význam. Sémantický prvek neříká jen „tady je nějaký blok“, ale „tady je navigace“ nebo „tady je článek“. HTML5 přidalo prvky, které popisují části stránky:

<body>
  <header>
    <h1>Gymnázium Navis</h1>
    <nav>
      <a href="/">Úvod</a>
      <a href="/aktuality">Aktuality</a>
      <a href="/kontakt">Kontakt</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Den otevřených dveří</h2>
      <p>Přijďte se podívat 15. listopadu…</p>
    </article>

    <aside>
      <h3>Rychlé odkazy</h3>
      <p>Rozvrh, jídelna, suplování</p>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 Gymnázium Navis</p>
  </footer>
</body>
PrvekVýznam
<header>Záhlaví stránky nebo sekce (logo, nadpis)
<nav>Hlavní navigace (menu)
<main>Hlavní obsah stránky, jen jednou
<article>Samostatný celek, který dává smysl i vytržený (článek, příspěvek, recenze)
<section>Tematická část s vlastním nadpisem
<aside>Doplňkový obsah vedle hlavního (boční panel)
<footer>Zápatí (kontakty, copyright)
<figure>, <figcaption>Obrázek nebo graf s popiskem

Pro srovnání stejná stránka bez sémantiky:

<!-- Totéž bez sémantiky: funguje, ale prohlížeč ani čtečka nevědí, co je co -->
<div class="hlavicka">
  <div class="menu">…</div>
</div>
<div class="obsah">…</div>
<div class="paticka">…</div>

Proč na sémantice záleží

  • Přístupnost: čtečky obrazovky pro nevidomé umí skočit rovnou na <main> nebo <nav>.
  • SEO: vyhledávače lépe pochopí, co je na stránce hlavní obsah.
  • Čitelnost kódu: vývojář hned vidí strukturu.

Toto chování je jen výchozí. V CSS ho lze změnit vlastností display (viz Rozložení).

DOM: stránka jako strom

Prohlížeč si HTML převede na DOM (Document Object Model), stromovou strukturu objektů. Každý prvek je uzel; prvek uvnitř jiného prvku je jeho potomek (dítě), obalující prvek je rodič, prvky na stejné úrovni jsou sourozenci.

document
└─ html
   ├─ head
   │  └─ title ─ "Moje stránka"
   └─ body
      ├─ h1 ─ "Nadpis"
      └─ p ─ "Text s "
         └─ a ─ "odkazem"

DOM je důležitý pro obě další vrstvy. CSS vybírá prvky podle jejich místa ve stromu (nav a = odkazy uvnitř navigace) a vlastnosti se po stromu dědí. JavaScript ve stromu prvky hledá a mění (document.getElementById(…)).

CSS

CSS: princip a syntaxe

CSS (Cascading Style Sheets, kaskádové styly) určuje vzhled HTML prvků. Hlavní myšlenka je oddělení obsahu od vzhledu: HTML říká, co na stránce je, CSS říká, jak to vypadá. Výhody:

  • Jeden CSS soubor může stylovat celý web. Změna barvy na jednom místě se projeví na stovkách stránek.
  • HTML je kratší a přehlednější.
  • Stejný obsah může mít různý vzhled: pro mobil, počítač, tisk.
  • Prohlížeč CSS soubor uloží do mezipaměti (cache), takže další stránky se načítají rychleji.

Styl se skládá z pravidel. Každé pravidlo má selektor (komu styl platí) a deklarace (vlastnost a hodnota):

h1 {
  color: navy;
  font-size: 32px;
}
/*
h1          → selektor (KOMU styl platí)
{ … }       → deklarační blok
color       → vlastnost
navy        → hodnota
color: navy; → jedna deklarace (končí středníkem)
*/

Tři způsoby připojení CSS

<!-- 1) Inline styl – přímo v atributu style. Platí jen pro tento jeden prvek. -->
<p style="color: red; font-weight: bold;">Červený text</p>

<!-- 2) Interní styl – v hlavičce dokumentu. Platí pro celou tuto stránku. -->
<head>
  <style>
    p { color: red; }
  </style>
</head>

<!-- 3) Externí styl – samostatný soubor. Jeden soubor může stylovat celý web. -->
<head>
  <link rel="stylesheet" href="styl.css">
</head>
ZpůsobKdeVýhodyNevýhody
Inlineatribut styleNejvyšší priorita, rychlá úprava jednoho prvkuMíchá obsah se vzhledem, nedá se znovu použít
Interní<style> v <head>Vše v jednom souboruPlatí jen pro jednu stránku
Externísoubor .css přes <link>Jeden styl pro celý web, cache, přehlednostDalší soubor ke stažení
Doporučení

V praxi se používá hlavně externí styl. Inline jen výjimečně (a v e-mailech).

Selektory

Selektor určuje, na které prvky se pravidlo použije.

*            { box-sizing: border-box; }   /* univerzální – všechny prvky        */
p            { line-height: 1.6; }         /* typový – všechny <p>                */
.upozorneni  { color: red; }               /* třídní – prvky s class="upozorneni" */
#hlavicka    { height: 80px; }             /* ID – prvek s id="hlavicka"          */
h1, h2, h3   { font-family: Georgia; }     /* skupina – více selektorů najednou   */
nav a        { color: white; }             /* potomek – <a> kdekoli uvnitř <nav>  */
ul > li      { margin: 4px; }              /* přímý potomek – jen děti <ul>       */
input[type="email"] { width: 100%; }       /* atributový                         */
a:hover      { text-decoration: none; }    /* pseudotřída – stav prvku            */
li:first-child { font-weight: bold; }      /* pseudotřída – pozice prvku          */
p::first-line  { font-variant: small-caps; } /* pseudoelement – část prvku       */

Třídy a ID se v HTML zapisují takto; v CSS se třída píše s tečkou (.upozorneni), ID s mřížkou (#hlavicka):

<p class="upozorneni">Zítra se neučí.</p>
<p class="upozorneni velky">Prvek může mít více tříd oddělených mezerou.</p>
<div id="hlavicka">ID musí být na stránce jen jednou.</div>

Pseudotřídy (jedna dvojtečka) vybírají prvek v určitém stavu nebo na určité pozici: :hover (myš nad prvkem), :focus (prvek je aktivní, např. pole, do kterého se píše), :visited (navštívený odkaz), :first-child, :nth-child(2n) (každý sudý). Pseudoelementy (dvě dvojtečky) vybírají část prvku: ::first-letter, ::before, ::after.

Kaskáda, specificita a dědičnost

Na jeden prvek často míří více pravidel, která si odporují. Kaskáda je postup, kterým prohlížeč rozhodne, které pravidlo vyhraje. Odtud slovo „Cascading“ v názvu CSS. Rozhoduje se v tomto pořadí:

  1. Důležitost: deklarace s !important přebije ostatní. Používat jen výjimečně, dělá styl nepřehledným.
  2. Původ: styl autora stránky přebije výchozí styl prohlížeče (proto jde změnit např. modrou barvu odkazů). Inline styl v atributu style přebije styly v <style> i v souboru.
  3. Specificita: konkrétnější selektor vyhrává nad obecnějším.
  4. Pořadí: při stejné specificitě vyhrává pravidlo, které je zapsané později.

Specificita je trojice čísel IDtřídyprvky. Porovnává se zleva: jedno ID vždy přebije libovolný počet tříd.

Dědičnost

Některé vlastnosti se automaticky dědí z rodiče na potomky v DOM stromu. Stačí nastavit písmo na body a platí pro celou stránku.

  • Dědí se hlavně vlastnosti textu: color, font-family, font-size, line-height, text-align.
  • Nedědí se vlastnosti „krabice“: margin, padding, border, background, width, height.
body {
  font-family: Arial, sans-serif;  /* zdědí všechny prvky uvnitř body */
  color: #333;                     /* zdědí se */
  border: 1px solid red;           /* NEzdědí se – rámeček bude jen kolem body */
}

Box model

Pro CSS je každý prvek obdélník (krabice). Krabice má čtyři vrstvy, od středu ven:

margin – vnější okraj (průhledný)
border – rámeček
padding – vnitřní okraj
content – obsah (width × height)
VrstvaVlastnostPopis
Obsahwidth, heightText, obrázek, vnořené prvky
Vnitřní okrajpaddingMezera mezi obsahem a rámečkem. Má barvu pozadí prvku.
RámečekborderČára kolem prvku: tloušťka, styl, barva (2px solid black)
Vnější okrajmarginPrůhledná mezera mezi prvkem a sousedy

Jak se počítá šířka: box-sizing

.krabice {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
}
/* box-sizing: content-box (výchozí):
   skutečná šířka = 200 + 2·20 + 2·5 = 250 px  (+ okraje 2·10 kolem)

   box-sizing: border-box:
   skutečná šířka = 200 px, obsah se zúží na 200 − 40 − 10 = 150 px */

* { box-sizing: border-box; }   /* běžné nastavení na začátku stylu */

Zkrácené zápisy okrajů (platí pro margin i padding):

margin: 10px;                 /* všechny 4 strany                          */
margin: 10px 20px;            /* nahoře+dole 10, vlevo+vpravo 20           */
margin: 10px 20px 30px 40px;  /* ve směru hodin: nahoře, vpravo, dole, vlevo */
margin: 0 auto;               /* vycentrování bloku s danou šířkou         */
Pozor

Svislé vnější okraje dvou bloků pod sebou se nesčítají, ale slévají (margin collapsing): mezi odstavci s margin: 20px bude mezera 20 px, ne 40 px.

font-size: 1.125rem;
font-weight: 700;          /* tučné */
font-style: italic;
line-height: 1.5;          /* výška řádku */
text-align: center;
text-decoration: underline;

Pozicování: position

  • static: výchozí, prvek je v normálním toku dokumentu.
  • relative: posunutí vůči své původní pozici (top, left…). Původní místo zůstane volné.
  • absolute: vyjmutý z toku, umístěný vůči nejbližšímu předkovi s nastaveným position (jinak vůči stránce).
  • fixed: pevně vůči oknu prohlížeče, při rolování se nehýbe.
  • sticky: chová se normálně, dokud nedojde k okraji okna, pak se „přilepí“.
.rodic   { position: relative; }            /* stane se „kotvou“ pro absolutní potomky */
.stitek  { position: absolute; top: 0; right: 0; }  /* pravý horní roh rodiče   */
.menu    { position: sticky; top: 0; }       /* při rolování se přilepí nahoru      */
.chat    { position: fixed; bottom: 20px; right: 20px; } /* stále v rohu okna    */

Flexbox: rozložení v jednom směru

Flexbox rozmisťuje prvky v jedné řadě (řádek nebo sloupec). Hodí se pro menu, lišty, zarovnání na střed, karty v řadě.

.menu {
  display: flex;               /* z rodiče se stane flex kontejner  */
  flex-direction: row;         /* hlavní osa: řádek (nebo column)   */
  justify-content: space-between; /* rozložení na hlavní ose        */
  align-items: center;         /* zarovnání na příčné ose           */
  gap: 16px;                   /* mezery mezi položkami             */
  flex-wrap: wrap;             /* když se nevejdou, zalomí se       */
}
.menu .logo { flex: 1; }       /* logo zabere zbylé místo           */

Grid: rozložení ve dvou směrech

CSS Grid rozvrhne prvky do mřížky řádků a sloupců. Hodí se pro rozvržení celé stránky nebo galerie.

.galerie {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 stejně široké sloupce */
  gap: 20px;
}

.stranka {
  display: grid;
  grid-template-columns: 250px 1fr;       /* boční panel + obsah */
  grid-template-areas:
    "hlavicka hlavicka"
    "panel    obsah"
    "paticka  paticka";
}
header { grid-area: hlavicka; }
K maturitě

Rozdíl jednou větou: Flexbox je jednorozměrný (řada), Grid dvourozměrný (řádky i sloupce). Dříve se rozložení řešilo tabulkami a později vlastností float; obojí je pro layout zastaralé.

Responzivní design

Responzivní stránka se přizpůsobí velikosti obrazovky: na mobilu má jeden sloupec a velká tlačítka, na počítači víc sloupců. Dnes přichází většina návštěv webů z mobilů. Nástroje:

  • Meta viewport v hlavičce (viz kostra). Bez něj mobil stránku jen zmenší.
  • Relativní jednotky (%, rem, fr) místo pevných pixelů.
  • Pružné rozložení pomocí Flexboxu a Gridu.
  • Media queries: styly, které platí jen za určité podmínky (šířka okna, tisk, tmavý režim).
  • Pružné obrázky: img { max-width: 100%; }.
/* Mobile first: základní styl je pro mobil … */
.galerie { display: grid; grid-template-columns: 1fr; }

/* … a pro širší obrazovky se přidává */
@media (min-width: 600px) {
  .galerie { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1000px) {
  .galerie { grid-template-columns: repeat(4, 1fr); }
}

/* Styl jen pro tisk */
@media print {
  nav, footer { display: none; }
}

Přístup mobile first znamená, že se nejdřív napíše styl pro mobil a pro větší obrazovky se postupně přidávají úpravy (min-width).

Praxe

Celý příklad s komentáři

Stránka, na které jsou vidět všechny tři vrstvy: HTML (struktura), CSS (vzhled v <style>) a JavaScript (reakce na kliknutí).

<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Ukázka HTML, CSS a JavaScriptu</title>
  <style>
    /* ===== CSS: vzhled ===== */
    body {
      font-family: Arial, sans-serif;   /* písmo pro celou stránku (dědí se) */
      background-color: #f4f4f4;
      margin: 20px;
    }
    h1 {
      color: #333;
      text-align: center;
    }
    button {
      display: block;                   /* tlačítko jako blok…               */
      margin: 20px auto;                /* …aby šlo vycentrovat pomocí auto  */
      padding: 10px 20px;
      font-size: 16px;
      background-color: #4CAF50;
      color: white;
      border: none;
      border-radius: 5px;               /* zaoblené rohy                     */
      cursor: pointer;                  /* kurzor ve tvaru ruky              */
      transition: background-color 0.2s;
    }
    button:hover {                      /* pseudotřída: myš je nad tlačítkem */
      background-color: #45a049;
    }
    p {
      text-align: center;
      color: #555;
    }
  </style>
</head>
<body>
  <!-- ===== HTML: obsah a struktura ===== -->
  <h1>Ukázka HTML, CSS a JavaScriptu</h1>
  <p id="zprava">Klikni na tlačítko pro zobrazení zprávy.</p>
  <button onclick="zobrazZpravu()">Klikni na mě</button>

  <script>
    // ===== JavaScript: chování =====
    function zobrazZpravu() {
      const prvek = document.getElementById('zprava');  // najde prvek v DOM podle id
      prvek.textContent = "Gratuluji! Právě jsi spustil JavaScript.";
      prvek.style.color = '#4CAF50';                    // změní styl za běhu
    }
  </script>
</body>
</html>

Co se děje: prohlížeč vykreslí nadpis, odstavec a zelené tlačítko. Při najetí myší tlačítko ztmavne (pseudotřída :hover a transition). Po kliknutí se zavolá funkce zobrazZpravu(), ta v DOM najde odstavec s id="zprava" a změní jeho text a barvu. Stránka se nemusí znovu načítat.

Vyzkoušej si

Uprav kód vlevo a vpravo hned uvidíš výsledek. Zkus třeba změnit barvu #2451d6, odsazení padding nebo přidat další odstavec.

Výsledek

Doma stačí kód uložit do souboru s příponou .html a otevřít ho v prohlížeči.

Nástroje pro tvorbu webu

  • Textový editor: stačí i Poznámkový blok. V praxi se používají editory se zvýrazněním syntaxe a našeptáváním: Visual Studio Code, Sublime Text, WebStorm.
  • Prohlížeč a vývojářské nástroje (DevTools, klávesa F12): zobrazí DOM, umožní měnit CSS naživo, ukáže chyby, simuluje mobil.
  • Validátor W3C (validator.w3.org): zkontroluje, jestli je HTML napsané správně.
  • Can I use (caniuse.com): ukáže, které prohlížeče podporují danou vlastnost.
  • CSS preprocesory (Sass, Less): rozšiřují CSS o vnořování, funkce a další. Překládají se do obyčejného CSS.
  • CSS frameworky (Bootstrap, Tailwind CSS): hotové styly a komponenty, rychlejší vývoj.

Jak vzniká web bez psaní kódu

  • WYSIWYG editory (What You See Is What You Get): uživatel upravuje stránku vizuálně jako v textovém editoru a HTML se vytvoří samo. Např. Adobe Dreamweaver, editor v e-mailu nebo v CMS.
  • Redakční systémy (CMS): aplikace na správu obsahu webu, kde obsah přidávají běžní uživatelé přes administraci. Např. WordPress (pohání zhruba 40 % webů), Joomla, Drupal.
  • Webové stavebnice (site builders): Wix, Squarespace, Webnode. Web se skládá z hotových bloků přetahováním myší.

Statický a dynamický web

Statický web tvoří hotové HTML soubory, každý návštěvník dostane totéž. Dynamický web generuje HTML až na serveru podle situace (přihlášený uživatel, data z databáze), pomocí serverových jazyků jako PHP, Python nebo JavaScript (Node.js). Prohlížeč ale vždy nakonec dostane HTML a CSS.

Využití HTML a CSS

  • Webové stránky všeho druhu: prezentace, e-shopy, zpravodajství, blogy.
  • Webové aplikace: Gmail, Google Dokumenty, online hry. Uživatelské rozhraní je HTML a CSS, logika v JavaScriptu. PWA (progresivní webové aplikace) se dají „nainstalovat“ jako aplikace a fungují i offline.
  • HTML e-maily: newslettery, potvrzení objednávek. Zvláštnost: poštovní programy (hlavně Outlook) podporují CSS jen omezeně, proto se v e-mailech dodnes používají tabulky na rozložení a inline styly.
  • Desktopové aplikace přes framework Electron: Visual Studio Code, Discord, Slack jsou uvnitř vlastně webové stránky.
  • Mobilní aplikace přes frameworky Ionic a Capacitor (dříve Cordova a PhoneGap). Framework je předpřipravená sada nástrojů a knihoven, která usnadňuje vývoj.
  • Dokumenty a tisk: převod HTML do PDF (faktury, reporty), e-knihy ve formátu EPUB jsou uvnitř HTML a CSS.
  • SEO (Search Engine Optimization, optimalizace pro vyhledávače): správné nadpisy, sémantické prvky, title, meta description a alt u obrázků pomáhají, aby byla stránka výš ve výsledcích vyhledávání.
  • Přístupnost (accessibility): správně napsané HTML umožňuje používat web i lidem se zrakovým nebo pohybovým postižením.

K maturitě

Jak odpovídat u maturity

Doporučená osnova odpovědi na 10–15 minut. U každého bodu si připrav jeden krátký příklad kódu, který umíš napsat na tabuli.

  1. Úvod: tři vrstvy webu (HTML, CSS, JS) a jejich role. HTML je značkovací jazyk, ne programovací.
  2. Historie: Berners-Lee, CERN, HTML 2.0, HTML 4 a CSS, HTML5, Living Standard. W3C a WHATWG.
  3. HTML syntaxe: značka, prvek, atribut, párové a nepárové, vnořování.
  4. Kostra dokumentu: napsat ji a vysvětlit DOCTYPE, head, body, meta.
  5. Prvky podle kategorií: text, seznamy, odkazy a obrázky, tabulky, formuláře, multimédia, sémantické HTML5.
  6. CSS princip: oddělení vzhledu, syntaxe pravidla, tři způsoby připojení.
  7. Selektory a kaskáda: typ, třída, ID, pseudotřídy; specificita a dědičnost.
  8. Box model a rozložení: nakreslit box model; Flexbox × Grid; responzivita a media queries.
  9. Využití a nástroje: weby, aplikace, e-maily, Electron; editor, DevTools, validátor, CMS.

Otázky k opakování

Nejdřív odpověz sám, pak si rozbal správnou odpověď.

Proč HTML není programovací jazyk?

Je to značkovací jazyk: jen popisuje strukturu a význam obsahu. Nemá proměnné, podmínky, cykly ani funkce, takže v něm nejde zapsat algoritmus.

Kdo vytvořil HTML, kde a kdy?

Tim Berners-Lee v CERN. Návrh webu 1989, první popis HTML 1991. První oficiální standard je HTML 2.0 z roku 1995.

Kdo dnes spravuje HTML a kdo CSS?

HTML spravuje WHATWG jako HTML Living Standard (od dohody s W3C v roce 2019). CSS spravuje W3C, po modulech.

Co dělá <!DOCTYPE html> a kde musí být?

Úplně na začátku dokumentu. Říká prohlížeči, že jde o HTML5, a přepne ho do standardního režimu zobrazení.

Jaký je rozdíl mezi <head> a <header>?

<head> je hlavička dokumentu s metadaty, nezobrazuje se. <header> je viditelné záhlaví stránky nebo sekce (logo, nadpis, menu) uvnitř <body>.

Co je sémantické HTML a proč ho používat?

Používání prvků podle jejich významu (nav, main, article, footer…) místo obecných div. Pomáhá přístupnosti (čtečky), SEO a čitelnosti kódu.

Jaký je rozdíl mezi metodami GET a POST?

GET posílá data v URL (viditelná, dají se uložit do záložky, omezená délka), hodí se pro vyhledávání. POST je posílá v těle požadavku, hodí se pro hesla a větší data.

Jaké jsou tři způsoby připojení CSS? Který má nejvyšší prioritu?

Inline (style u prvku), interní (<style> v hlavičce), externí (soubor přes <link>). Nejvyšší prioritu má inline, pokud nepočítáme !important.

Který selektor vyhraje: #menu a, nebo .nav .polozka a?

#menu a má specificitu 1-0-1, .nav .polozka a má 0-2-1. Vyhrává #menu a, protože jedno ID přebije libovolný počet tříd.

Jak široký bude prvek s width: 300px; padding: 10px; border: 2px solid;?

Při výchozím box-sizing: content-box: 300 + 2·10 + 2·2 = 324 px. Při border-box přesně 300 px.

Které vlastnosti se dědí a které ne?

Dědí se hlavně textové (color, font-*, line-height, text-align). Nedědí se vlastnosti krabice (margin, padding, border, background, width).

Jaký je rozdíl mezi Flexboxem a Gridem?

Flexbox rozmisťuje prvky v jednom směru (řádek nebo sloupec). Grid ve dvou směrech (řádky a sloupce zároveň).

Co je responzivní design a jak se dělá?

Přizpůsobení stránky různým velikostem obrazovky. Meta viewport, relativní jednotky, Flexbox a Grid, media queries, max-width: 100% u obrázků.

Proč se v HTML e-mailech používají tabulky?

Poštovní klienti (hlavně Outlook) podporují moderní CSS jen omezeně, takže rozložení pomocí Flexboxu a Gridu by se rozpadlo. Tabulky a inline styly fungují všude.

Slovníček pojmů

HTML
HyperText Markup Language, značkovací jazyk pro strukturu webové stránky
CSS
Cascading Style Sheets, kaskádové styly pro vzhled stránky
Hypertext
Text s odkazy na jiné dokumenty
Značka (tag)
Zápis ve špičatých závorkách, např. <p>
Prvek (element)
Počáteční značka + obsah + koncová značka
Atribut
Doplňující údaj prvku, název="hodnota"
DOM
Document Object Model, stromová reprezentace stránky v prohlížeči
Selektor
Část CSS pravidla určující, na které prvky se použije
Kaskáda
Pravidla, podle kterých se rozhoduje mezi konfliktními styly
Specificita
„Váha“ selektoru (ID > třída > prvek)
Box model
Model prvku jako krabice: content, padding, border, margin
Responzivita
Přizpůsobení stránky velikosti zařízení
Media query
Podmínka v CSS (@media), kdy mají styly platit
W3C
World Wide Web Consortium, organizace pro webové standardy
WHATWG
Skupina výrobců prohlížečů, spravuje HTML Living Standard
SEO
Optimalizace stránky pro vyhledávače
CMS
Redakční systém pro správu obsahu webu (WordPress)
WYSIWYG
What You See Is What You Get, vizuální editor bez psaní kódu
Framework
Předpřipravená sada nástrojů a knihoven pro rychlejší vývoj
