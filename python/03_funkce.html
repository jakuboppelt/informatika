Python: funkce

Navazuje na proměnné a typy. Naučíš se dát kusu kódu jméno, předat mu vstup a získat z něj výsledek. Nejdřív krátký výklad s ukázkami, které si můžeš zkopírovat a vyzkoušet, potom úkoly. Jak programy psát a spouštět, najdeš v prvních krocích.

Úkolů7 + 1 bonus, od nejlehčího
Časjedna vyučovací hodina
Když se zaseknešpřečti chybu, pak Nápověda, až nakonec Řešení

Výklad

Co je funkce

Funkce už používáš od první hodiny: print("Ahoj"), input("Jméno: "), int("5"), len("ahoj"). Každá má jméno, v závorkách dostane vstup a něco udělá nebo vrátí výsledek. Jejich kód ale psal někdo jiný. Dnes se naučíš psát vlastní.

Funkce je pojmenovaný kus kódu, který spustíš zavoláním jeho jména. Je to jako recept: jednou ho sepíšeš a pak podle něj vaříš, kdykoli chceš, a třeba pokaždé z jiných surovin.

Proč funkce používat

  • Nemusíš dokola opisovat stejný kód.
  • Když v kódu najdeš chybu, opravíš ji na jednom místě.
  • Velký program rozdělíš na malé části s dobrými jmény a lépe se čte.

Příklad bez funkce

Tři řádky s hlavičkou se tu opakují dvakrát. Kdybys chtěl(a) změnit nápis, musíš opravit obě místa, a čím delší program, tím víc míst.

Ukázka
print("====================")
print("   Školní kalkulačka")
print("====================")
print("Součet:", 2 + 3)

print("====================")
print("   Školní kalkulačka")
print("====================")
print("Součin:", 4 * 5)

Syntaxe: jak funkci napsat a zavolat

Stejný program s funkcí. Opakující se tři řádky se napíšou jednou a pak se jen zavolají jménem.

Ukázka
def hlavicka():
    print("====================")
    print("   Školní kalkulačka")
    print("====================")

hlavicka()
print("Součet:", 2 + 3)

hlavicka()
print("Součin:", 4 * 5)

Výstup

====================
   Školní kalkulačka
====================
Součet: 5
====================
   Školní kalkulačka
====================
Součin: 20

Definice není volání

Řádek def funkci jen vytvoří, nic se při něm nevypíše. Tělo se provede, až když funkci zavoláš. Zkus smazat obě volání hlavicka() a program neudělá nic z hlavičky. Python čte shora dolů, takže funkce musí být definovaná dřív, než ji poprvé zavoláš.

Parametry a volání

Funkce, která dělá pokaždé totéž, je užitečná málo. Mnohem lepší je, když jí při volání předáš vstup a ona s ním pracuje.

Jeden parametr

Ukázka
def pozdrav(jmeno):
    print("Ahoj,", jmeno)

pozdrav("Eliška")
pozdrav("Tomáš")

Výstup

Ahoj, Eliška
Ahoj, Tomáš

jmeno v závorkách u def je parametr: jméno, pod kterým funkce vidí vstup. Hodnota, kterou při volání dosadíš ("Eliška"), se jmenuje argument. Parametr je jako prázdná krabička uvnitř funkce, při každém volání do ní Python vloží jiný argument.

Víc parametrů

Parametry se oddělují čárkou a argumenty se při volání přiřadí podle pořadí: první argument do prvního parametru, druhý do druhého.

Ukázka
def odecti(a, b):
    print(f"{a} - {b} = {a - b}")

odecti(10, 3)
odecti(3, 10)
odecti(b=3, a=10)

Výstup

10 - 3 = 7
3 - 10 = -7
10 - 3 = 7

První dvě volání se liší jen pořadím argumentů, a výsledek je jiný. Třetí volání předává argumenty jménem (b=3, a=10), a pak na pořadí nezáleží.

Co všechno může být argument

Argumentem je jakýkoli výraz. Python ho nejdřív vyhodnotí a výsledek teprve předá funkci.

Ukázka
pozdrav("Eliška")             # hodnota přímo
jmeno = "Tomáš"
pozdrav(jmeno)                # proměnná
pozdrav("Ma" + "rie")         # výpočet
pozdrav(input("Jméno: "))     # výsledek jiné funkce

Špatný počet argumentů

Kolik parametrů funkce má, tolik argumentů musíš při volání dát. Jinak Python skončí s TypeError a v hlášce řekne, kolik jich čekal.

Ukázka
pozdrav()                     # TypeError: pozdrav() missing 1 required positional argument: 'jmeno'
pozdrav("Eliška", "Tomáš")    # TypeError: pozdrav() takes 1 positional argument but 2 were given

Vestavěné funkce

Python jich má spoustu a volají se úplně stejně. Některé, třeba len a round, už znáš z minulé lekce. Různé funkce chtějí různý počet argumentů:

VoláníVýsledekCo dělá
len("ahoj")4počet znaků v textu
abs(-7)7absolutní hodnota
max(3, 8, 2)8největší z hodnot (argumentů může být kolik chceš)
round(3.14159, 2)3.14zaokrouhlí na 2 desetinná místa

Všimni si, že tyhle funkce nic nevypisují. Výsledek vrátí, a co s ním bude, je na tobě: vypsat ho (print(len("ahoj"))), uložit do proměnné, nebo ho použít ve výpočtu. Právě to se teď naučíš i u vlastních funkcí.

Návratová hodnota

print hodnotu jen vypíše na obrazovku, program se k ní už nedostane. return hodnotu vrátí tomu, kdo funkci zavolal, a ten ji může uložit, vypsat nebo s ní dál počítat.

Ukázka
def na_druhou(x):
    return x * x

a = na_druhou(5)
print(a)
print(na_druhou(2) + na_druhou(3))

Výstup

25
13

Volání na_druhou(5) se v programu chová jako hodnota 25: dá se uložit do a a dá se sčítat. Kdyby funkce místo return používala print, nešlo by ani jedno.

Vrátit jde cokoli

Funkce může vrátit číslo, text i logickou hodnotu. Funkce, které odpovídají na otázku ano/ne, vracejí True nebo False. Stačí k tomu porovnání z minulé lekce:

Ukázka
def je_sude(n):
    return n % 2 == 0

print(je_sude(4))
print(je_sude(7))

Výstup

True
False

Výraz n % 2 == 0 se vyhodnotí na True, nebo False a právě tuhle hodnotu return vrátí.

Return funkci ukončí

Jakmile se provede return, funkce skončí a řádky pod ním se už neprovedou:

Ukázka
def zkus():
    print("před return")
    return 1
    print("za return")    # tenhle řádek se nikdy neprovede

zkus()

Výstup

před return

Dává to smysl hlavně tehdy, když funkce může skončit už v půlce. To využiješ, až se naučíš podmínky.

Past: funkce bez return

Funkce, která nic nevrací, vrátí speciální hodnotu None (česky „nic“). Je to jedna z nejčastějších chyb začátečníků.

Ukázka
def secti(a, b):
    print(a + b)

x = secti(2, 3)
print("x je", x)

Výstup

5
x je None

Funkce výsledek jen vypsala (to je ta 5), ale nevrátila, takže do x se nic nedostalo.

Proměnné uvnitř funkce

Proměnné vytvořené v těle funkce, včetně parametrů, existují jen uvnitř ní. Venku je Python nezná a ohlásí NameError. Ven se z funkce dostane jedině to, co vrátíš pomocí return.

Ukázka
def vypocet():
    vysledek = 42

vypocet()
print(vysledek)    # NameError: name 'vysledek' is not defined

Volání funkcí

1 Co vypíše?

3 min

Nejdřív nespouštěj. Na papír napiš, co program vypíše. Teprve potom ho spusť a porovnej.

Výchozí kód
def pozdrav(jmeno):
    print("Ahoj,", jmeno)

pozdrav("Eliška")
jmeno = "Tomáš"
pozdrav(jmeno)
pozdrav("Ma" + "rie")
pozdrav(jmeno + "ek")
Nápověda

Tělo funkce se provede při každém volání, ne při def. Argument se nejdřív vyhodnotí (proměnná na svou hodnotu, součet textů na jeden text) a výsledek se uloží do parametru.

Řešení
Ahoj, Eliška
Ahoj, Tomáš
Ahoj, Marie
Ahoj, Tomášek

Funkce se provedla čtyřikrát, jednou za každé volání. Řádek def nevypsal nic. Parametr jmeno uvnitř funkce a proměnná jmeno mimo ni jsou dvě různé věci, i když se jmenují stejně: při druhém volání se hodnota proměnné jen zkopírovala do parametru.

2 Zavolej funkci

4 min

Funkce obsah_obdelniku je hotová. Pod ni napiš tři volání: pro obdélník 4 × 6, pro obdélník 7 × 5 a pro rozměry, které načteš od uživatele.

Výchozí kód
def obsah_obdelniku(a, b):
    print(f"Obdélník {a} × {b} má obsah {a * b}.")

# tvůj kód

Při spuštění zadej například: 3, 5. Pak zkus i jiné hodnoty.

Očekávaný výstup

Obdélník 4 × 6 má obsah 24.
Obdélník 7 × 5 má obsah 35.
Šířka: 3
Výška: 5
Obdélník 3 × 5 má obsah 15.
Nápověda

Volání má tvar obsah_obdelniku(4, 6), argumenty jsou v pořadí parametrů. Pro třetí volání nejdřív načti dvě čísla pomocí int(input(…)) do proměnných a ty pak předej funkci.

Řešení
Řešení
def obsah_obdelniku(a, b):
    print(f"Obdélník {a} × {b} má obsah {a * b}.")

obsah_obdelniku(4, 6)
obsah_obdelniku(7, 5)

sirka = int(input("Šířka: "))
vyska = int(input("Výška: "))
obsah_obdelniku(sirka, vyska)

Argumentem může být číslo i proměnná. Funkci ani nezajímá, odkud hodnoty pocházejí. Zkus ji zavolat jen s jedním argumentem a přečti si hlášku: TypeError ti řekne, který argument chybí.

Vlastní funkce

3 Představení

3 min

Napiš tělo funkce predstav_se(jmeno, vek), která vypíše větu o jedné osobě. Volání pod ní už jsou hotová.

Výchozí kód
def predstav_se(jmeno, vek):
    ...

predstav_se("Eliška", 16)
predstav_se("Tomáš", 17)

Očekávaný výstup

Jmenuji se Eliška a je mi 16 let.
Jmenuji se Tomáš a je mi 17 let.
Nápověda

Uvnitř funkce používej parametry jmeno a vek jako obyčejné proměnné. Větu nejsnáz poskládáš přes f"…". Tři tečky ... nahraď svým kódem.

Řešení
Řešení
def predstav_se(jmeno, vek):
    print(f"Jmenuji se {jmeno} a je mi {vek} let.")

predstav_se("Eliška", 16)
predstav_se("Tomáš", 17)

Parametry nemají hodnotu, dokud funkci nezavoláš. Při každém volání dostanou jiné argumenty a stejné tělo vypíše jinou větu. Přidej třetí volání s vlastním jménem a věkem.

4 Obvod a obsah

5 min

Dopiš dvě funkce, které výsledek vracejí, a nevypisují ho. Výpis zařídí až program pod nimi. Když program spustíš hned, uvidíš Obvod: None. Rozmysli si proč.

Výchozí kód
def obvod_obdelniku(a, b):
    ...

def obsah_obdelniku(a, b):
    ...

print("Obvod:", obvod_obdelniku(4, 6))
print("Obsah:", obsah_obdelniku(4, 6))

Očekávaný výstup

Obvod: 20
Obsah: 24
Nápověda

Místo print použij return. Obvod obdélníku je 2 * (a + b). Funkce bez return vrací None, proto ta první hláška.

Řešení
Řešení
def obvod_obdelniku(a, b):
    return 2 * (a + b)

def obsah_obdelniku(a, b):
    return a * b

print("Obvod:", obvod_obdelniku(4, 6))
print("Obsah:", obsah_obdelniku(4, 6))

Funkce vrátí hodnotu a o tom, co s ní bude, rozhoduje ten, kdo ji zavolal: vypíše ji, uloží, nebo s ní dál počítá. Zkus plocha = obsah_obdelniku(4, 6) a pak print(plocha * 2). S funkcí, která jen vypisuje, by to nešlo.

5 Je plnoletý?

3 min

Napiš funkci je_plnoleta(vek), která vrátí True, když je věk alespoň 18, jinak False. Program pod ní načte věk a výsledek vypíše. Když ho spustíš hned, vypíše None. Rozmysli si proč.

Výchozí kód
def je_plnoleta(vek):
    ...

vek = int(input("Věk: "))
print("Plnoletý:", je_plnoleta(vek))

Při spuštění zadej například: 17. Pak zkus 18 a 25.

Očekávaný výstup

Věk: 17
Plnoletý: False
Nápověda

Funkce má vrátit logickou hodnotu, ne ji vypsat. Porovnání z minulé lekce je samo o sobě True nebo False: zkus si print(17 >= 18). Tři tečky ... nahraď svým kódem.

Řešení
Řešení
def je_plnoleta(vek):
    return vek >= 18

vek = int(input("Věk: "))
print("Plnoletý:", je_plnoleta(vek))

Výraz vek >= 18 se vyhodnotí na True, nebo False a return ho vrátí. Dokud v těle funkce nebylo return, vracela funkce None, proto se na začátku vypsalo Plnoletý: None. Hotová funkce se dá použít jako hodnota: print(je_plnoleta(20) and je_plnoleta(30)). V příští lekci ji využiješ v podmínce.

6 Najdi a oprav chyby

5 min

V programu jsou tři chyby. Funkce má spočítat průměr dvou čísel. Spusť program, přečti si hlášku, oprav jednu chybu a spusť znovu.

Výchozí kód
def prumer(a, b)
    soucet = a + b
return soucet / 2

prumer(4, 9)
print("Průměr je", vysledek)

Očekávaný výstup

Průměr je 6.5
Nápověda

Postupuj podle hlášek jednu po druhé. První se týká řádku s def, druhá slova return (co patří do funkce, musí být odsazené), třetí proměnné vysledek. Hodnotu, kterou funkce vrátí, musíš při volání někam uložit.

Řešení
Řešení
def prumer(a, b):
    soucet = a + b
    return soucet / 2

vysledek = prumer(4, 9)
print("Průměr je", vysledek)

1) Na konci řádku s def chyběla dvojtečka: SyntaxError. 2) return nebyl odsazený, a proto nepatřil do funkce: SyntaxError: 'return' outside function. 3) Funkce sice vrátila 6.5, ale nikdo si hodnotu nezapamatoval, proměnná vysledek proto neexistuje: NameError. Vrácenou hodnotu ulož (vysledek = prumer(4, 9)), nebo ji rovnou použij (print(prumer(4, 9))).

7 Proč tam stojí None?

4 min

Program má vypsat čtvrtinu ze 100. Místo toho vypíše jedno číslo a skončí chybou. Přečti si hlášku, zjisti, co se stalo, a oprav jedno místo.

Výchozí kód
def polovina(x):
    print(x / 2)

def ctvrtina(x):
    return polovina(polovina(x))

print("Čtvrtina ze 100 je", ctvrtina(100))

Očekávaný výstup

Čtvrtina ze 100 je 25.0
Nápověda

V hlášce je NoneType. None je hodnota „nic“, kterou vrací funkce bez return. Co dostane vnější polovina, když vnitřní nic nevrátí? A co s tím pak udělá?

Řešení
Řešení
def polovina(x):
    return x / 2

def ctvrtina(x):
    return polovina(polovina(x))

print("Čtvrtina ze 100 je", ctvrtina(100))

Vnitřní polovina(100) jen vypsala 50.0 a nic nevrátila. Vnější polovina proto dostala None a zkusila ho dělit dvěma: TypeError: unsupported operand type(s) for /: 'NoneType' and 'int'. Po záměně print za return se výsledek vnitřního volání předá vnějšímu. Pravidlo: když chceš výsledek funkce dál používat, funkce ho musí vrátit, nestačí ho vypsat.

8 Převodník času

8 min

Pamatuješ úkol Kolik je to hodin? z první lekce? Tehdy ses musel(a) pokaždé přepsat číslo přímo v programu. Udělej z něj funkci na_cas(sekundy), která vrátí text ve tvaru 1 h 2 min 5 s. Tři volání pod ní ji vyzkoušejí.

Výchozí kód
def na_cas(sekundy):
    ...

print(na_cas(3725))
print(na_cas(59))
print(na_cas(100000))

Očekávaný výstup

1 h 2 min 5 s
0 h 0 min 59 s
27 h 46 min 40 s
Nápověda

Vezmi řešení úkolu Kolik je to hodin? z první lekce a vlož ho do těla funkce (odsazené). Číslo 3725 nahraď parametrem sekundy. Místo print na konci použij return a text poskládej f-řetězcem.

Řešení
Řešení
def na_cas(sekundy):
    hodiny = sekundy // 3600
    zbytek = sekundy % 3600
    minuty = zbytek // 60
    zbytek = zbytek % 60
    return f"{hodiny} h {minuty} min {zbytek} s"

print(na_cas(3725))
print(na_cas(59))
print(na_cas(100000))

Hotový výpočet jsi jen „zabalil(a)“ do funkce. Teď ho zavoláš pro libovolné číslo a nemusíš nic přepisovat. Proměnné hodiny, zbytek a minuty existují jen uvnitř funkce, ven se dostane jen to, co vrátí return. Zkus místo textu vrátit tři hodnoty najednou: return hodiny, minuty, zbytek.

Hotovo? Vrať se k úkolu, který ti dal nejvíc práce, a zkus ho napsat znovu bez nápovědy. Tak se to naučíš nejrychleji.
