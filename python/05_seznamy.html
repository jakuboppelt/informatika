Python: seznamy

Navazuje na větvení a cykly. Naučíš se uložit víc hodnot do jedné proměnné, sáhnout na konkrétní hodnotu a projít je všechny cyklem. Nejdřív krátký výklad s ukázkami, potom úkoly. Jak programy psát a spouštět, najdeš v prvních krocích.

Úkolů5 + 1 bonus, od nejlehčího
Časjedna vyučovací hodina
Když se zaseknešpřečti chybu, pak Nápověda, až nakonec Řešení

Výklad

Proč seznamy

Seznam je jedna proměnná, ve které je víc hodnot najednou. Bez něj potřebuje každá hodnota vlastní proměnnou. Představ si, že chceš spočítat průměr známek:

Ukázka
znamka1 = 1
znamka2 = 3
znamka3 = 2
znamka4 = 1
znamka5 = 4

prumer = (znamka1 + znamka2 + znamka3 + znamka4 + znamka5) / 5
print(prumer)

Co když známek bude 30? Nebo když předem nevíš, kolik jich bude? Takhle to nejde. Se seznamem stačí jedna proměnná:

Ukázka
znamky = [1, 3, 2, 1, 4]

Vytvoření a indexy

Hodnoty píšeš do hranatých závorek a oddělíš je čárkou. V seznamu můžou být čísla, texty, cokoli.

Ukázka
znamky = [1, 3, 2, 1, 4]
jmena = ["Anna", "Petr", "Eva"]
prazdny = []

print(znamky)
print(jmena)

Výstup

[1, 3, 2, 1, 4]
['Anna', 'Petr', 'Eva']

Každá hodnota má své pořadové číslo, index. Pozor: počítá se od nuly. Na hodnotu sáhneš tak, že index napíšeš do hranatých závorek za jméno seznamu.

Index012
Hodnota"Anna""Petr""Eva"
Záporný index-3-2-1
Ukázka
jmena = ["Anna", "Petr", "Eva"]

print(jmena[0])
print(jmena[2])
print(jmena[-1])

Výstup

Anna
Eva
Eva

Záporný index počítá od konce: [-1] je vždy poslední prvek, ať je seznam jakkoli dlouhý.

Index mimo seznam

Když sáhneš na index, který neexistuje, třeba jmena[3], program skončí s chybou IndexError: list index out of range. Seznam se třemi prvky má indexy jen 0, 1 a 2.

Změna, append a len

Změna hodnoty

Přes index můžeš hodnotu i přepsat, stejně jako přiřazuješ do proměnné.

Ukázka
jmena = ["Anna", "Petr", "Eva"]
jmena[1] = "Pavel"
print(jmena)

Výstup

['Anna', 'Pavel', 'Eva']

Přidání na konec

append přidá hodnotu na konec seznamu. Píše se s tečkou za jménem seznamu: seznam si hodnotu „přidá sám do sebe“.

Ukázka
jmena = ["Anna", "Pavel", "Eva"]
jmena.append("Jan")
print(jmena)

Výstup

['Anna', 'Pavel', 'Eva', 'Jan']

Typicky začneš s prázdným seznamem [] a hodnoty do něj postupně přidáváš, třeba podle toho, co zadá uživatel.

Délka seznamu

len už znáš u textu, kde vrací počet znaků. U seznamu vrací počet prvků.

Ukázka
jmena = ["Anna", "Pavel", "Eva", "Jan"]
print(len(jmena))
print(jmena[len(jmena) - 1])

Výstup

4
Jan

Poslední index je vždy o jedna menší než délka: seznam se 4 prvky má indexy 0 až 3.

Procházení cyklem

Cyklus for umí projít seznam prvek po prvku. V každém kole je v proměnné cyklu jedna hodnota ze seznamu.

Ukázka
jmena = ["Anna", "Petr", "Eva"]

for jmeno in jmena:
    print("Ahoj", jmeno)

Výstup

Ahoj Anna
Ahoj Petr
Ahoj Eva

Čti to jako: „pro každé jméno v seznamu jmen udělej…“. Jméno proměnné cyklu (jmeno) si vymýšlíš sám. Zvykem je jednotné číslo od jména seznamu: znamky → znamka.

Už znáš for i in range(5). Teď je vidět, co range vlastně dělá: vyrobí řadu čísel 0, 1, 2, 3, 4, kterou cyklus prochází stejně jako seznam.

Seznam a podmínka

Ukázka
znamky = [1, 3, 2, 5, 4]

for znamka in znamky:
    if znamka == 5:
        print("Pozor, pětka!")

Výstup

Pozor, pětka!

Typické postupy

Většina programů se seznamy dělá jednu ze čtyř věcí. Všechny mají stejný vzor: před cyklem si připravíš proměnnou, v cyklu ji upravuješ, po cyklu vypíšeš výsledek.

Součet a průměr

Ukázka
znamky = [1, 3, 2, 1, 4]

soucet = 0
for znamka in znamky:
    soucet = soucet + znamka

prumer = soucet / len(znamky)
print("Průměr:", prumer)

Výstup

Průměr: 2.2

Největší hodnota

Začneš prvním prvkem a pak hledáš, jestli není něco většího.

Ukázka
teploty = [12, 18, 15, 21, 9]

nejvetsi = teploty[0]
for t in teploty:
    if t > nejvetsi:
        nejvetsi = t

print("Nejtepleji bylo", nejvetsi, "stupňů.")

Výstup

Nejtepleji bylo 21 stupňů.

Počítání

Ukázka
znamky = [1, 3, 1, 5, 1, 2]

jednicek = 0
for znamka in znamky:
    if znamka == 1:
        jednicek = jednicek + 1

print("Počet jedniček:", jednicek)

Výstup

Počet jedniček: 3

Hledání

Jestli je hodnota v seznamu, zjistíš pomocí in. Výsledek je True, nebo False, takže se hodí rovnou do podmínky.

Ukázka
nakup = ["mléko", "chleba", "vejce"]

if "chleba" in nakup:
    print("Chleba nezapomeň!")

Výstup

Chleba nezapomeň!
Hotové funkce

Python umí sum(znamky), max(teploty) a min(teploty) i sám. V úkolech je ale nejdřív napiš cyklem: právě na tom se naučíš, jak procházení funguje. Hotové funkce pak můžeš klidně používat.

Indexy

1 Co vypíše?

5 min

Nejdřív si na papír napiš, co program vypíše. Teprve potom ho spusť a porovnej.

Výchozí kód
barvy = ["červená", "zelená", "modrá", "žlutá"]

print(barvy[1])
print(barvy[-1])
print(len(barvy))

barvy[0] = "černá"
barvy.append("bílá")
print(barvy)
print(barvy[len(barvy) - 1])

Očekávaný výstup

zelená
žlutá
4
['černá', 'zelená', 'modrá', 'žlutá', 'bílá']
bílá
Nápověda

Indexy začínají nulou, takže barvy[1] je druhá barva. [-1] je poslední. Po append má seznam o prvek víc.

Řešení
Řešení
barvy = ["červená", "zelená", "modrá", "žlutá"]

print(barvy[1])      # zelená – index 1 je druhý prvek
print(barvy[-1])     # žlutá – poslední prvek
print(len(barvy))    # 4

barvy[0] = "černá"
barvy.append("bílá")
print(barvy)
print(barvy[len(barvy) - 1])   # bílá – teď je seznam dlouhý 5

Nejčastější omyl je barvy[1] = „červená“. Druhá častá chyba je u posledního řádku: po append je délka 5, takže poslední index je 4.

Procházení

2 Vysvědčení

7 min

Máš seznam známek. Spočítej a vypiš průměr a počet pětek. Nepoužívej sum, napiš to cyklem.

Výchozí kód
znamky = [2, 1, 5, 3, 5, 1, 2, 1]

soucet = 0
petek = 0

# sem napiš cyklus

print("Průměr:", soucet / len(znamky))
print("Počet pětek:", petek)

Očekávaný výstup

Průměr: 2.5
Počet pětek: 2
Nápověda

V jednom cyklu můžeš dělat dvě věci zároveň: každou známku přičti do soucet a pak se podmínkou zeptej, jestli je to pětka. Pokud ano, zvyš petek o 1.

Řešení
Řešení
znamky = [2, 1, 5, 3, 5, 1, 2, 1]

soucet = 0
petek = 0

for znamka in znamky:
    soucet = soucet + znamka
    if znamka == 5:
        petek = petek + 1

print("Průměr:", soucet / len(znamky))
print("Počet pětek:", petek)

Pořadí je pořád stejné: příprava před cyklem, práce v cyklu, výpis po cyklu. Přičítání je odsazené jen o jednu úroveň, takže se provede pro každou známku. Zvýšení petek je odsazené víc, provede se jen u pětek.

3 Nejteplejší den

7 min

Máš naměřené teploty za týden a seznam dnů. Najdi nejvyšší a nejnižší teplotu. Nepoužívej max ani min.

Výchozí kód
teploty = [12, 18, 15, 21, 9, 14, 17]

nejvyssi = teploty[0]
nejnizsi = teploty[0]

# sem napiš cyklus

print("Nejvyšší teplota:", nejvyssi)
print("Nejnižší teplota:", nejnizsi)

Očekávaný výstup

Nejvyšší teplota: 21
Nejnižší teplota: 9
Nápověda

Projdi všechny teploty. Když je aktuální teplota větší než nejvyssi, ulož ji do nejvyssi. U nejnižší to samé, jen obráceně.

Řešení
Řešení
teploty = [12, 18, 15, 21, 9, 14, 17]

nejvyssi = teploty[0]
nejnizsi = teploty[0]

for t in teploty:
    if t > nejvyssi:
        nejvyssi = t
    if t < nejnizsi:
        nejnizsi = t

print("Nejvyšší teplota:", nejvyssi)
print("Nejnižší teplota:", nejnizsi)

Proč začínat teploty[0] a ne nulou? Kdyby všechny teploty byly pod nulou, maximum by vyšlo 0, i když taková teplota v seznamu vůbec není.

4 Nákupní seznam

8 min

Program se opakovaně ptá, co koupit, a ukládá to do seznamu. Když uživatel jen zmáčkne Enter, ptaní skončí. Pak program vypíše počet položek a celý seznam, každou položku na samostatný řádek.

Výchozí kód
nakup = []

polozka = input("Co koupit? (Enter = konec) ")

Při spuštění zadej například: mléko, chleba, vejce a nakonec jen Enter. Pak zkus i jiné hodnoty.

Očekávaný výstup

Co koupit? (Enter = konec) mléko
Co koupit? (Enter = konec) chleba
Co koupit? (Enter = konec) vejce
Co koupit? (Enter = konec) 
Na seznamu jsou 3 věci:
- mléko
- chleba
- vejce
Nápověda

Použij while jako v úloze „Sčítej, dokud nezadám nulu“: první položku načti před cyklem, v cyklu ji přidej pomocí append a načti další. Prázdný vstup je prázdný text "". Výpis je druhý, samostatný cyklus for až po skončení while.

Řešení
Řešení
nakup = []

polozka = input("Co koupit? (Enter = konec) ")
while polozka != "":
    nakup.append(polozka)
    polozka = input("Co koupit? (Enter = konec) ")

print("Na seznamu jsou", len(nakup), "věci:")
for polozka in nakup:
    print("-", polozka)

Tady se poprvé seznam neplní ručně, ale za běhu programu. Program předem neví, kolik položek bude, a se seznamem to nevadí. Prázdný text se do seznamu nedostane, protože cyklus skončí dřív, než by se přidal.

5 Pizza pro třídu 3

8 min

Pamatuješ na pizzu pro třídu? Tentokrát nechce každý stejně. Každý student napsal, kolik kousků sní, a jedna pizza má 8 kousků. Spočítej, kolik kousků je potřeba celkem, kolik celých pizz objednat, aby se dostalo na všechny, a kolik kousků zbyde.

Výchozí kód
kousky = [3, 2, 4, 3, 5, 2, 3, 4]
kousku_v_pizze = 8

Očekávaný výstup

Celkem kousků: 26
Je potřeba koupit 4 pizzy.
Zbyde 6 kousků.
Nápověda

Nejdřív cyklem sečti kousky ze seznamu. Pak je to stejné jako minule: // dá počet celých pizz a % zbytek. Když zbytek není nula, musíš přiobjednat ještě jednu pizzu.

Řešení
Řešení
kousky = [3, 2, 4, 3, 5, 2, 3, 4]
kousku_v_pizze = 8

celkem = 0
for k in kousky:
    celkem = celkem + k

pizzy = celkem // kousku_v_pizze
zbytek = celkem % kousku_v_pizze
if zbytek > 0:
    pizzy = pizzy + 1

print("Celkem kousků:", celkem)
print("Je potřeba koupit", pizzy, "pizzy.")
print("Zbyde", pizzy * kousku_v_pizze - celkem, "kousků.")

26 kousků jsou 3 celé pizzy (24 kousků) a 2 kousky navíc, takže objednáš 4 pizzy a 6 kousků zbyde. Vyzkoušej přidat do seznamu studenta, který sní 6 kousků: pak to vyjde přesně na 4 pizzy a nic nezbyde.

Bonus

6 Kdo sní nejvíc?

8 min

K pizze přidej seznam jmen. Jméno a počet kousků na stejném indexu patří k sobě: Anna sní 3, Petr 2 a tak dál. Vypiš, kdo sní nejvíc kousků. Když je jich víc se stejným počtem, vypiš všechny.

Výchozí kód
jmena = ["Anna", "Petr", "Eva", "Jan", "Ota", "Lucie", "Tom", "Ema"]
kousky = [3, 2, 4, 3, 5, 2, 3, 4]

Očekávaný výstup

Ota sní 5 kousků.
Nápověda

Úkol má dva kroky. Nejdřív najdi největší počet kousků, jako v úloze 3. Pak potřebuješ procházet oba seznamy najednou, a to jde přes indexy: for i in range(len(kousky)):. Uvnitř máš jmena[i] a kousky[i].

Řešení
Řešení
jmena = ["Anna", "Petr", "Eva", "Jan", "Ota", "Lucie", "Tom", "Ema"]
kousky = [3, 2, 4, 3, 5, 2, 3, 4]

nejvic = kousky[0]
for k in kousky:
    if k > nejvic:
        nejvic = k

for i in range(len(kousky)):
    if kousky[i] == nejvic:
        print(jmena[i], "sní", kousky[i], "kousků.")

for x in seznam dává hodnoty, for i in range(len(seznam)) dává indexy. Indexy potřebuješ, když procházíš dva seznamy, které k sobě patří. Zkus Evě změnit počet na 5: program vypíše dvě jména.

Hotovo? Vrať se k úkolu, který ti dal nejvíc práce, a zkus ho napsat znovu bez nápovědy. Tak se to naučíš nejrychleji.
