Python: první kroky

Krátké úlohy pro úplné začátečníky: výpis, proměnné a vstup. Programy píšeš a spouštíš u sebe na počítači, výchozí kód si zkopíruješ jedním kliknutím.

Úkolů12, od nejlehčího
Časjedna vyučovací hodina
Když se zaseknešpřečti chybu, pak Nápověda, až nakonec Řešení

Jak pracovat

  1. Otevři editor pro Python. Ve škole použij Python IDLE, který je na školních počítačích nainstalovaný (najdeš ho v nabídce Start). Doma doporučuji Visual Studio Code, postup instalace a prvního programu najdeš v návodu Getting Started with Python in VS Code. Kromě samotného VS Code musíš mít nainstalovaný ještě Python 3 a rozšíření Python pro VS Code (jak se instalují rozšíření, viz Extension Marketplace). Pokud chceš začít jednodušeji, poslouží stejně dobře Thonny, který má Python rovnou v sobě a nic dalšího nepotřebuje. Je jedno, co si vybereš.
  2. Pro každou úlohu si založ nový soubor, třeba uloha01.py. Výchozí kód zkopíruj tlačítkem Kopírovat a vlož ho do souboru.
  3. Program spustíš v IDLE a v Thonny klávesou F5, ve VS Code tlačítkem ▷ Run Python File vpravo nahoře. Výstup se v IDLE objeví v samostatném okně Shell, v Thonny v panelu Shell a ve VS Code v panelu Terminal dole.
  4. Když program chce něco od uživatele (input), zastaví se a čeká. Napiš odpověď a stiskni Enter.
  5. Odsazuj klávesou Tab. Editor odsadí o čtyři mezery a za dvojtečkou odsadí nový řádek sám. V Pythonu na odsazení záleží.
  6. Program, který se zasekl (třeba v nekonečném cyklu), zastavíš klávesami Ctrl + C nebo tlačítkem Stop.
  7. Řešení si otevři až po vlastním pokusu. Je jen jedno z možných, tvoje může vypadat jinak a být správně.
Chyba není trest

Chybová hláška je anglicky a nejdůležitější je její poslední řádek: typ chyby a popis. O řádek výš je číslo řádku v tvém programu (line 3). Naučit se hlášky číst je půlka programování, tahák níž ti s tím pomůže.

Tahák

ZápisCo dělá
print("Ahoj", x)vypíše hodnoty na jeden řádek, oddělené mezerou
print()vypíše prázdný řádek
x = 5uloží hodnotu do proměnné x
"jmeno" × jmenov uvozovkách je text, bez nich jméno proměnné
moje_jmenojméno proměnné: bez mezer, nezačíná číslicí, velká a malá písmena se liší
+ - * /sčítání, odčítání, násobení, dělení (výsledek je desetinné číslo)
// %celočíselné dělení a zbytek: 17 // 5 je 3, 17 % 5 je 2
input("Otázka: ")zeptá se uživatele, vrátí text
int(text)převede text na celé číslo
f"Je mi {vek} let"vloží hodnotu proměnné do textu

Nejčastější chyby

HláškaCo obvykle znamená
SyntaxErrorPython větě nerozumí: chybí uvozovka, závorka, čárka nebo dvojtečka.
IndentationErrorŠpatné odsazení: chybí za if, for nebo while, nebo je navíc.
NameErrorPython nezná to jméno: překlep, velké písmeno, nebo proměnná ještě nemá hodnotu.
TypeErrorMíchání typů, třeba text + číslo. Často chybí int(…).
ValueErrorint dostal text, který není číslo.

Výpis

1 Ahoj, světe!

2 min

Program už jeden řádek vypisuje. Zkopíruj ho do editoru, ulož a spusť (F5). Pak ho doplň tak, aby vypsal přesně tyto tři řádky, jen s tvým jménem.

Výchozí kód
# Řádek začínající # je komentář, Python ho přeskočí.
print("Ahoj, světe!")

Očekávaný výstup

Ahoj, světe!
Jmenuji se Eliška.
Učím se Python.
Nápověda

Každý příkaz print vypíše jeden řádek. Text patří do uvozovek a celý do kulatých závorek.

Řešení
Řešení
print("Ahoj, světe!")
print("Jmenuji se Eliška.")
print("Učím se Python.")

Tři příkazy, tři řádky. Python provádí příkazy shora dolů, jeden po druhém.

2 Najdi a oprav chyby

4 min

V programu jsou tři chyby, na každém řádku jedna. Spusť ho a přečti si, co Python hlásí. Hláška ti řekne číslo řádku. Oprav jednu chybu, spusť znovu a pokračuj.

Výchozí kód
Print("Dobrý den")
print("Dnes je pátek)
print("Výsledek je" 5)

Očekávaný výstup

Dobrý den
Dnes je pátek
Výsledek je 5
Nápověda

Python rozlišuje velká a malá písmena. Každé uvozovky se musí zavřít. Když chceš v print vypsat víc věcí za sebou, odděl je čárkou.

Řešení
Řešení
print("Dobrý den")
print("Dnes je pátek")
print("Výsledek je", 5)

1) Print a print jsou pro Python dvě různá slova a zná jen to druhé. 2) Chyběly koncové uvozovky. 3) Chyběla čárka mezi textem a číslem. Všimni si, že print mezi ně sám vloží mezeru.

Proměnné

3 Uvozovky, nebo ne?

3 min

Nejdřív nespouštěj. Na papír napiš, co vypíše každý řádek. Teprve potom program spusť a porovnej.

Výchozí kód
jmeno = "Eliška"
print("jmeno")
print(jmeno)
print("2 + 3")
print(2 + 3)
print(jmeno, "má", 2 + 3, "jablek")
Nápověda

Uvozovky znamenají: tohle je text, vypiš ho přesně tak, jak je napsaný. Co je bez uvozovek, Python nejdřív vyhodnotí.

Řešení
jmeno
Eliška
2 + 3
5
Eliška má 5 jablek

V uvozovkách je text a vypíše se doslova. Bez uvozovek je to buď jméno proměnné (vypíše se, co je v ní uložené), nebo výpočet (vypíše se výsledek). Číslo 5 a text "5" vypadají ve výpisu stejně, ale pro Python to jsou dvě různé věci.

4 Vizitka

5 min

V programu jsou uložené údaje o člověku. Vypiš z nich vizitku. Do print už jméno, věk ani město přímo nepiš, používej jen proměnné. Když pak změníš první čtyři řádky, vypíše se vizitka někoho jiného.

Výchozí kód
jmeno = "Eliška"
prijmeni = "Nováková"
vek = 16
mesto = "Brno"

print("=== VIZITKA ===")
# tvůj kód

Očekávaný výstup

=== VIZITKA ===

Jméno: Eliška Nováková
Věk: 16 let
Město: Brno
Nápověda

Do print můžeš dát víc věcí oddělených čárkou, mezi každé dvě vloží mezeru: print("Jméno:", jmeno, prijmeni). Prázdný řádek vypíše print() bez ničeho. Text s proměnnou uvnitř napíšeš i jako f-řetězec: f"Věk: {vek} let".

Řešení
Řešení
jmeno = "Eliška"
prijmeni = "Nováková"
vek = 16
mesto = "Brno"

print("=== VIZITKA ===")
print()
print("Jméno:", jmeno, prijmeni)
print(f"Věk: {vek} let")
print("Město:", mesto)

Proměnnou do výpisu dostaneš dvěma způsoby: čárkou v print, nebo f-řetězcem, kde ji napíšeš do složených závorek. Všimni si, že text se ukládá v uvozovkách ("Brno") a číslo bez nich (16). Zkus přepsat údaje nahoře na své a spustit znovu.

5 Špatná jména proměnných

4 min

Program má čtyři chyby a všechny se týkají jmen proměnných. Spusť ho, přečti hlášku, oprav jednu chybu a spusť znovu.

Výchozí kód
moje jmeno = "Tomáš"
1trida = "1.A"
mesto = "Praha"
print(moje jmeno, "chodí do", 1trida)
print("Město:", Mesto)
print("Škola:", skola)

Očekávaný výstup

Tomáš chodí do 1.A
Město: Praha
Škola: Gymnázium
Nápověda

Jméno proměnné nesmí obsahovat mezeru (místo ní se píše podtržítko _) a nesmí začínat číslicí. Python rozlišuje velká a malá písmena. Proměnnou můžeš vypsat až poté, co do ní něco uložíš.

Řešení
Řešení
moje_jmeno = "Tomáš"
trida = "1.A"
mesto = "Praha"
skola = "Gymnázium"
print(moje_jmeno, "chodí do", trida)
print("Město:", mesto)
print("Škola:", skola)

1) Mezera ve jméně: SyntaxError. 2) Jméno začíná číslicí: SyntaxError. 3) Mesto a mesto jsou dvě různé proměnné, Mesto neexistuje: NameError. 4) Do skola nikdo nic neuložil: NameError. Dobré jméno proměnné je psané malými písmeny, bez diakritiky, se slovy oddělenými podtržítkem a je z něj poznat, co v proměnné je.

6 Co vypíše?

3 min

Nejdřív nespouštěj. Na papír napiš, jaká tři čísla program vypíše. Teprve potom ho spusť a porovnej.

Výchozí kód
a = 5
b = a
a = a + 3
print(a)
print(b)
print(a * b)
Nápověda

Rovnítko v Pythonu neznamená rovnost, ale ulož: vyhodnoť pravou stranu a výsledek ulož do proměnné vlevo. Co se stane s b, když později změníš a?

Řešení
8
5
40

b = a uloží do b hodnotu, kterou má a právě teď, tedy 5. Pozdější změna a už b neovlivní. Zápis a = a + 3 čti zprava: vezmi starou hodnotu a, přičti 3 a výsledek ulož zpět do a.

7 Prohoď hodnoty

4 min

Prohoď obsah dvou proměnných, aby v leva byla hruška a v prava jablko. Slova "jablko" a "hruška" už v programu znovu napsat nesmíš.

Výchozí kód
leva = "jablko"
prava = "hruška"
print("Před:", leva, prava)

# tvůj kód

print("Po:", leva, prava)

Očekávaný výstup

Před: jablko hruška
Po: hruška jablko
Nápověda

Zkus nejdřív leva = prava a podívej se, co se pokazí. Jak vyměníš obsah dvou plných sklenic? Potřebuješ třetí, prázdnou.

Řešení
Řešení
leva = "jablko"
prava = "hruška"
print("Před:", leva, prava)

pomocna = leva
leva = prava
prava = pomocna

print("Po:", leva, prava)

Kdybys hned napsal(a) leva = prava, jablko by se ztratilo a v obou proměnných by byla hruška. Proto si ho nejdřív odložíš do pomocné proměnné. Python umí i zkratku leva, prava = prava, leva, ale postup s pomocnou proměnnou funguje v každém programovacím jazyce.

8 Pizza pro třídu

5 min

Třída má 28 studentů, každý sní 3 kousky a jedna pizza má 8 kousků. Doplň program tak, aby spočítal a vypsal, kolik kousků se sní celkem, kolik je to celých pizz a kolik kousků zbývá do další pizzy.

Výchozí kód
studentu = 28
kousku_na_studenta = 3
kousku_v_pizze = 8

kousku = 0        # oprav
cele_pizzy = 0    # oprav
zbyva = 0         # oprav

print("Kousků celkem:", kousku)
print("Celých pizz:", cele_pizzy)
print("Kousků navíc:", zbyva)

Očekávaný výstup

Kousků celkem: 84
Celých pizz: 10
Kousků navíc: 4
Nápověda

Kromě + - * / má Python ještě // (celočíselné dělení: 17 // 5 je 3) a % (zbytek po dělení: 17 % 5 je 2).

Řešení
Řešení
studentu = 28
kousku_na_studenta = 3
kousku_v_pizze = 8

kousku = studentu * kousku_na_studenta
cele_pizzy = kousku // kousku_v_pizze
zbyva = kousku % kousku_v_pizze

print("Kousků celkem:", kousku)
print("Celých pizz:", cele_pizzy)
print("Kousků navíc:", zbyva)

84 kousků je 10 celých pizz a 4 kousky navíc, takže objednat je potřeba 11. Zkus změnit počet studentů: díky proměnným se všechno přepočítá samo. Zkus také obyčejné dělení /: dostaneš 10.5, desetinné číslo.

9 Kolik je to hodin?

4 min

Stopky ukazují počet sekund. Převeď ho na hodiny, minuty a sekundy. Program musí fungovat pro libovolné číslo, ne jen pro 3725.

Výchozí kód
sekundy = 3725

# tvůj kód

print(hodiny, "h", minuty, "min", zbytek, "s")

Očekávaný výstup

1 h 2 min 5 s
Nápověda

Kolik celých hodin je v 3725 sekundách? 3725 // 3600. Kolik sekund zbude? 3725 % 3600. Se zbytkem udělej totéž pro minuty.

Řešení
Řešení
sekundy = 3725
hodiny = sekundy // 3600
zbytek = sekundy % 3600
minuty = zbytek // 60
zbytek = zbytek % 60
print(hodiny, "h", minuty, "min", zbytek, "s")

Postupně „ukusuješ“ největší jednotky a se zbytkem pracuješ dál. Pro 100000 sekund vyjde 27 h 46 min 40 s.

10 Pozdrav

3 min

Funkce input se zeptá uživatele a vrátí, co napsal. Program se zastaví a čeká, až odpověď napíšeš a stiskneš Enter. Doplň program tak, aby pozdravil jménem a zeptal se i na oblíbené jídlo.

Výchozí kód
jmeno = input("Jak se jmenuješ? ")
print(f"Ahoj, {jmeno}!")

Při spuštění zadej například: Eliška, svíčková. Pak zkus i jiné hodnoty.

Očekávaný výstup

Jak se jmenuješ? Eliška
Co rád(a) jíš? svíčková
Ahoj, Eliška!
Mňam, svíčková!
Nápověda

Do f"…" řetězce vložíš proměnnou tak, že ji napíšeš do složených závorek: f"Ahoj, {jmeno}!".

Řešení
Řešení
jmeno = input("Jak se jmenuješ? ")
jidlo = input("Co rád(a) jíš? ")
print(f"Ahoj, {jmeno}!")
print(f"Mňam, {jidlo}!")

input zastaví program, dokud uživatel neodpoví. Text otázky je dobré ukončit mezerou, jinak se odpověď nalepí hned za otazník.

11 Proč je 5 + 3 = 53?

4 min

Program má sečíst dvě čísla, ale pro 5 a 3 vypíše 53. Spusť ho, zjisti proč a oprav ho.

Výchozí kód
a = input("První číslo: ")
b = input("Druhé číslo: ")
print("Součet je", a + b)

Při spuštění zadej například: 5, 3. Pak zkus i jiné hodnoty.

Očekávaný výstup

První číslo: 5
Druhé číslo: 3
Součet je 8
Nápověda

input vždycky vrací text, i když uživatel napíše číslice. Text a text se „sčítá“ tak, že se slepí. Funkce int(…) převede text na celé číslo.

Řešení
Řešení
a = int(input("První číslo: "))
b = int(input("Druhé číslo: "))
print("Součet je", a + b)

Hodnoty mají typ: "5" je text (str), 5 je celé číslo (int), 5.0 desetinné číslo (float). Zkus místo čísla napsat pět: int takový text převést neumí a ohlásí ValueError.

12 Kdy ti bude sto?

4 min

Zeptej se na rok narození a vypiš, kolik let ti bude letos (2026) a ve kterém roce oslavíš sté narozeniny.

Výchozí kód
rok = 0  # načti od uživatele

Při spuštění zadej například: 2010. Pak zkus i jiné hodnoty.

Očekávaný výstup

Rok narození: 2010
Letos ti bude 16 let.
Sto ti bude v roce 2110.
Nápověda

Načti rok jako číslo (vzpomeň si na minulý úkol). Věk letos je rozdíl dvou letopočtů, sté narozeniny jsou rok narození plus sto.

Řešení
Řešení
rok = int(input("Rok narození: "))
letos = 2026
print(f"Letos ti bude {letos - rok} let.")
print(f"Sto ti bude v roce {rok + 100}.")

Uložit 2026 do proměnné letos je lepší než psát číslo přímo do výpočtu: za rok změníš jedno místo a pojmenovaná hodnota se líp čte.

Hotovo? Vrať se k úkolu, který ti dal nejvíc práce, a zkus ho napsat znovu bez nápovědy. Tak se to naučíš nejrychleji.
