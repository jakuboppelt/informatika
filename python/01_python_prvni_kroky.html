Python: první kroky

Krátké úlohy pro úplné začátečníky: výpis, proměnné, vstup, podmínky a cykly. Každá úloha má vlastní editor, ve kterém Python běží přímo v prohlížeči. Nic se neinstaluje a nic se nikam neodesílá.

Úkolů14 + 1 bonus, od nejlehčího
Časdvě vyučovací hodiny
Když se zaseknešpřečti chybu, pak Nápověda, až nakonec Řešení

Jak pracovat

  • Program spustíš tlačítkem ▶ Spustit nebo zkratkou Ctrl + Enter. Poprvé se Python pár sekund načítá.
  • Klávesa Tab v editoru odsadí řádek o čtyři mezery, Shift + Tab odsazení ubere. V Pythonu na odsazení záleží.
  • Když program chce něco od uživatele (input), vezme si odpověď z pole Vstup, každý řádek je jedna odpověď. Vstup si klidně přepiš a zkoušej různé hodnoty.
  • Chybová hláška není trest. Řekne ti číslo řádku a druh chyby. Naučit se ji číst je půlka programování.
  • Řešení si otevři až po vlastním pokusu. Je jen jedno z možných, tvoje může vypadat jinak a být správně.
Neuloží se

Po zavření nebo obnovení stránky se tvůj kód smaže. Co si chceš nechat, zkopíruj si.

Nejčastější chyby

Výpis

1 Ahoj, světe!

2 min

Program už jeden řádek vypisuje. Spusť ho tlačítkem Spustit (nebo Ctrl + Enter). Pak ho doplň tak, aby vypsal přesně tyto tři řádky, jen s tvým jménem.

Očekávaný výstup

Ahoj, světe!
Jmenuji se Eliška.
Učím se Python.
Nápověda

Každý příkaz print vypíše jeden řádek. Text patří do uvozovek a celý do kulatých závorek.

Výstup




Řešení
print("Ahoj, světe!")
print("Jmenuji se Eliška.")
print("Učím se Python.")
Tři příkazy, tři řádky. Python provádí příkazy shora dolů, jeden po druhém.






2 Najdi a oprav chyby
4 min


V programu jsou tři chyby, na každém řádku jedna. Spusť ho a přečti si, co Python hlásí. Hláška ti řekne číslo řádku. Oprav jednu chybu, spusť znovu a pokračuj.


Očekávaný výstup
Dobrý den
Dnes je pátek
Výsledek je 5


Nápověda
Python rozlišuje velká a malá písmena. Každé uvozovky se musí zavřít. Když chceš v print vypsat víc věcí za sebou, odděl je čárkou.



  

  
  
Výstup

  




Řešení
print("Dobrý den")
print("Dnes je pátek")
print("Výsledek je", 5)
1) Print a print jsou pro Python dvě různá slova a zná jen to druhé. 2) Chyběly koncové uvozovky. 3) Chyběla čárka mezi textem a číslem. Všimni si, že print mezi ně sám vloží mezeru.

3 Co vypíše?
3 min


Nejdřív nespouštěj. Na papír napiš, jaká tři čísla program vypíše. Teprve potom ho spusť a porovnej.


Nápověda
Rovnítko v Pythonu neznamená rovnost, ale ulož: vyhodnoť pravou stranu a výsledek ulož do proměnné vlevo. Co se stane s b, když později změníš a?



  

  
  
Výstup

  




Řešení
8
5
40
b = a uloží do b hodnotu, kterou má a právě teď, tedy 5. Pozdější změna a už b neovlivní. Zápis a = a + 3 čti zprava: vezmi starou hodnotu a, přičti 3 a výsledek ulož zpět do a.






4 Pizza pro třídu
5 min


Třída má 28 studentů, každý sní 3 kousky a jedna pizza má 8 kousků. Doplň program tak, aby spočítal a vypsal, kolik kousků se sní celkem, kolik je to celých pizz a kolik kousků zbývá do další pizzy.


Očekávaný výstup
Kousků celkem: 84
Celých pizz: 10
Kousků navíc: 4


Nápověda
Kromě + - * / má Python ještě // (celočíselné dělení: 17 // 5 je 3) a % (zbytek po dělení: 17 % 5 je 2).



  

  
  
Výstup

  




Řešení
studentu = 28
kousku_na_studenta = 3
kousku_v_pizze = 8

kousku = studentu * kousku_na_studenta
cele_pizzy = kousku // kousku_v_pizze
zbyva = kousku % kousku_v_pizze

print("Kousků celkem:", kousku)
print("Celých pizz:", cele_pizzy)
print("Kousků navíc:", zbyva)
84 kousků je 10 celých pizz a 4 kousky navíc, takže objednat je potřeba 11. Zkus změnit počet studentů: díky proměnným se všechno přepočítá samo. Zkus také obyčejné dělení /: dostaneš 10.5, desetinné číslo.






5 Kolik je to hodin?
4 min


Stopky ukazují počet sekund. Převeď ho na hodiny, minuty a sekundy. Program musí fungovat pro libovolné číslo, ne jen pro 3725.


Očekávaný výstup
1 h 2 min 5 s


Nápověda
Kolik celých hodin je v 3725 sekundách? 3725 // 3600. Kolik sekund zbude? 3725 % 3600. Se zbytkem udělej totéž pro minuty.



  

  
  
Výstup

  




Řešení
sekundy = 3725
hodiny = sekundy // 3600
zbytek = sekundy % 3600
minuty = zbytek // 60
zbytek = zbytek % 60
print(hodiny, "h", minuty, "min", zbytek, "s")
Postupně „ukusuješ“ největší jednotky a se zbytkem pracuješ dál. Pro 100000 sekund vyjde 27 h 46 min 40 s.

6 Pozdrav
3 min


Funkce input se zeptá uživatele a vrátí, co napsal. Tady uživatele zastupuje pole Vstup: každý jeho řádek je jedna odpověď. Doplň program tak, aby pozdravil jménem a zeptal se i na oblíbené jídlo.


Očekávaný výstup
Jak se jmenuješ? Eliška
Co rád(a) jíš? svíčková
Ahoj, Eliška!
Mňam, svíčková!


Nápověda
Do f"…" řetězce vložíš proměnnou tak, že ji napíšeš do složených závorek: f"Ahoj, {jmeno}!".



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
jmeno = input("Jak se jmenuješ? ")
jidlo = input("Co rád(a) jíš? ")
print(f"Ahoj, {jmeno}!")
print(f"Mňam, {jidlo}!")
input zastaví program, dokud uživatel neodpoví. Když v poli Vstup chybí řádek, program skončí hláškou, že mu došel vstup.






7 Proč je 5 + 3 = 53?
4 min


Program má sečíst dvě čísla, ale pro 5 a 3 vypíše 53. Spusť ho, zjisti proč a oprav ho.


Očekávaný výstup
První číslo: 5
Druhé číslo: 3
Součet je 8


Nápověda
input vždycky vrací text, i když uživatel napíše číslice. Text a text se „sčítá“ tak, že se slepí. Funkce int(…) převede text na celé číslo.



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
a = int(input("První číslo: "))
b = int(input("Druhé číslo: "))
print("Součet je", a + b)
Hodnoty mají typ: "5" je text (str), 5 je celé číslo (int), 5.0 desetinné číslo (float). Zkus do Vstupu napsat pět: int takový text převést neumí a ohlásí ValueError.






8 Kdy ti bude sto?
4 min


Zeptej se na rok narození a vypiš, kolik let ti bude letos (2026) a ve kterém roce oslavíš sté narozeniny.


Očekávaný výstup
Rok narození: 2010
Letos ti bude 16 let.
Sto ti bude v roce 2110.


Nápověda
Načti rok jako číslo (vzpomeň si na minulý úkol). Věk letos je rozdíl dvou letopočtů, sté narozeniny jsou rok narození plus sto.



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
rok = int(input("Rok narození: "))
letos = 2026
print(f"Letos ti bude {letos - rok} let.")
print(f"Sto ti bude v roce {rok + 100}.")
Uložit 2026 do proměnné letos je lepší než psát číslo přímo do výpočtu: za rok změníš jedno místo a pojmenovaná hodnota se líp čte.

9 Sudé, nebo liché?
4 min


Načti celé číslo a vypiš, jestli je sudé, nebo liché. Vyzkoušej víc čísel, třeba i 0 a záporná.


Očekávaný výstup
Zadej číslo: 7
liché


Nápověda
Sudé číslo má po dělení dvěma zbytek 0. Porovnání se píše == (dvě rovnítka), jedno rovnítko je přiřazení. Řádky uvnitř if a else musí být odsazené (klávesa Tab).



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
n = int(input("Zadej číslo: "))

if n % 2 == 0:
    print("sudé")
else:
    print("liché")
Za if a else je dvojtečka a odsazený blok. Odsazení není ozdoba: podle něj Python pozná, které řádky k podmínce patří. Výsledek pro -3 je „liché“, protože -3 % 2 je v Pythonu 1.






10 Známka z testu
6 min


Z testu se dá získat 0 až 50 bodů. Načti body a vypiš známku podle tabulky.
BodyZnámka
45 a víc1
38 až 442
30 až 373
20 až 294
méně než 205


Očekávaný výstup
Body: 41
Známka: 2


Nápověda
Použij if, několikrát elif a na konci else. Podmínky se testují shora: jakmile jedna platí, zbytek se přeskočí. Proto stačí psát jen dolní hranice, pokud začneš od nejvyšší.



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
body = int(input("Body: "))

if body >= 45:
    print("Známka: 1")
elif body >= 38:
    print("Známka: 2")
elif body >= 30:
    print("Známka: 3")
elif body >= 20:
    print("Známka: 4")
else:
    print("Známka: 5")
Otestuj hranice: 45, 44, 38, 37, 30, 20, 19. Chyby se schovávají právě tam. Zkus také prohodit pořadí podmínek (začít body >= 20) a sleduj, co se pokazí.






11 Přestupný rok
6 min


Rok je přestupný, když je dělitelný 4, ale ne 100. Výjimka: roky dělitelné 400 přestupné jsou. Takže 2024 ano, 1900 ne, 2000 ano. Napiš program, který o zadaném roce rozhodne.


Očekávaný výstup
Rok: 1900
nepřestupný


Nápověda
Podmínky můžeš spojovat slovy and (musí platit obě) a or (stačí jedna). „Dělitelný 4“ zapíšeš jako rok % 4 == 0, „není dělitelný 100“ jako rok % 100 != 0.



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
rok = int(input("Rok: "))

if (rok % 4 == 0 and rok % 100 != 0) or rok % 400 == 0:
    print("přestupný")
else:
    print("nepřestupný")
Závorky tu nejsou nutné, protože and má přednost před or, ale pomáhají čtení. Vyzkoušej všechny čtyři případy: 2023, 2024, 1900, 2000.

3 min


Program vypisuje čísla od 0 do 9. Uprav ho tak, aby odpočítával od 10 do 1 a nakonec vypsal Start!.

10
9
8
7

4

Start!


Nápověda
range(a, b, krok) začne na a a skončí před b. Krok může být záporný. Řádek se Start! už do cyklu nepatří, takže nebude odsazený.



  

  
  
Výstup

13 Malá násobilka
5 min


Načti číslo a vypiš jeho násobilku od 1 do 10 přesně v tomto tvaru.


Očekávaný výstup
Násobilka čísla: 7
7 × 1 = 7
7 × 2 = 14
…
7 × 10 = 70


Nápověda
Kolikrát se má cyklus opakovat a jakých hodnot má proměnná nabývat? Pozor, range(10) začíná nulou. Výpis nejsnáz poskládáš přes f"…".



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
n = int(input("Násobilka čísla: "))

for i in range(1, 11):
    print(f"{n} × {i} = {n * i}")
Uvnitř složených závorek ve f-řetězci může být i výpočet, třeba {n * i}.






14 Sčítej, dokud nezadám nulu
6 min


Program má načítat čísla tak dlouho, dokud uživatel nezadá 0. Pak vypíše jejich součet. Dopředu nevíš, kolik čísel přijde, a proto se tu hodí cyklus while.


Očekávaný výstup
Číslo: 4
Číslo: 7
Číslo: -2
Číslo: 0
Součet: 9


Nápověda
Potřebuješ proměnnou na průběžný součet, na začátku 0. Načti první číslo ještě před cyklem. V cyklu ho přičti a načti další. Cyklus běží, dokud cislo != 0.



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
soucet = 0
cislo = int(input("Číslo: "))

while cislo != 0:
    soucet = soucet + cislo
    cislo = int(input("Číslo: "))

print("Součet:", soucet)
for použij, když víš, kolikrát opakovat. while použij, když opakuješ, dokud platí podmínka. Když zapomeneš uvnitř cyklu načíst další číslo, podmínka bude platit pořád a cyklus nikdy neskončí. Editor takový program po pěti sekundách zastaví.

15 Stromeček
8 min


Načti výšku a nakresli z hvězdiček stromeček. Na řádku 1 je jedna hvězdička, na každém dalším o dvě víc, a celý je zarovnaný na střed.


Očekávaný výstup
Výška: 4
   *
  ***
 *****
*******
   |


Nápověda
Text jde násobit číslem: "*" * 3 je ***. Pro řádek i (od 0) potřebuješ 2*i + 1 hvězdiček. Kolik mezer před nimi? Na posledním řádku žádná, na předposledním jedna…



  

  
  
co by napsal uživatel, jedna odpověď na řádek

  
  
Výstup

  




Řešení
vyska = int(input("Výška: "))

for i in range(vyska):
    mezery = vyska - i - 1
    hvezdy = 2 * i + 1
    print(" " * mezery + "*" * hvezdy)
print(" " * (vyska - 1) + "|")
Klíčové je najít vzorec, jak počet mezer a hvězdiček závisí na čísle řádku. Nakresli si to do tabulky (řádek, mezery, hvězdy) a vzorec uvidíš. Kmen pod stromečkem je dobrovolný.
