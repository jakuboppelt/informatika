Python: proměnné a typy

Navazuje na první kroky. Podíváme se důkladněji na proměnné a na to, jaké hodnoty v nich mohou být: čísla, text a logické hodnoty. Nejdřív krátký výklad s ukázkami, které si můžeš zkopírovat a vyzkoušet, potom úkoly. Jak programy psát a spouštět, najdeš v prvních krocích.

Úkolů8 + 1 bonus, od nejlehčího
Časjedna vyučovací hodina
Když se zaseknešpřečti chybu, pak Nápověda, až nakonec Řešení

Výklad

Proměnná

V první lekci jsi proměnné už používal(a). Teď si řekneme přesněji, co to je, a naučíš se, jaké hodnoty v nich mohou být.

Proměnná je jméno, pod kterým si program pamatuje hodnotu. Hodnota je uložená v paměti počítače a jméno je štítek, podle kterého ji program najde. Proměnnou vytvoříš tím, že jí poprvé něco přiřadíš:

Ukázka
jmeno = "Eliška"
vek = 16
print(jmeno, vek)

Výstup

Eliška 16

Rovnítko není rovnost

V programování = neznamená „je rovno“, ale ulož. Python nejdřív vypočítá pravou stranu a výsledek uloží do proměnné vlevo. Proto má smysl i tento zápis, který by v matematice nedával smysl:

Ukázka
x = 5
x = x + 1      # vezmi x (5), přičti 1, výsledek ulož zpět do x
print(x)       # 6

Zkrácené zápisy

Změnit proměnnou podle její staré hodnoty se dělá tak často, že pro to existují zkratky. Stejně fungují i /= a //=.

Ukázka
body = 10
body += 5      # totéž co body = body + 5, tedy 15
body -= 3      # body = body - 3, tedy 12
body *= 2      # body = body * 2, tedy 24
print(body)    # 24

Jména proměnných

  • Píšou se malými písmeny, bez diakritiky, místo mezery je podtržítko: cena_s_dph.
  • Nesmí začínat číslicí a nesmí obsahovat mezeru. Velká a malá písmena se rozlišují: Mesto a mesto jsou dvě různé proměnné.
  • Nesmí být shodná s klíčovým slovem Pythonu (if, for, def, class, True a další), ty mají pevný význam.
  • Jméno má říkat, co v proměnné je: vek je lepší než x.
Hodnoty, které se nemění

Hodnotu, která se v programu nemá měnit (třeba sazba daně), podle dohody píšeme VELKÝMI písmeny: DPH = 0.21. Python tě nezastaví, kdybys ji přepsal(a), je to upozornění pro člověka, který kód čte. Když se sazba změní, upravíš jedno místo v programu.

Datové typy

Každá hodnota v Pythonu má typ. Typ říká, co hodnota je a co s ní jde dělat. Zatím nám stačí čtyři základní:

TypVýznamPříklady
intcelé číslo42, -7, 0
floatdesetinné číslo, píše se s tečkou3.14, -0.5, 2.0
strtext (řetězec, anglicky string)"ahoj", 'ahoj', "", "42"
boollogická hodnota: pravda, nebo nepravdaTrue, False

Typ hodnoty zjistíš funkcí type:

Ukázka
print(type(42))
print(type(3.14))
print(type("ahoj"))
print(type(True))
print(type("42"))

Výstup

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'str'>

Pozor na poslední řádek: "42" je v uvozovkách, takže je to text, ne číslo.

Typ určuje, co s hodnotou jde dělat

Stejný zápis může mít podle typu jiný význam, nebo nemusí fungovat vůbec:

Ukázka
print(5 + 3)        # 8      čísla se sečtou
print("5" + "3")    # 53     texty se slepí
print("ha" * 3)     # hahaha text se zopakuje
print("5" + 3)      # TypeError: can only concatenate str (not "int") to str

Poslední řádek skončí chybou, protože Python neví, jestli má text a číslo sečíst, nebo slepit. Musíš mu to říct sám: buď převedeš text na číslo, nebo číslo na text (viz Převody typů).

Typ patří hodnotě, ne proměnné

Proměnná si může vzít hodnotu jiného typu, než jakou měla dřív. Python ti v tom nebrání, ale musíš si hlídat, co v ní zrovna je.

Ukázka
x = 5
print(type(x))      # <class 'int'>
x = "pět"
print(type(x))      # <class 'str'>

Čísla

Se čísly typu int a float se počítá takto:

ZápisVýznamPříkladVýsledek
+sčítání7 + 29
-odčítání7 - 25
*násobení7 * 214
/dělení7 / 23.5
//celočíselné dělení7 // 23
%zbytek po dělení7 % 21
**mocnina7 ** 249
  • Dělení / dává vždy float, i když vyjde celé číslo: 10 / 2 je 5.0, ne 5. Celé číslo dostaneš až z //.
  • Když se smíchá int a float, výsledek je float: 3 + 0.5 je 3.5.
  • Pořadí operací je jako v matematice: nejdřív **, potom * / // %, nakonec + -. Závorky mají přednost před vším.
Ukázka
print(2 + 3 * 4)       # 14
print((2 + 3) * 4)     # 20
print(2 * 3 ** 2)      # 18
print(round(3.14159, 2))   # 3.14   zaokrouhlení na 2 desetinná místa
Desetinná tečka, ne čárka

Python zná jen desetinnou tečku: 3.5. Zápis 3,5 by pochopil úplně jinak. Desetinná čísla se v počítači ukládají přibližně a občas se to projeví drobnou odchylkou. Proč, uvidíš v bonusovém úkolu.

Text

Text (str) píšeme do uvozovek, dvojitých "…" nebo jednoduchých '…'. Záleží jen na tom, aby konec byl stejný jako začátek.

Spojování, opakování, délka

Ukázka
a = "Python"
b = "rulez"
print(a + " " + b)     # Python rulez   spojení textů
print(a * 2)           # PythonPython   opakování
print(len(a))          # 6              počet znaků

Jednotlivé znaky

Znaky v textu se číslují od nuly. Číslo znaku se píše do hranatých závorek za text. Záporné číslo počítá od konce.

ŘádekSlovo „Python“
ZnakPython
Číslo od začátku012345
Číslo od konce-6-5-4-3-2-1
Ukázka
slovo = "Python"
print(slovo[0])      # P
print(slovo[1])      # y
print(slovo[-1])     # n   poslední znak

Číslo mimo text skončí chybou IndexError: string index out of range, třeba slovo[6].

Velká a malá písmena

K textu patří i vlastní funkce, které se volají za tečkou:

Ukázka
jmeno = "Eliška"
print(jmeno.upper())    # ELIŠKA
print(jmeno.lower())    # eliška

Formátování čísel v textu

Do f-řetězce můžeš za proměnnou napsat :.2f, tedy „desetinné číslo na 2 místa“. Hodí se na ceny a měření:

Ukázka
cena = 12.5
print(f"Cena: {cena}")            # Cena: 12.5
print(f"Cena: {cena:.2f} Kč")     # Cena: 12.50 Kč

Logické hodnoty

Typ bool má jen dvě hodnoty: True (pravda) a False (nepravda). Píšou se velkým prvním písmenem a bez uvozovek. Zápis "True" v uvozovkách je text, a true Python vůbec nezná.

Porovnání

Porovnání dá jako výsledek logickou hodnotu:

ZápisVýznam
==rovná se
!=nerovná se
< >menší, větší
<= >=menší nebo rovno, větší nebo rovno
Ukázka
print(5 > 3)         # True
print(5 == 6)        # False
print(5 != 6)        # True
print("a" == "a")    # True
Jedno rovnítko, nebo dvě?

x = 5 hodnotu uloží. x == 5 se zeptá, jestli se rovná, a vrátí True nebo False. Záměna je jedna z nejčastějších chyb začátečníků.

and, or, not

Logické hodnoty se dají spojovat:

ZápisVýznamPlatí, když…
a and ba zároveňplatí obě části
a or bneboplatí aspoň jedna část
not aopakčást a neplatí
Ukázka
vek = 17
print(vek >= 15 and vek < 18)    # True    obě části platí
print(vek < 10 or vek > 60)      # False   ani jedna neplatí
print(not (vek == 17))           # False

Podle logických hodnot se rozhodují podmínky (if), které se naučíš až po funkcích. Logické hodnoty ale použiješ už v příští lekci.

Převody typů

Hodnotu jednoho typu můžeš převést na jiný funkcemi se jménem typu:

ZápisVýsledekPoznámka
int("42")42text na celé číslo
int(3.99)3desetinnou část ořízne, nezaokrouhluje
float("2.5")2.5text na desetinné číslo
float(7)7.0celé číslo na desetinné
str(123)"123"číslo na text
Ukázka
print(int("42") + 1)         # 43
print(float("2.5") * 2)      # 5.0
print("Věk: " + str(16))     # Věk: 16
print(int(float("3.5")))     # 3

Když převod nejde

Text, který nevypadá jako číslo, převést nejde. Python skončí s chybou ValueError:

Ukázka
int("pět")      # ValueError: invalid literal for int() with base 10: 'pět'
int("3.5")      # ValueError: text s tečkou na int nejde, nejdřív float
float("3,5")    # ValueError: could not convert string to float: '3,5'

Poslední dva řádky jsou častá past: int nepřijme text s desetinnou tečkou a float nepřijme desetinnou čárku.

input a převody

input vrací vždy text. Když chceš s odpovědí počítat, převeď ji hned při načtení: int(input("Věk: ")) pro celé číslo, float(input("Cena: ")) pro desetinné. F-řetězec naopak převádí sám, proto f"Věk: {vek}" funguje s číslem i s textem, kdežto "Věk: " + vek jen s textem.

Proměnné

1 Životy ve hře

3 min

Nejdřív nespouštěj. Na papír napiš, co program vypíše. Po každém řádku si zapiš, kolik mají proměnné právě teď. Teprve potom ho spusť a porovnej.

Výchozí kód
zivoty = 3
zivoty = zivoty - 1
zivoty -= 1
zivoty += 5
bonus = zivoty * 2
zivoty = zivoty // 2
print(zivoty, bonus)
Nápověda

Jdi řádek po řádku. zivoty -= 1 je zkratka za zivoty = zivoty - 1. Proměnná bonus se spočítá z hodnoty zivoty v tu chvíli a později se už nemění.

Řešení
3 12
ŘádekŽivotyBonus
zivoty = 33zatím neexistuje
zivoty = zivoty - 12
zivoty -= 11
zivoty += 56
bonus = zivoty * 2612
zivoty = zivoty // 2312

Každé přiřazení nejdřív vyhodnotí pravou stranu se starými hodnotami a teprve výsledek uloží. Proto se bonus po svém vzniku už nemění, i když zivoty o řádek níž klesne.

2 Jaký je to typ?

3 min

Nejdřív nespouštěj. Na papír napiš, jakého typu je každá z osmi hodnot (int, float, str, bool). Teprve potom program spusť a porovnej.

Výchozí kód
print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
print(type("True"))
print(type(10 / 2))
print(type(10 // 3))
print(type(5 > 3))
Nápověda

Uvozovky dělají z čehokoli text. Dělení / dává vždy desetinné číslo, // celé. Porovnání dává logickou hodnotu.

Řešení
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'str'>
<class 'float'>
<class 'int'>
<class 'bool'>

Nejčastější omyly jsou dva. "42" a "True" jsou kvůli uvozovkám texty, i když vypadají jako číslo a logická hodnota. A 10 / 2 je float (5.0), i když by výsledek šel zapsat jako celé číslo.

Nejdřív nespouštěj. Na papír napiš, co program vypíše. Teprve potom ho spusť a porovnej.

Plus u čísel sčítá, u textů je lepí. Hvězdička u textu opakuje. Mocnina ** má přednost před násobením a závorky mají přednost před vším.

Řešení

haha!

36

Řádky 2 a 3 pracují s texty: "5" + "3" je 53 a "5" * 3 je 555. U posledních dvou záleží na pořadí: 2 * 3 ** 2 je 2 * 9, ale (2 * 3) ** 2 je 6 ** 2.

4 Převody: co vypíše?

4 min

Nejdřív nespouštěj. Na papír napiš, co program vypíše. Jeden řádek skončí chybou: poznamenej si který a jaká to bude chyba. Teprve potom program spusť a porovnej.

Výchozí kód
print(int("42") + 1)
print(int(3.99))
print(float("2.5") * 2)
print("Věk: " + str(16))
print(int(float("3.5")))
print(int("3.5"))
Nápověda

int desetinnou část ořízne. Funkce float umí číst text s tečkou, ale int ne. Co se stane s řádky pod chybou? Python je už nespustí.

Řešení
43
3
5.0
Věk: 16
3
ValueError: invalid literal for int() with base 10: '3.5'

Pátý řádek jde, protože float("3.5") dá 3.5 a int z toho oříznutím udělá 3. Poslední řádek dá int rovnou text s tečkou a ten nepřijme: ValueError. Vedle chybové hlášky se vypíše i číslo řádku a kus programu (to si pamatuj z první lekce).

5 Cena s DPH

5 min

Zboží stojí určitou cenu bez DPH a DPH je 21 %. Vypiš cenu s DPH na dvě desetinná místa. Cenu načti od uživatele a pamatuj, že může mít i haléře.

Výchozí kód
DPH = 0.21
cena = float(input("Cena bez DPH: "))

# tvůj kód

Při spuštění zadej například: 249. Pak zkus i 249.90.

Očekávaný výstup

Cena bez DPH: 249
Cena s DPH: 301.29 Kč
Nápověda

Cena s DPH je cena * (1 + DPH). Výsledek ulož do proměnné a vypiš ho f-řetězcem. Za proměnnou ve složených závorkách může být :.2f, tedy desetinné číslo na 2 místa.

Řešení
Řešení
DPH = 0.21
cena = float(input("Cena bez DPH: "))

s_dph = cena * (1 + DPH)
print(f"Cena s DPH: {s_dph:.2f} Kč")

Cenu je potřeba načíst jako float, protože int by nepřijal 249.90. Zkus v posledním řádku vynechat :.2f: pro 249 vyjde 301.28999999999996. Proč se to děje, zjistíš v bonusovém úkolu. Díky pojmenované hodnotě DPH stačí při změně sazby upravit jediné místo.

6 Práce s textem

5 min

Načti od uživatele slovo a vypiš o něm pět údajů přesně v tomto tvaru.

Výchozí kód
slovo = input("Slovo: ")

# tvůj kód

Při spuštění zadej například: Python. Pak zkus i jiné slovo a nakonec jen stiskni Enter (prázdný text).

Očekávaný výstup

Slovo: Python
Délka: 6
První písmeno: P
Poslední písmeno: n
Velkými písmeny: PYTHON
Třikrát za sebou: PythonPythonPython
Nápověda

Počet znaků zjistí len(slovo). První znak je slovo[0] (číslování začíná nulou), poslední slovo[-1]. Velká písmena dá slovo.upper() a opakování *. Výpisy nejsnáz poskládáš přes print("Délka:", …).

Řešení
Řešení
slovo = input("Slovo: ")

print("Délka:", len(slovo))
print("První písmeno:", slovo[0])
print("Poslední písmeno:", slovo[-1])
print("Velkými písmeny:", slovo.upper())
print("Třikrát za sebou:", slovo * 3)

Pro prázdný text program skončí chybou IndexError: string index out of range: v prázdném textu není žádný první znak. Poslední znak by šel zapsat i jako slovo[len(slovo) - 1], ale záporné číslo je kratší.

Logické hodnoty

7 Pravda, nebo nepravda?

4 min

Nejdřív nespouštěj. Na papír napiš u každého řádku True, nebo False. Teprve potom program spusť a porovnej.

Výchozí kód
print(5 > 3)
print(5 == 5.0)
print("5" == 5)
print(10 % 3 == 1)
print(not (2 < 1))
print(3 > 2 and 3 > 5)
print(3 > 2 or 3 > 5)
Nápověda

Porovnání vždy dává True nebo False. Spojka and dá True, jen když platí obě strany, or když platí aspoň jedna. Pozor na řádky 2 a 3: porovnává se hodnota a text není číslo.

Řešení
True
True
False
True
True
False
True

Celé číslo 5 a desetinné 5.0 mají stejnou hodnotu, proto 5 == 5.0 je True. Text "5" se ale číslu 5 nerovná, i když se vypíše stejně. Řádek 4: 10 % 3 je 1, takže 1 == 1. Řádek 5: 2 < 1 je False a not ho obrátí. Řádky 6 a 7 se liší jedinou spojkou: 3 > 2 platí, 3 > 5 neplatí, a proto and dá False, kdežto or dá True.

Opravujeme

8 Najdi a oprav chyby

5 min

V programu jsou tři chyby a všechny souvisejí s typy. Spusť ho a přečti si, co Python hlásí. Oprav jednu chybu, spusť znovu a pokračuj.

Výchozí kód
vek = int(input("Kolik ti je? "))
print("Příští rok ti bude " + vek + 1)
cena = float("12,50")
print("Cena:", cena)
pocet = "3"
print("Celkem:", pocet * cena)

Při spuštění zadej například: 16.

Očekávaný výstup

Kolik ti je? 16
Příští rok ti bude 17
Cena: 12.5
Celkem: 37.5
Nápověda

Postupuj podle hlášek jednu po druhé. První se týká spojování textu s číslem, druhá desetinné čárky, třetí násobení textu desetinným číslem. Zvaž, kdy je vhodnější čárka v print a kdy převod str(…) nebo int(…).

Řešení
Řešení
vek = int(input("Kolik ti je? "))
print("Příští rok ti bude", vek + 1)
cena = float("12.50")
print("Cena:", cena)
pocet = 3
print("Celkem:", pocet * cena)

1) "…" + vek je text plus číslo: TypeError: can only concatenate str (not "int") to str. Nejjednodušší oprava je čárka v print, ten si číslo převede sám. Šlo by i f"Příští rok ti bude {vek + 1}". 2) Python chce desetinnou tečku: float("12,50") dá ValueError. 3) "3" je text a text se desetinným číslem násobit nedá: TypeError: can't multiply sequence by non-int of type 'float'. Oprava je psát 3 bez uvozovek, nebo převést int(pocet).

Bonus

9 Počítač a desetinná čísla

5 min

Nejdřív nespouštěj. Napiš, co podle tebe program vypíše. Pak ho spusť a zkus vysvětlit, co tě překvapilo.

Výchozí kód
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2) == 0.3)
print(2 ** 100)
Nápověda

Počítač ukládá čísla ve dvojkové soustavě. Zlomek 0,1 se v ní nedá zapsat přesně, podobně jako 1/3 se nedá přesně zapsat desetinným číslem. Celá čísla (int) jsou naopak přesná.

Řešení
0.30000000000000004
False
True
1267650600228229401496703205376

Desetinná čísla (float) jsou v počítači uložená přibližně, a proto 0.1 + 0.2 není přesně 0.3. Dvě desetinná čísla se proto neporovnávají pomocí ==. Buď se nejdřív zaokrouhlí (třetí řádek), nebo se porovná, jestli je jejich rozdíl dost malý. Ze stejného důvodu se peníze v programech často počítají v haléřích jako celá čísla. Celá čísla jsou naproti tomu přesná a v Pythonu mohou být libovolně velká: 2 ** 100 se vejde bez problému.
