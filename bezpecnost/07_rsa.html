1 · Prvočísla

Co je prvočíslo a jak je najít

Prvočíslo je číslo větší než 1, které je dělitelné jen jedničkou a samo sebou. Číslo 7 ano, číslo 8 ne (je dělitelné dvěma).

Eratosthenovo síto: vezmi nejmenší nevyškrtnuté číslo, nech ho a škrtni všechny jeho násobky.

1 · Prvočísla

Prvočísla jsou atomy čísel

Každé přirozené číslo větší než 1 se dá jediným způsobem složit z prvočísel (na pořadí nezáleží). Říká se tomu základní věta aritmetiky. Vyber číslo nebo napiš vlastní.

1 · Prvočísla

Násobit je snadné, rozkládat je pomalé

Vyber délku čísla. Počítač vybere dvě prvočísla, vynásobí je a pak se pokusí rozložit výsledek tím nejjednodušším způsobem: zkouší dělitele 3, 5, 7, 9, …

Nejlepší známý algoritmus (obecné číselné síto) je mnohem rychlejší než zkoušení dělitelů, ale pořád roste neúměrně rychle s délkou čísla. Číslo o 2048 bitech nezvládne, a proto mu věříme.

1 · Prvočísla

Dojdou nám prvočísla?

Nedojdou. Euklides to dokázal před více než 2000 lety: kdyby jich bylo konečně mnoho, vynásobil by je a přičetl jedničku. Takové číslo není dělitelné žádným z nich, takže musí být samo prvočíslo nebo mít nový prvočinitel. Spor.

A nejsou jen nekonečně, je jich i velmi hodně. Vyber délku v bitech.

1 · Prvočísla

Jak se najde obří prvočíslo

Prvočísla se neskládají podle vzorce. Vybere se náhodné liché číslo a otestuje se. Nejdřív rychle dělením malými prvočísly, potom Miller–Rabinovým testem, který složené číslo prozradí s velkou jistotou během jediného kola.

3 · Algoritmus RSA

Proč se zpráva vrátí

Klíče se vybírají tak, aby platilo e · d = 1 + k · φ. Eulerova věta říká, že mφ dává zbytek 1, a tak se při dešifrování mocniny „vykrátí“:

me·d = m1 + k·φ = m · (mφ)k ≡ m · 1k = m

4 · RSA v praxi

RSA nešifruje data, jen klíč

RSA je pomalé a zvládne jen malý blok (u 2048 bitů nanejvýš 190 bajtů). Proto se používá hybridně: RSA ochrání malý klíč a data se šifrují rychlou symetrickou šifrou AES.

Zkus doma

RSA od nuly v Pythonu

Celé RSA na pár řádcích. Vlastní prvočísla, klíče, zašifrování a dešifrování. Stačí standardní knihovna (Python 3.8 a novější).

import math
import secrets


def je_prvocislo(n, kol=20):
    """Miller–Rabin: pravděpodobnostní test prvočíselnosti."""
    if n < 2:
        return False
    for p in (2, 3, 5, 7, 11, 13):
        if n % p == 0:
            return n == p
    d, s = n - 1, 0
    while d % 2 == 0:
        d //= 2
        s += 1
    for _ in range(kol):
        a = secrets.randbelow(n - 3) + 2
        x = pow(a, d, n)
        if x in (1, n - 1):
            continue
        for _ in range(s - 1):
            x = x * x % n
            if x == n - 1:
                break
        else:
            return False
    return True


def nahodne_prvocislo(bity):
    while True:
        x = secrets.randbits(bity) | (1 << (bity - 1)) | 1   # přesně `bity` bitů, liché
        if je_prvocislo(x):
            return x


e = 65537
while True:
    p, q = nahodne_prvocislo(512), nahodne_prvocislo(512)
    phi = (p - 1) * (q - 1)
    if p != q and math.gcd(e, phi) == 1:
        break

n = p * q
d = pow(e, -1, phi)            # modulární inverze (Python 3.8+)

print("n má", len(str(n)), "číslic")
zprava = int.from_bytes("Ahoj".encode(), "big")
sifra = pow(zprava, e, n)      # šifrování: m^e mod n
print("šifra:", sifra)
print("zpět: ", pow(sifra, d, n).to_bytes(4, "big").decode())

Je to jen pro výuku: klíč o 1024 bitech je dnes slabý a chybí padding. Skutečné klíče vyrábí osvědčená knihovna. Zkus změnit 512 na 16 a rozložit n ručně.

Skutečné RSA: knihovna a příkazy

from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import rsa, padding

soukromy = rsa.generate_private_key(public_exponent=65537, key_size=2048)
verejny = soukromy.public_key()

oaep = padding.OAEP(mgf=padding.MGF1(hashes.SHA256()), algorithm=hashes.SHA256(), label=None)
s1 = verejny.encrypt(b"Ahoj", oaep)
s2 = verejny.encrypt(b"Ahoj", oaep)
print(s1 == s2)                    # False: OAEP přidává náhodu
print(soukromy.decrypt(s1, oaep))     # b'Ahoj'

pss = padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH)
podpis = soukromy.sign(b"Smlouva", pss, hashes.SHA256())
verejny.verify(podpis, b"Smlouva", pss, hashes.SHA256())   # při změně textu vyhodí InvalidSignature

RSA ve třídě na papíře

  1. Klíče: každý si vybere dvě prvočísla do 50 a spočítá n, φ, e a d. Pomůže slide s generátorem.
  2. Zveřejnění: dvojici (n, e) napíše na tabuli. Číslo d nikomu neříká.
  3. Zpráva: soused si vybere cizí veřejný klíč, zprávu převede na čísla (A = 1) a zašifruje je. V Pythonu stačí pow(m, e, n).
  4. Dešifrování: majitel klíče vrátí čísla na písmena pomocí pow(c, d, n).
  5. Eva: zbytek třídy zkusí z veřejného klíče zjistit d. Jak dlouho jim to trvá? A co kdybyste si vybrali prvočísla o šesti číslicích?

Shrnutí

Co si odneseš

  • Prvočísla jsou atomy čísel. Dvě velká vynásobit je okamžité, součin rozložit je prakticky nemožné.
  • Pár veřejný a soukromý klíč řeší předání tajemství cizím lidem: zámek se rozdává, klíček zůstává u majitele.
  • RSA: n = p · q, veřejný klíč (n, e), soukromý klíč d. Šifrování je c = me mod n, dešifrování m = cd mod n.
  • Obrácený směr je podpis: podepisuje soukromý klíč, ověřuje veřejný.
  • V praxi se přidává padding (OAEP, PSS) a RSA chrání jen klíč, data šifruje AES.
  • Dnes platí 2048 bitů jako minimum. Kvůli kvantovým počítačům se plánuje přechod na postkvantové algoritmy.
